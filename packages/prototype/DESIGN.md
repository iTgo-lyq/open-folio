# OpenFolio 设计规范

## 产品与依据

OpenFolio 为项目成员提供 Specs、Changes 和原型的只读工作台。主要任务是选择项目、定位记录、阅读来源并查看交付；页面优先保证阅读连续性和当前位置清晰。

本文件提炼当前产品，不定义新的视觉改版。实现依据：

- [共享主题与组件样式](../ui/src/styles.css)：`--of-*` token、按钮、表单、标签与容器。
- [业务布局样式](../../src/app/globals.css)：工作台骨架、模块导航、阅读区及断点。
- [工作台壳层](../../src/components/workspace.tsx)：导航层级、项目上下文、搜索和配置入口。
- [UI 包用法](../ui/README.md) 与 [根开发约定](../../AGENTS.md)：组件复用边界。

规则与实现冲突时核对上述来源，修订本文件；不要用旧原型覆盖正式产品。本文中的设计意图是对当前实现的归纳。

## 视觉方向

浅雾蓝底色包围白色工作面，深蓝用于操作和选中，细分隔线组织信息。整体偏轻、冷静，标题克制，给长文和结构化记录保留空间。

辨识特征是左侧悬浮胶囊导航与大面积白色工作面；渐变、半透明与柔和阴影集中在外壳，内容区域保持平实。保留现有 OpenFolio 品牌图标，不引入营销式大标题、插画或高饱和配色。

## 色彩与字体

| 角色 | 名称 / token | 实际值 | 使用位置 |
| --- | --- | --- | --- |
| 正文 | 墨灰 `--of-ink` | `#2e3c46` | 控件与主要文字 |
| 辅助 | 蓝灰 `--of-muted` | `#7a8995` | 次级信息、图标；不作为唯一状态提示 |
| 边界 | 浅灰 `--of-line` | `#e9edf0` | 内容分隔和轻边框 |
| 操作 | 深蓝 `--of-blue` | `#285d80` | 主操作、链接 |
| 轻强调 | 雾蓝 `--of-blue-soft` | `#edf5fb` | 悬停和轻背景 |
| 表面 | `--of-surface` / 白色 | `#f8fbfd` / `#ffffff` | 次级控件 / 工作面 |
| 焦点 | `--of-focus` | `#749ebb` | 2px 焦点描边，外扩 3px |
| 成功 / 提醒 / 错误 | `--of-green` / `--of-orange` / `--of-red` | `#548673` / `#b48b49` / `#ae655e` | 结合文案或图标表达状态 |

外壳沿用 `#f8fafc` 基底上的浅蓝、浅紫、近白径向渐变；工作面为白色。导航的当前项使用近白半透明圆面和 `#355e7f` 图标，避免把所有可点元素都做成实心主按钮。

字体采用 `--of-font`：Inter、系统 UI 字体、PingFang SC、Microsoft YaHei、sans-serif；当前未打包或远程下载 Inter，实际字体依赖本机回退。代码与快捷键用 SFMono-Regular / Consolas / Liberation Mono / monospace。

| 文本用途 | 字号 / 字重 / 行高 | 应用规则 |
| --- | --- | --- |
| 全局控件 | 13px / 常规 | 紧凑工具型界面，项目名及模块名用 600 |
| 主按钮 | 12px / 400 / 1.5 | 明确动作，不用大号营销按钮 |
| 来源和辅助文字 | 10–11px / 常规 | 分支、只读标记和更新时间 |
| 阅读正文 | 13px / 常规 / 1.95 | 长文阅读；正文色 `#657480` |
| 文档一级标题 | 27px / 600 / 1.5 | 字距 -0.035em，色 `#354e60` |
| 文档二级标题 | 18px / 550 / 1.6 | 轻底线，字距 -0.02em |

这里只记录已实现的字号；本次外壳原型不填充文档正文或业务列表。

## 布局与尺寸

桌面外壳占满 `100dvh`，左侧轨道 84px，右侧工作面自适应。外边距为上/右/下 12px，工作面圆角 16px；顶部栏高 64px、左右内边距 25px，来源栏高 39px。内容面板单独滚动，避免头部与上下文一起丢失。

模块胶囊宽 60px，导航点击区 44×44px；品牌按钮同为 44px。折叠侧栏后保留 12px 恢复把手，配置入口移到头部。共享间距基准为 4px，按钮圆角 7px、最小高度 34px；外壳使用更大的圆角和更轻的阴影以区分层级。

| 视口 | 既有行为 |
| --- | --- |
| 大于 1180px | 完整侧栏、搜索文字与快捷键提示 |
| 761–1180px | 保留侧栏，搜索收为图标；正文侧目录折叠 |
| 不超过 760px | 左侧轨道隐藏，模块导航移至底部；配置入口在顶部；外壳边距 9px、底部预留 78px；工作面圆角 13px、顶部高 58px |
| 不超过 360px | 进一步收紧项目选择器与头部间距，隐藏来源时间 |

新增页面遵循实际内容重排，不靠整体缩放适配手机。原型检查 1440×1000、768×1024、390×844，并检查 320px 窄屏。

## 组件与交互

- 导航：Specs / Changes / 原型三项固定顺序，当前项同时有底色与 `aria-current`；桌面图标提供悬停/键盘标签，手机显示图标和文字。
- 项目上下文：左侧项目标识和选择器，后接当前模块、只读标记；切换项目清除前一项目上下文。来源栏独立表达分支及读取状态。
- 基础组件：正式产品从 `@open-folio/ui` 复用 Button、IconButton、Badge、Field/Input、Card、Tabs 等，组合放 `src/components`。原型采用内联 HTML/CSS 保存同样的视觉规则；不另造通用组件库。
- 表单与反馈：标签关联控件，错误同时有文案，操作成功或失败提供状态反馈。禁用态有样式和语义；可点击图标有名称。业务内容依次区分加载、无内容、失败与正常状态。
- 键盘：保持可见焦点；搜索快捷键为 Cmd/Ctrl+K，弹层支持 Escape 关闭并回到触发控件。移动端保留可用的配置和导航入口。
- 动效：导航颜色约 150ms、侧栏宽度约 200ms；尊重 `prefers-reduced-motion`。原型不访问浏览器持久存储、业务接口或外部资源。

当前产品有较浅辅助文字和 30–34px 小图标按钮，本文记录现状，不声称已完成全部 WCAG 对比度或触控目标审计。

## 页面外壳与后续延续

当前原型只有 `workspace-shell`：品牌、模块导航、项目上下文、顶部工具、来源栏和留白内容面。模块切换、折叠、搜索入口及配置入口只演示壳层交互，配置反馈不修改真实设置。没有测试 Change、模拟业务指标或正文。

构建生成自包含 HTML：样式与脚本内联，品牌图像为 data URL。发布方式见 [README.md](README.md)，当前入口在 `prototype.json`，固定交付由 Change 引用保留；已归档原型不随当前清理或存储迁移改写。

后续新增业务原型先复用这套壳层和规则；明确新增状态与例外，同时更新规范及对应实现。不要用旧 demo 的布局作为新的产品基线。
