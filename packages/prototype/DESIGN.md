# OpenFolio 设计规范

## change-sharing 分享模式原型

用户反馈“更适合阅读文档”后，本页以文档站组织分享内容。沿用正式产品字体与深蓝操作色，正文采用白色、文字 #253344，导航底色 #f7f9fc、辅助文字 #617184、边界 #e5ebf1、选中和链接 #285d80；不采用其他未验收原型的视觉系统。

桌面采用 244px 材料侧栏、最大 720px 正文和 200px 章节导航。Change 摘要收进侧栏；文档标题 34px、章节 23px、正文 16px/1.95，文件名使用等宽辅助字体。1200px 以下隐藏右侧章节栏，通过“本页目录”打开；700px 以下材料侧栏收为目录弹层，正文保持 16px，标题 30px。首屏直接进入材料，六类 Change 内容仍从侧栏或手机目录进入。专注阅读收起侧栏并保持舒适行宽，字号可切换为 18px；提供章节定位、当前章节与阅读进度、上一篇/下一篇。表格和代码在自身区域横向滚动。

分享管理、异常状态和全部详情范围保留；链接失效不展示 Change 标题或正文。顶部评审工具默认折叠，仅用于示例视角、场景和模拟推送，不进入产品。状态仅存内存，不调用真实接口；遵循键盘焦点、Escape 关闭、目录选择后焦点回到内容和减少动态效果规则。

### 覆盖与能力依据

2026-10-20 核对的产品依据为协作分支 `develop@fee9a9f`，并已对照当前 Specs 和页面实现。六组主体入口为：仓库首页与导航、Specs 阅读、Changes 列表详情、原型总览设备预览、Token 登录与当前凭据、匿名公开原型页。需求澄清 Q1 选择全部覆盖；Q2 选择浅色和深色同时覆盖三种设备；Q3 选择全部按当前 Token 登录能力设计。运维配置完整页面、UI 组件库独立预览不纳入。

`centralized-accounts` 的账号密码实现尚未合入此基线；本 Change 不采用其登录/注册、账号绑定 Token 或跨浏览器账号恢复。旧蓝色玻璃原型的搜索、收藏、全量内容计数、最近动态和偏好页仅为历史演示，不继承为能力要求。当前真实产品与旧原型的差异详见需求；后续协作分支变化应先核对，不用其他分支的原型替代事实。

### 视觉与交互规则

- **气质与布局**：安静、轻盈、柔和、内容优先；侧栏融入窗口背景，中央内容形成完整文档表面。用低对比背景、细微边界和充足留白组织导航、正文及按需出现的辅助工具，减少厚重分割线。常用操作直接可达，低频操作放菜单、浮层或辅助面板。
- **色彩与材质**：框架以冷调中性色为主，蓝色用于选中、主操作、焦点和适当状态；成功/警告/错误同时配文案或图标。玻璃仅用于浮于内容之上的顶部工具栏、导航、切换器、菜单、弹出层和抽屉外层。正文、表格、长文、表单及抽屉阅读区为实底；不叠加多层玻璃，容器内控件不用第二层模糊。透明、高光、细边界和柔和阴影服务于层级，可读性优先。
- **明暗主题**：浅色与深色分别安排窗口、工作面、辅助层、文本和语义状态，不简单反色；手机可探索纯黑底色。主题切换仅用内存状态，不声称已具备服务端同步。确切色值、字阶和尺寸随后续原型设计确定，旧稿 token 只作参考，不提前固定技术方案。
- **字体与组件**：功能界面使用本地/系统无衬线字体，靠字号、字重、行距和留白建立层级；检查中文、中英混排、粗体和长文。图标简洁、笔画统一；圆角随尺寸递增，小控件紧凑，卡片与浮层更柔和。按钮、列表、标签、输入框和菜单保持一致节奏，避免装饰性边框。保留 Markdown 内容差异，不增加封面、字体选择或文档皮肤编辑器。
- **状态与连续操作**：hover、focus、selected、pressed、disabled、完成状态清楚，反馈轻微及时；选中、键盘焦点和打开详情不同。原型卡片图片打开预览，其他区域打开详情，两种动作各有可达入口。任务完成与记录时间配文字/图标，不创造没有数据依据的逾期。工程内容只读；不展示就地编辑、多选批量写入或拖动看板。快捷键服务于现有控件和阅读，不增加全局搜索或命令中心。
- **动效与降级**：面板展开/收起时宽度与圆角自然连续变化，动效短促，用来解释布局和切换。不支持 `backdrop-filter`、开启减少透明度或浏览器无法可靠识别透明度偏好时，采用不透明表面；开启减少动态效果时关闭动画与过渡。评审工具可切换降级场景，工具本身不进入产品导航。
- **响应式与可访问性**：覆盖桌面 1440×900、平板 834×1194、手机 390×844 及 320px 窄屏。目录/辅助面板收起后仍可恢复，主体和浮层无横向溢出，长路径换行；必要的代码/diff 横向滚动限制在独立阅读区。焦点可见，键盘路径完整，Escape 关闭最上层并恢复触发点焦点；触摸不依赖 hover。空态、加载失败、离线、无权限提供真实原因及可行下一步。

六个 `quiet-*` 入口共用一套窗口、导航和内容规则。浅色：窗口 `#edf0f5`、工作面 `#ffffff`、次级面 `#f5f7fa`、正文 `#263345`、辅助文字 `#657186`、蓝色 `#3268cf`。深色：窗口 `#151a22`、工作面 `#202731`、次级面 `#272f3b`、正文 `#e1e8f2`、辅助文字 `#a0aec1`、蓝色 `#9bbaff`。状态继续使用独立绿、琥珀和红，配文字或图标。

正文、表格和表单为实底。项目切换器与手机导航在支持且未启用减少透明度时采用局部 blur(18px)，否则使用不透明表面。面板宽度/圆角过渡为 180ms；减少动态效果会关闭所有动画和过渡。深色重新安排对比与表面，未使用纯黑反色或外部字体。画布按实际设备尺寸绘制，以缩放适应可见区域；100% 仅在画布内滚动，不撑宽页面。

### 原型数据、验收与发布

仅使用虚构用户、仓库、文档和凭据，状态只驻留内存，不访问真实接口或浏览器持久存储；不加载外部字体或 CDN，全部运行资源来自包内并按现有方式内联。原型评审工具明确标记示例数据，提供加载、空态、失败、离线、无权限、失效会话、复制失败和降级场景。临时离线可保留已显示内容；明确失权必须清除私有正文，不展示离线授权或同步功能。

浅色/深色、六组入口、三种设备均需验证，含键盘、焦点恢复、触摸、阅读边界和浏览器错误检查。只读工程记录与匿名固定预览权限必须准确；现有设备批量退出也只能影响当前 Token 工作台。发布时使用新的固定产物和三种设备缩略图，保留旧引用，并提供两套主题的检查证据。用户明确验收固定版本后才整理 Technical/Plan。详细验收以需求九项标准为准。

## account-login 方案原型

沿用正式产品的雾蓝外壳、玻璃侧轨、白色工作面及既有色彩、字阶。登录／注册采用窄表单，账号页以 Token 列表和登录设备页签组织；区分“退出登录”和“解除绑定”，文案保持简短。覆盖桌面、平板、手机及 320px 窄屏，弹窗支持 Escape 和焦点恢复。

顶部场景与浏览器 A／B 切换仅用于评审：模拟设备共享账号绑定，各自保存登录及 Token 选择。支持自填示例账号密码，仅接受 demo／demo-work 示例 Token；状态仅驻留内存，不访问真实接口或浏览器持久存储。该原型沿用当前产品样式。

## 布局与尺寸

桌面外壳占满 `100dvh`，左侧轨道 84px，右侧工作面自适应。外边距为上/右/下 12px，工作面圆角 16px；顶部栏高 64px、左右内边距 25px；读取来源和操作统一放在页头右侧。内容面板单独滚动，避免头部与上下文一起丢失。

模块胶囊宽 60px，导航点击区 44×44px；品牌按钮同为 44px。折叠侧栏后保留 12px 恢复把手，配置入口移到头部。共享间距基准为 4px，按钮圆角 7px、最小高度 34px；外壳使用更大的圆角和更轻的阴影以区分层级。

| 视口 | 既有行为 |
| --- | --- |
| 大于 1180px | 完整侧栏、页头右侧读取来源与操作 |
| 761–1180px | 保留侧栏，页头状态保持紧凑；正文侧目录折叠 |
| 不超过 760px | 左侧轨道隐藏，模块导航移至底部；配置入口在顶部；外壳边距 9px、底部预留 78px；工作面圆角 13px、顶部高 58px |
| 不超过 360px | 进一步收紧项目选择器与头部间距，隐藏来源时间 |

新增页面遵循实际内容重排，不靠整体缩放适配手机。原型检查 1440×1000、768×1024、390×844，并检查 320px 窄屏。

## 组件与交互

- 导航：Specs / Changes / 原型三项固定顺序，当前项同时有底色与 `aria-current`；桌面图标提供悬停/键盘标签，手机显示图标和文字。
- 项目上下文：左侧项目标识和选择器，后接当前模块、只读标记；切换项目清除前一项目上下文。页头右侧入口表达分支及读取状态，窄屏可展开查看完整信息。
- 基础组件：正式产品从 `@open-folio/ui` 复用 Button、IconButton、Badge、Field/Input、Card、Tabs 等，组合放 `src/components`。原型采用内联 HTML/CSS 保存同样的视觉规则；不另造通用组件库。
- 表单与反馈：标签关联控件，错误同时有文案，操作成功或失败提供状态反馈。禁用态有样式和语义；可点击图标有名称。业务内容依次区分加载、无内容、失败与正常状态。
- 键盘：保持可见焦点；弹层支持 Escape 关闭并回到触发控件。移动端保留可用的配置和导航入口。
- 动效：导航颜色约 150ms、侧栏宽度约 200ms；尊重 `prefers-reduced-motion`。原型不访问浏览器持久存储、业务接口或外部资源。

当前产品有较浅辅助文字和 30–34px 小图标按钮，本文记录现状，不声称已完成全部 WCAG 对比度或触控目标审计。

## 页面外壳与后续延续

`workspace-shell` 作为既有外壳基线：品牌、模块导航、项目上下文、页头右侧工具与读取状态和留白内容面。模块切换、折叠、读取状态及配置入口只演示壳层交互，配置反馈不修改真实设置。没有测试 Change、模拟业务指标或正文。

构建生成自包含 HTML：样式与脚本内联，品牌图像为 data URL。发布方式见 [README.md](README.md)，当前入口在 `prototype.json`，固定交付由 Change 引用保留；已归档原型不随当前清理或存储迁移改写。

后续新增业务原型先复用这套壳层和规则；明确新增状态与例外，同时更新规范及对应实现。不要用旧 demo 的布局作为新的产品基线。

## personal-workbench 方案原型

本节是新 Change 的设计提案，不代表正式产品已实现。用户要求个人工作台沿用既有侧边玻璃按钮框架。保持 84px 侧轨、60px 半透明玻璃胶囊、44px 圆形模块按钮、雾蓝渐变外壳和 16px 圆角白色工作面；玻璃的白色描边、内高光、柔和阴影与 blur(20px) saturate(135%) 延续外壳基线。

胶囊增加“我的仓库”入口，用细分隔线与 Specs／Changes／原型区分；后三项保留固定顺序。顶部品牌按钮收起侧栏，12px 把手恢复；底部圆形配置按钮进入“我的连接”。收起或手机布局时，连接入口移到顶部。没有可用仓库时，模块按钮有禁用语义；发现仓库后可进入最近选择的仓库。

仓库选择回到 64px 顶栏，提供“我的仓库”及当前可访问仓库选项；进入仓库后显示仓库名、当前模块和只读标记，不重复增加横向模块 Tabs。切换仓库保留模块并重置文档位置。页头右侧显示当前连接或仓库分支、读取状态和分享入口；正文区域独立滚动。

首页在白色工作面中以仓库行呈现名称、命名空间、内容和状态，保留状态筛选、重新发现与异常恢复。连接管理和首次连接页同样复用外壳。首版仅提供“连接 GitHub”，没有平台选择或尚未支持的平台占位。

色彩沿用既有主题；辅助文字采用 `#647582`，正文与控件以 13px 为主，文档标题 25–27px，仓库路径和提交为等宽字体。内容区保持平实，玻璃和阴影集中在侧边导航。

761–1100px 保留 84px 侧轨，读取状态通过页头右侧入口展开，文档目录通过阅读区入口打开。手机隐藏侧轨，在距底部 12px 的悬浮玻璃胶囊中展示“我的仓库／Specs／Changes／原型”四项，保留图标、文字和当前项底色；白色工作面底部预留 78px 及安全区，保持连接、切换和目录入口可用。覆盖 1440×900、834×1194、390×844 和 320px 窄屏。

顶部细栏是原型评审工具，明确标识示例数据并切换首次连接、发现中、空结果、部分失败、连接失效、无权限和公开原型场景；该工具不进入产品。连接／替换／移除、仓库切换、阅读、分享与公开预览均在内存模拟，不接收真实凭据，不访问后端。

## token-workspaces 方案原型

延续现有外壳、字阶与间距，登录表单使用可选显示名称和 token。当前只有 GitHub 适配器，平台实例以静态信息展示；不出现 OAuth 按钮或未实现的平台菜单。原型示例凭据提示只出现在评审环境。

“当前凭据”展示当前身份摘要、复制 token 和该身份的设备会话。浏览器多身份方案在摘要前增加“此浏览器的身份”列表，以显示名称、平台账号和当前标记组织；相同账号的不同 token 用各自显示名称区分，列表不展示 token。页头“添加身份”输入示例 token，已记住的身份直接点选；手机把切换与移除操作重排到每行下方，避免账号信息被按钮挤窄。

移除提供确认弹层，当前身份移除后展示其他身份的选择页；退出设备同时取消该设备记住当前身份的授权。设备用清晰列表标记当前设备，单设备退出和全部退出的语义分别表达。复制自动失败时提供只读示例值供手动选择，关闭弹层清除。所有状态仍只在原型内存中演示。

相同 token 恢复时用简短状态反馈继续阅读；不同 token 进入独立的仓库发现空态。切换失败保持原凭据，失效页提供重试和切换。继续检查 1440×900、834×1194、390×844 和 320px。

## clarification-detail 方案原型

复用当前 640px 详情抽屉与移动端边距，在概览的目标与材料下添加澄清问答。按 Q 编号排列，问题与最终回答上下呈现，以细线分隔；未答显示“未回答”，撤回保留内容并轻标“已撤回”，无记录隐藏。正文 13px，保留换行并折断长链接。原型仅演示概览，顶部场景栏不进入产品。

## change-integration 方案原型

延续详情抽屉，增加“合入变更”页签。桌面该页签宽度最多 1040px，文件列表与统一 diff 并排；其他页签保持原宽度。1000px 以下在文件列表与正文间切换，保留返回入口，代码区域独立横向滚动。提交摘要固定在内容顶部，文件路径可换行；新增和删除同时用浅绿/浅红背景、正负号与新旧行号表达。展示归档移动、二进制、超限和关联异常；顶部场景栏属于原型评审工具。沿用三种设备及 320px 检查，尚待用户验收。
