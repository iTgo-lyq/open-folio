# OpenFolio 设计规范

本包维护七组 `quiet-*` 现行原型，覆盖工作台、阅读、账号和匿名分享。设计依据与验收要求见[前端样式与交互重构](../../docs/project/changes/frontend-style-interaction-refactor/requirement.md)。历史设计可从 Git 和所属 Change 的固定版本读取，不再作为当前入口维护。

### 覆盖与能力依据

产品依据为协作分支 `develop@9de1e5a`：账号密码登录与账号绑定 Token（`centralized-accounts`）、Change 类型标签与紧急程度、按创建时间排序、交付标签与 PR（`pr-release-delivery`）均已集成；Change 分享按 `change-sharing` 已确认的“仓库 + Change 直接链接”设计。七组入口：我的仓库与侧栏、Specs 阅读、Changes 列表与详情、原型总览与画布、账号与 Token、匿名公开原型、Change 分享阅读。不提供搜索、快速跳转或收藏（需求 Q5）。

### 产品取舍

以用户最常问的问题组织界面：“哪个仓库可以读”“这份能力现在是什么”“哪些 Change 需要处理”“设计长什么样”。

- **去重**：侧栏展开时顶栏不再显示仓库；身份只在侧栏底部账号菜单出现一次；页面去掉眉标、口号与说明性脚注，标题旁只放真实数量。
- **控件克制**：Changes 只保留一行工具栏——范围分段（进行中 / 已完成 / 已取消）、“筛选”（类型、紧急程度、创建者）、“显示”（列表 / 看板、分组、排序）。阶段与等待筛选由默认分组“等待确认 / 受阻 / 推进中”替代；规模、关联能力、任务状态筛选、任务粒度与全局依赖图移除。已完成按“待发布 / 已发布 / 交付待核实”分组。来源异常有记录时才以提示条出现。仓库页去掉状态页签，需要处理的仓库单独成组；原型页只保留“预览设备”分段。
- **信息外露**：Change 行直接显示类型标签、紧急/高旗标、等待原因或受阻任务、PR 草稿/待集成、任务进度、创建者与创建时间（创建者需后端配合，取首次提交作者）。Specs 文末列出相关 Change，原型卡片显示关联 Change 与公开状态（均由已加载的数据组合）。
- **阅读优先**：Change 详情从 640px 抽屉改为完整阅读页，与 Change 分享页共用“材料目录 + 正文 + 本页目录”布局；未产生的材料置灰并标“未产生”，缺失文件单独提示。

### 壳层与侧栏

- 窗口底色承载侧栏，内容面为圆角 14px 的白色文档表面，距窗口 8px。侧栏展开宽 244px：Logo、我的仓库、当前仓库切换器及其 Specs / Changes / 原型、底部账号按钮。选中项为中性底色配加深的文字与图标。
- **点击 Logo 收起**：侧栏过渡到 72px 窄轨（260ms），Logo 保持原位；我的仓库、Specs、Changes、原型四个图标组成垂直居中的悬浮胶囊，账号头像在底部。胶囊为 52px 宽、26px 圆角，自上而下由 92% 到 60% 的半透明渐变表面配 0.5px 内描边、顶部内高光、底部暗边与两层悬浮投影（背后没有内容可模糊，靠层次表现质感）；按钮 42px 圆形，当前项为实底圆片与陶土图标，悬停为轻微底色，提示在右侧显示名称。再次点击 Logo 或 ⌘\ / Ctrl+\ 展开。收起后顶栏出现紧凑的仓库切换。平板默认收起，手机改为同一材质的底部胶囊导航。
- 顶栏 52px（手机 50px），是浮在内容面顶部的玻璃层（70% 内容面色 + 模糊）：列表、正文、目录各滚动区从顶栏下方开始，滚动时内容从顶栏下经过并被模糊，滚动后出现细分隔。公开原型页与 Change 分享页的页头同样处理；右侧为页面操作与一个“同步状态”按钮（已同步 / 正在读取 / 离线 / 同步失败 / 无权限 / Token 失效），弹层内显示来源、提交与刷新。主题移入账号菜单。
- 收起态 Changes 图标右上角使用陶土色数量角标，表示当前仓库进行中的 Change 总数。0 隐藏、超过 99 显示 99+；辅助说明读出完整数量，不改变图标链接的名称与点击范围。

### 视觉取值

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 窗口 / 侧栏 | `#f1f1ee` | `#131313`（手机 `#000`） |
| 内容面 | `#ffffff` | `#1c1c1e`（手机 `#000`） |
| 次级面 / 填充 | `#f8f8f6` / `#efefec` | `#19191b` / `#2a2a2d` |
| 正文 / 次要 / 辅助 | `#1d1d1b` / `#55554f` / `#85857e` | `#ececea` / `#ababa5` / `#8a8a84` |
| 强调：主操作、选中图标与文字、链接、开关、进度、焦点（陶土） | `#a8502c`，文字 / 悬停 `#94451f`，选中底 10% 陶土 | `#e8926b`，文字 / 悬停 `#f1a886`，其上文字 `#23130b` |
| 已同步 / 已发布、等待确认 / 提醒、受阻 / 错误 | `#1c6f4a` / `#9a5c06` / `#c4372c` | `#5ccb94` / `#e7ad4c` / `#ff7b6e` |

框架为墨色与中性灰，陶土只少量用于主按钮、当前导航与选中图标、正文链接、开关、进度、当前阶段和焦点；导航选中底仍为中性灰。其余彩色只表达状态，“推进中”、待集成、待发布、PR 待合入等常态用中性标签，状态同时配文字或图标。人员头像与仓库字标是真实头像的占位，统一降为约 26% 饱和度，不与状态色竞争。文档插图沿用内容自身的配色（区域图为灰绿与琥珀）。评审栏可切换墨色（浅 `#1d1d1b` / 深 `#ececea`）与上一版蓝色（`#2c6ce0` / `#6f9cff`）作对照：墨色与蓝色只替换强调色，标志及网站图标统一使用新版矢量；对照不进入产品设置。对比度检查覆盖三种强调色 × 两套主题：主按钮文字、链接与选中文字、选中底上的文字及三种状态标签不低于 4.5:1，焦点框对内容面和窗口底不低于 3:1。

**标志**：保留现有 OpenFolio 造型，按 `public/brand/openfolio-mark-deep-blue.png` 的几何描为平面矢量 [`src/assets/openfolio-mark.svg`](src/assets/openfolio-mark.svg)，无渐变与高光；外框为当前文字色（墨色，深色模式反白），内侧面板为同色 42% 不透明度，不随陶土强调色着色。侧栏 24px 配 15px 字标，手机顶栏与公开/分享页页头 22px，登录卡片 34px。网站图标与应用图标为 [`src/assets/openfolio-icon.svg`](src/assets/openfolio-icon.svg)：64 网格、14.5 圆角的浅色方底 `#f7f7f4`，带 12% 墨色细边，标志占 75%；浅色与深色标签栏都使用同一方底。七个原型入口通过 data URL 内联同一 SVG favicon；未声明图标的新入口在构建时自动补齐同一图标。正式产品也使用这一版标志与应用图标。

分隔与边界使用 8–14% 透明度的 0.5px 线，悬停 / 选中 / 按下为 4.5% / 6.5% / 8.5% 的中性叠加。语义色都配文字或图标。材质（半透明 + `blur(24px) saturate(1.8)` + 内高光）用于顶栏与公开页页头、收起胶囊、手机导航、菜单与弹层（60% 不透明度）、提示和抽屉外层；抽屉内的阅读区是带 0.5px 边界的 12px 圆角实底卡片，正文、表格、表单与确认对话框为实底。目标浏览器默认支持 `backdrop-filter`，不提供减少透明度或不支持模糊时的实底降级；减少动态效果关闭全部动画与过渡。

字体为系统 UI 与中文回退（PingFang SC、Microsoft YaHei、Noto Sans CJK SC），代码使用系统等宽。界面 13.5px；页面标题 26px/680（手机 24px）；正文 15.5px、行高 1.85，可在阅读设置中切换为 17.5px；文档标题 30px/700，二级标题 19.5px/650。圆角随尺寸递增：标签 6px、按钮与输入 8–9px、菜单项 7px、卡片与弹层 12px、内容面 14px、对话框 16px、胶囊全圆。示例应用（Atlas）在画布与缩略图内使用自己的品牌色和背景，与工作台主题无关。

### 组件与状态

Specs 与 Change 材料目录统一使用 13px / 1.5 的条目文字、最小 34px 行高、上下各 7px 留白、8px 图文间距与 550 选中字重；树形层级保留独立缩进，长标题允许换行。目录展开/收起沿用 Lucide 图标，线宽为 1.5。

Specs 悬浮高亮与选中态覆盖相同整行区域，包括缩进和展开箭头；悬浮使用较淡的 hover 色阶，选中保持 selected 色阶。

按钮（默认、幽灵、主要、危险）、图标按钮、分段控件、开关、标签、头像、仓库字标、输入框、菜单（单选 / 多选 / 普通项）、弹层、对话框、右侧与底部面板、提示与骨架屏共享同一节奏。菜单与分段支持方向键，弹层与对话框 Escape 关闭并回到触发控件；从详情返回列表时焦点回到原行。任务状态以图标 + 文字表达，不使用复选框。空态说明原因与下一步；离线保留已显示内容，失权清除私有内容，登录过期回到登录页。

### 数据与验证

全部使用虚构仓库（Atlas 旅行应用等）、人员、文档与凭据，状态只在内存中；评审工具位于顶部细条，可切换页面、场景、主题，“评审设置”内可切换强调色、预览网站图标并演示减少动态效果，不属于产品。`verify-quiet-workbench.mjs` 在仅授予 `allow-scripts` 的 iframe 与项目 CSP 下检查七个入口 × 两套主题 × 1440 / 834 / 390 / 320 四档宽度的溢出，并覆盖侧栏收起、键盘、筛选、详情、分享、画布、账号、登录、强调色切换、标志、玻璃顶栏与抽屉材质、对比度及各状态。

### Changes 动态视图（change-focus-and-archive）

本次 `quiet-changes` 保留 Changes 单行工具栏与分段页签样式，详见 [技术方案](../../docs/project/changes/change-focus-and-archive/technical.md)。仅参考用户截图的交互，加入视图切换、右侧齿轮及带取消/确认的管理弹层；固定状态快捷入口在前，个人视图（含默认“我的”）在右侧按保存顺序展示，初始仍选中“我的”，已发布单列已归档，取消零数量隐藏。状态可作为个人视图的多选条件。页签复用现有 `.seg` 紧凑圆角样式；筛选与显示仍在工具栏右侧，额外条件标签在下方，系统默认视图自带条件不重复展示或计入筛选角标，无额外条件时省略整行；筛选和编辑面板仍展示完整条件。手机使用现有图标按钮。沿用上述颜色、字号、间距与圆角，不照搬截图外观。

管理器宽 440px、窄屏两侧留 12px，长表单内部滚动，底部操作可见。行内显隐/编辑/删除，左侧排序柄；通过拖拽排序，不展示上下移动按钮、不为其预留行底部空白；触屏可从拖拽柄拖动，柄上的键盘操作继续保留。已保存配置、列表临时查询与管理草稿独立，明确未保存反馈。

2026-10-23 查询 shadcnuikit `dashboard-dropdown10`：参考其显隐、拖拽柄、键盘排序及弹层层级；目录模板的列管理结构不直接符合用户的视图编辑与取消/确认需求，也不适用于项目的自包含 HTML 原型，继续复用现有原型控件，不安装 React/Tailwind/dnd-kit。用户截图仅作为交互参考，视觉依据为现有 OpenFolio 组件和主题。

本 Change 的整页原型仅为 tab/视图管理提供上下文。正式实现只改该区域及必要联动，其他区域以现有产品为准，不将整页原型当作整体改版要求。
