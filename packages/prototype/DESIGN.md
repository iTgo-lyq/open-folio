# OpenFolio 页面片段

原型呈现当前业务组件，不维护第二套工作台设计。界面依据是 [`src/components`](../../src/components) 的布局与 CSS Modules、[`@open-folio/ui`](../ui/README.md) 的基础组件和 token，以及业务全局样式。旧七组手写设计保留在 Git 历史和所属 Change 的固定预览中。

## 复用规则

- 沿用业务组件的系统字体、明暗主题、中性表面、陶土强调色、响应式断点、键盘和焦点行为。不要为了原型覆盖业务布局、复制组件 CSS 或添加预览专用 props。
- `src/fragment.css` 只控制评审栏和片段容器，不定义第二套按钮、表单、阅读器或工作台样式。
- 七个 `quiet-*` 是业务片段入口：仓库与侧栏、Specs 阅读、Changes 列表与材料、原型总览与画布、账号与 Token、匿名公开画布、Change 分享阅读。基础组件仍在 UI 包预览，不进入本清单。
- 入口可组合壳层与相应片段，不组合成带路由、后端和真实登录的应用。点击其他模块只提示另开对应入口。

## 数据与状态

虚构仓库 `demo/atlas`、`demo/notes`，虚构账号 `demo-lin`，密码 `demo12345`，Token `demo` 或 `demo-work`。不要录入真实信息。主题、目录折叠、阅读偏好、视图、账号和表单操作均只在本页内存运行；切换场景或刷新重置。

评审栏显示适用场景：正常、空态、加载、请求失败、登录/注册或不存在/已撤回。业务组件保留真实交互和错误提示；请求与资源由包内 mock 接管。

原型/公开画布直接复用业务组件的设备选择、旋转、缩放与详情。画布内部本应加载外部产物，但截图 CSP 禁止子 iframe，所以 `PrototypeFrame` 资源边界用包内轻量交互占位替代，明确显示“资源边界 mock”；它不代表真实 Atlas 产品设计，也不验证跨域 iframe 和托管握手。Change 分享复用 PublicShell 与 ChangeReading，不运行分享解析/认证 provider。

## 验证

`npm run verify --workspace prototype` 检查七入口 × 两套主题 × 1440/834/390/320 四档宽度，覆盖主要局部交互和场景，检测异常、外部请求及持久存储访问。正式卡片截图沿用 `screenshot` 命令与声明设备；只有实际发布后才更新固定引用。
