# 交付计划

按编号顺序推进，基于 [需求](./requirement.md) 和 [技术方案](./technical.md)。

## T1：延续关系登记与折叠阅读

交付可选关系字段、创建与 active 修改命令、关系解析和工作台折叠列表及详情上下文，更新 skill 使用约定。验收覆盖合法登记、无效关系降级、多跳与分叉、独立依赖和状态、筛选及无障碍。运行命令与分组单元测试、既有 Change 回归、类型检查、浏览器交互和生产构建。

## T2：关联既有交付并完成验收验证

按明确授权，仅补两个指定归档 Change 之间的延续关系，核对既有正文和完成事实完全保留；以独立提交记录迁移。完成独立评审与整体验证，提供实际页面和迁移证据供人工验收。验收后同步 Specs、归档并集成 develop，更新长期服务并冒烟验证。

## T3：简化分组展示并修正列表间距

按用户实际页面反馈，将分组改为标题加外框，原记录始终可见，移除展开状态、额外文案及组级操作。修正外框底部间距与末行重复边框；复验筛选、独立详情、键盘、窄屏和相邻普通记录，独立复审后更新开发服务供验收。
