## T9：真实首屏截图与缓存

按用户本轮反馈，为总览卡片增加服务端按需截图。页面与原有预览共用设备尺寸，组件按固定视口；筛选设备、切换来源及打开预览保持一致。卡片可视时加载、按比例展示，等待/失败/重试与预览操作独立，不向 Git 或 Change 新增图片字段。

截图复用固定 Git 读取及校验，在 OS 沙箱 Chromium 的空白上下文中离线渲染；仅由路由拦截返回已校验 HTML，保留响应头 CSP，禁止额外请求和 WebSocket，进程不携带宿主凭据环境。使用可强制终止的独立 BrowserServer，将启动和页面执行纳入总时限。实测 Playwright 的 serviceWorkers:block 注入脚本与 opaque origin 不兼容，改由既有 CSP 的 opaque origin 和 worker-src:none 禁止 worker，没有放宽同源或资源访问权限。

缓存按项目/仓库、HTML 内容、尺寸及渲染器版本隔离，同键合并、并发/队列/时限有界，私有磁盘原子写入并按容量/闲置时间回收。内容不变时无关 Git 文档提交和重启都可复用；当前校验在缓存前以及生成结束后执行，304 也不绕过检查。截图浏览器和安装要求已加入运行说明。
