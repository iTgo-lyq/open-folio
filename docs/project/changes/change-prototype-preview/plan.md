# Change 原型预览实施计划

## 交付目标

落实 [Requirement](./requirement.md) 与 [Technical](./technical.md)：一个项目维护一个原型包，由 SpecTrail prototype 子 skill 接入；Change 关联自包含 HTML，工作台在同域沙箱中按声明尺寸展示，并保留归档版本。

## 执行顺序

| 任务 | 前置任务 |
| ---- | -------- |
| T1   | 无       |
| T2   | T1       |
| T3   | T2       |
| T4   | T3       |
| T5   | T4       |
| T6   | T5       |

## 任务

### T1：统一原型关联与项目配置校验

交付项目选择状态、页面/组件关联与视口约定，主 skill、无依赖 hook 和工作台解析保持一致。hook 按暂存内容检查关联路径；非法原型字段不能隐藏 Change 核心内容，旧文档保持兼容。

验收覆盖 A1、A3、A9。用临时仓库及共享正反例验证拒绝/启用、两种视口模式、路径与 symlink、未暂存入口、删除或保留旧关联及解析降级。

### T2：交付原型子 skill 与本地交付工具

交付子 skill、幂等接入、基础原型包、离线交付检查和归档保留引用工具；继承已有设计规范，拒绝选择持久化，初始化失败不启用，不覆盖用户文件。

验收覆盖 A1、A2、A5、A6。临时 Git 仓库验证接入/拒绝/重试、现有包和 workspace、构建检查、标签冲突与推送；按 skill-creator 校验 skill 并做真实操作验证。

### T3：读取固定 Git 原型并提供同域隔离预览

交付基线开关、归档引用采集、固定提交解析、受限 HTML 读取及受保护路由；缺失与超限有明确诊断，缓存不绕过当前开关或引用可达性。

验收覆盖 A5、A6、A7、A8。真实临时远端仓库验证历史回看、删除分支/标签、冷缓存、非法 revision/path、项目切换与资源限额；浏览器验证 CSP 与工作台 API 隔离。

### T4：在 Change 详情浏览页面与组件

交付原型标签、入口和设备切换、横竖方向、组件固定尺寸、100%/适应画布、固定版本深链接及可读错误。保留现有页面结构与键盘操作。

验收覆盖 A3、A4、A7。浏览器测量实际 iframe 尺寸，验证缩放与布局互不混淆、链接恢复、状态切换和已知异常；不要求截图产物。

### T5：完成真实原型接入与整体验证

在当前项目接入单一原型包，关联真实可查看的多个入口，构建并推送，启动更新后的工作台供用户验收。补充运行和导出说明，保留现有 Spec/Change 阅读能力。

验收覆盖 A1–A9。执行核心、hook/子 skill、浏览器测试与类型/格式/生产构建；核对已推送真实分支及现有私有入口，同域认证和预览输出一致。

### T6：完成独立评审与交付复验

由隔离上下文 reviewer 评审最终差异并做子 skill 的行为验证，记录可行动问题及复验。重点覆盖契约一致性、历史引用、访问边界和状态误判；修复后按影响范围复验。

## 整体验证

对照 Requirement A1–A9 汇总证据到 Execution，独立评审到 Review。所有交付推送并验证后进入 close，保留 active 并等待用户验收，不提前归档、同步已实现 Specs 或合入守护分支。
