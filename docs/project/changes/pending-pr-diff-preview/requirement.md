# 在工作台预览待合入 PR 的文件差异

当前 Change 已关联 PR 时，用户可以从概览打开 PR，但「合入变更」页要等系统定位到正式合并提交才显示文件列表和 diff。登录工作台的仓库读者需要在原页提前审阅本次 Change 的差异，并在合入后继续从该页查看实际交付。

## 范围与行为

- 有唯一关联的开放 Change PR 时，在「合入变更」页显示 PR 编号、链接、待合入或 Draft 状态、文件列表和逐文件 diff。PR 推送新提交后，工作台刷新时显示更新的差异。
- PR 合入且系统定位到有效合并提交后，工作台刷新时自动显示正式合入差异，无需另选页面。
- 没有可预览的关联 PR 时显示现有空态。多个开放候选或预览读取失败时在页内说明原因；已合入而正式差异不可用时显示相应的合入诊断。
- 未合入代码的文件列表和 diff 限定在当前用户具备仓库读取权限的登录工作台。

## 验收

1. 在同一 Change 的「合入变更」页打开 Draft 或开放 PR 的预览，能通过文件列表逐个审阅其差异并打开 PR。PR 新增提交后刷新，文件清单和正文对应更新后的 PR。
2. PR 合入并刷新工作台后，同一入口自动显示合并提交对应的正式文件清单与 diff。
3. 无关联 PR、多个候选和差异读取失败各有相应提示。公开分享请求无法取得未合入的文件清单或 diff。
