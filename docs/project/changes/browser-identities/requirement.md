# 浏览器记住多个身份并点选切换

## 背景与目标

当前一个 token 对应一套独立工作台，浏览器设备会话只绑定其中一套。切换凭据会撤销当前设备旧会话，再创建新会话；服务端保留旧工作台，但再次切回必须重新输入 token。

用户已确认启动方向：当前浏览器记住多个已登录身份，支持添加、点选切换和单独移除；token 加密保存在服务端，各工作台继续隔离，切换失败保留当前身份，授权过期后重新输入 token。

本 Change 为 medium：需要改变持久化设备授权与当前身份的关系，并联动会话存储、API 和界面。已有 token 工作台标识与缓存归属继续使用，不合并同账号的不同 token。

## 范围与行为变化

### 添加与恢复身份

- ADDED：当前浏览器可记住多套已成功验证的身份。首次添加输入 token，可填写显示名称；添加成功后进入该身份，之前已记住的身份仍可点选切回。相同 token 不产生重复列表项。
- ADDED：身份列表展示显示名称、平台账号及当前身份标记。同一账号的不同 token 仍为独立身份，沿用各自的显示名称和工作台。
- MODIFIED：刷新页面、重开浏览器与服务重启后，有效的浏览器授权可恢复身份列表和当前身份。升级前已经登录的浏览器兼容恢复当前身份，不要求为本次升级重新输入 token。
- 保留当前 GitHub.com 平台支持范围。身份列表仅含该浏览器亲自登录过的身份，不提供其他浏览器或全服务的凭据目录。

### 点选切换

- ADDED：点选已记住且授权有效的身份，无需输入 token。切换时使用目标工作台的 token 验证平台身份；成功后再切换当前读取上下文，失败保留原身份。
- MODIFIED：一个浏览器仍只有一个当前身份，同一浏览器配置下的标签页共享该身份。切换成功后清除旧正文、仓库列表、错误和临时复制内容，旧请求不能把原身份内容重新显示出来；其他浏览器、其他设备的登录不受影响。
- 保留同 token 工作台共享、不同 token 的仓库发现、快照缓存和偏好隔离。重新选回原身份恢复其已保存工作台，不复制另一个身份的数据；既有显式阅读链接继续优先，并按新身份检查权限。
- 授权过期、被撤销或 token 已失效时不能直接切入，提示重新登录。临时网络故障或限流不清除已记住的身份，也不改变当前身份。

### 移除、退出与设备撤销

- ADDED：可单独从本浏览器移除已记住的身份。移除非当前身份不打断当前阅读；移除当前身份或退出当前设备后回到身份选择／登录界面，其他有效身份仍可点选登录。
- MODIFIED：退出当前设备、撤销单台设备和退出当前凭据的全部设备，同时撤销对应的记住授权，不能靠点选列表重新获得已退出的登录。即使目标身份暂非浏览器当前身份，设备撤销仍对该身份生效。
- 保留工作台凭据和已提交缓存；移除身份只取消本浏览器的登录授权，不删除其他设备登录或工作台数据。再次输入相同有效 token 可恢复原工作台。

## 约束与边界

- token 仍加密存储于服务端，不写入 URL、localStorage 或 sessionStorage。浏览器用 HttpOnly Cookie 持有不可读的登录凭证，普通身份列表和响应不含 token；主动复制仍只能复制当前身份的 token。
- 只能切换、移除当前浏览器授权的身份，知道其他工作台 ID 不构成授权。所有写请求沿用同源和 HTTPS 校验。
- 浏览器授权有期限，沿用 30 天闲置与 90 天绝对期限。切换不能绕过期限或已发生的设备撤销。清除本站 Cookie 后，需重新输入各身份 token；不会凭账号名恢复完整历史身份列表。
- 兼容已有状态、设备会话、加密密钥与缓存；不重置当前数据目录。服务更新按仓库开发机约定停止、构建、启动并验证。
- 本次不新增 OAuth、统一用户账号体系或跨浏览器同步身份列表。工程记录仍由各身份自己的 token 只读访问。

## 验收标准

1. 同浏览器添加 A、B 后，A → B → A 均可点选完成，切回不提交 token；重复添加 A 不生成重复项。同账号不同 token 仍有独立工作台。
2. 刷新、浏览器重开和服务重启恢复有效列表及当前身份；旧单身份登录在升级后保持有效。清除 Cookie 后无法取回先前列表，输入相同 token 仍恢复原工作台。
3. 切换恢复目标身份的仓库、缓存和偏好，不显示旧身份的正文或临时 token；延迟到达的旧读取和会话响应不能恢复旧上下文。同浏览器标签页重新同步身份，其他设备仍保持原登录。
4. 验证目标 token 失败、网络故障或限流不改变当前登录；过期或被撤销的授权不能切入。未经本浏览器登录的工作台 ID 不能用于切换、读取或移除。
5. 移除非当前身份不影响当前阅读；移除／退出当前身份后仍可点选其他有效身份。单设备和全设备撤销均阻止通过身份列表恢复被撤销的登录，不删除其他身份或已提交工作台数据。
6. 身份摘要、浏览器持久存储、URL 和普通响应不包含 token；主动复制只返回当前身份凭据。桌面与窄屏可完成添加、切换和移除，键盘操作可达，现有复制和设备管理流程仍可用。
