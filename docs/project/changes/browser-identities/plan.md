# 浏览器多身份实施计划

交付[需求](./requirement.md)与[技术方案](./technical.md)定义的浏览器身份集合。默认按 T1 → T2 → T3 串行，任务包含所属实现、测试与执行证据；原型在技术阶段先行评审，不提前修改正式服务。

## T1 记住身份并安全点选切换

交付浏览器集合、独立身份授权、当前选择代次、添加与点选接口及身份列表界面。旧登录失效，保留原 token 工作台；同 token 去重，同账号不同 token 隔离，切换先验证后提交。接通前端请求代次与标签页同步，保留当前复制和只读工作台流程。

验收：同浏览器添加 A、B 并点选 A → B → A，不再次发送 token；刷新与服务重启恢复新登录；旧 Cookie 不恢复，但相同 token 保留原缓存与偏好。失败切换保留原身份，跨浏览器目标不能切入，期限不因切换重置，晚到响应不能恢复旧上下文。

验证：会话、凭据 API、偏好、仓库和发现的适用单元／集成测试；浏览器 token 工作台与凭据回归，补充跨标签页和延迟响应；类型与相关文件格式检查。调整浏览器测试代理分发以支持新身份路由，所有模拟仍使用隔离 fixture。

## T2 移除身份并统一设备撤销

交付身份移除和选择页，将退出当前、撤销单设备与退出当前凭据全部设备统一为授权撤销。未选中的授权也能被所属工作台的其他设备撤销；移除非当前身份保留当前阅读，当前身份退出后可选择其他身份。覆盖过期清理、持久化关系校验和离线密钥轮换对新状态的保留。

验收：移除／退出后的身份不能靠集合恢复；其他身份、其他浏览器和工作台数据按授权范围保留。单设备退出不中止其他设备的共享任务，全设备退出停止该工作台任务。四种宽度与键盘可完成全部主流程。

验证：撤销与切换竞态、非当前身份撤销、全设备退出、闲置／绝对到期、缓存归属和密钥轮换测试；浏览器移除、退出、复制及窄屏回归。独立评审发现的并发交付和恢复边界由追加 T3 修复，完成后执行整体验证及开发机更新。

## T3 补齐并发交付与分页恢复边界

对照独立评审 R1–R4，补齐最后一个身份退出时的延迟登录复核、登录 Cookie 与仓库／发现／准备原型响应交付前的原选择复核，以及无 BroadcastChannel 时 A → B → A 的分页恢复。保持已确认目标与接口使用方式，修正已交付 T1 的边界，不改写其完成记录。

验收：最后一个身份退出后，已在途的登录不能重建集合或写回 Cookie；切换后不能交付原身份的仓库、发现或原型准备响应；相同身份选择代次变化后从仓库第一页重新读取。

验证：确定性会话／HTTP 竞态测试、无 BroadcastChannel 的分页浏览器回归，复核 R1–R4。通过整体验证与独立复验后生产构建，按仓库约定更新开发机服务并记录真实冒烟。

## 整体验证与交付

对照需求六项验收记录自动检查与真实服务证据，包含普通响应不含 token、Cookie 丢失需要重新添加、旧登录失效、数据未删除。正式构建前停止使用 `.next` 的服务，构建成功后启动；不为验证建立额外生产产物目录或例行备份。

medium 的独立评审使用与实现上下文隔离的评审 Agent，覆盖完整差异、需求对应、测试结果与遗漏。问题修复后再提供人工验收；验收通过后同步个人访问与分享／项目知识 Specs、归档并推送。合入守护分支或 PR 沿用后续明确选择，不由技术确认推导。
