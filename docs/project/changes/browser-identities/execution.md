# 实施与验证证据

## T1 记住身份并安全点选切换

新增浏览器集合和身份授权，外层状态版本 3 保留原加密工作台但不恢复旧登录。接通添加、点选切换、当前读取选择代次、身份列表和 BroadcastChannel 同步；切换不更换 Cookie，重复 token 替换本浏览器授权且不重复建工作台。当前设备退出的 Cookie 响应同时改为不写 Cookie，便于保留其他已记住身份和避免延迟响应覆盖登录。

验证结果：

- `npm test`：154 项通过，包含 8 项新增身份存储／API 测试；覆盖同账号不同 token、重启和偏好恢复、A → B → A 旧 lease、验证失败、切换／退出及添加竞态、跨浏览器目标、旧 revision 复制拒绝、独立期限和旧 Cookie 拒绝但保留工作台。
- 会话、凭据 API 与偏好集中检查 20 项通过；仓库、发现与权限集中检查 20 项通过，与全量单元结果一致。
- 浏览器个人登录与复制流程通过；一次退出断言仍按旧行为期望登录页，修订为有其他身份时显示选择页、无其他身份时显示登录页。随后 token-workspaces 与新增 browser-identities 集中回归 10 项通过，含四种宽度、延迟正文／偏好／会话响应、无 token 提交的点选切回及第二标签页同步。
- `npm run typecheck`、`npm run format:check` 通过。生产构建和开发机更新在 T2 集成全部移除与撤销行为后执行。

## T2 移除身份并统一设备撤销

新增所属身份移除接口与确认弹层，当前身份移除后可选择其余身份；非当前移除不改变选择代次或停止当前读取。单设备和全设备撤销统一删除身份授权，包含尚未选中的授权；工作台、偏好、缓存以及其他身份按范围保留。

- 集中身份测试 15 项通过，新增非当前／当前移除、其他设备撤销未选中授权、选择指针清理、损坏归属拒绝、双身份密钥轮换和每浏览器身份上限。
- `npm test` 全量 161 项通过；完整浏览器回归 76 项通过，包含四种宽度的移除、取消焦点、退出后选择其他身份、目标 token 失效和平台不可达保持原身份。
- 类型检查和格式检查通过。独立评审发现 R1–R3；追加 T3 修复并复验这些边界，整体验证和服务更新在 T3 集成后执行。

### 真实凭据与数据冒烟

在最终独立实例使用忽略配置中的一个真实 token、两个隔离浏览器授权，以下检查通过，普通日志未包含 token、Cookie 或密钥：

- 真实登录的安全摘要和 HttpOnly／SameSite Cookie；重复添加相同 token 保持单项与原工作台 UUID；无效 token 添加返回 401，当前身份保留。
- 点选已保存授权只发送 identityId；主动复制返回当前 token，其他响应不包含 token。
- 同 token 的两个浏览器共享工作台，撤销第二浏览器后无法恢复授权，第一浏览器仍有效。
- 真实仓库发现、刷新与工作台读取通过；生产窄屏“当前凭据”可用，无横向溢出，URL、localStorage、sessionStorage 不包含 token。
- 通过正式管理脚本停止和启动服务后，同 Cookie 恢复当前身份与列表。
- 移除身份后工作台数组保持原内容，重新输入 token 恢复原 UUID；没有 Cookie 的浏览器看不到先前列表。仅清理本次测试授权，保留验证工作台与缓存；状态和凭据密钥权限均为 0600。
- 模拟新链接的 HTTPS 代理 Host 与 forwarded-proto，真实登录返回 Secure／HttpOnly Cookie，同源复制通过，其他 Origin 返回 403。最初模拟使用 fetch 时自定义 Host 未保留，改用原生 HTTP 请求后通过；应用实现未变。

两个不同的真实 token 未配置；同账号不同 token 的双身份切换、偏好／缓存隔离、失败切换、期限、旧版本登录拒绝及旧工作台保留由单元与完整浏览器 fixture 覆盖。真实读取的第一次临时冒烟未正确准备工作台快照，并以 snapshotId 检查 Workbench；修正为显式刷新后检查 id，临时和最终实例均通过。
