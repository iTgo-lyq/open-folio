# Change 短链保留分享时的阅读位置

用户指出：「比如用户正在看执行记录，我希望分享出去后也是这个页面。」现有短链只记录仓库、集成分支和 Change，分享弹层未传递材料与章节。作为 durable-change-share-links 的后续修复，按用户明确的当前页面分享方向补齐，不另改界面或绘制原型。

## 范围与方案

- 分享弹层读取当前 Change 的材料、相对文档路径、章节、原文、图片、原型设备及合入文件位置，只保存既有公开阅读允许的定位参数；不保存个人视图、账号、连接、Token 或快照。
- 定位参数和目标一起存入不可变短链映射。相同目标与阅读位置复用标识，不同位置使用不同标识；复制后的地址保持简短，后续切换材料不改写已经分享的记录。
- 接收者直接打开短链时恢复保存的位置；之后仍可切换材料、刷新和前进返回，地址中显式阅读参数覆盖初始位置，避免旧章节或文档串到新材料。
- 文本文档的 Agent 链接默认读取对应单篇，显式 document 参数仍可读取同 Change 的其他单篇；非文档页面继续返回 Change 上下文并保留网页入口位置。
- 既有无阅读位置的短链继续读取 Change 默认页面，不修改历史记录；新增字段可选，无不兼容迁移，持续使用现有来源、权限和快照检查。

本次为 small：局部补齐分享定位的传递和默认恢复，复用既有短链存储、读取与公开参数边界，不改布局或鉴权流程。

## 验收

- 从执行记录和其他材料分享，接收者落在对应材料；章节、额外文档及原型位置均能恢复，复制出的短链无长查询串。
- 同位置重复分享复用地址，切换位置后分享得到新地址，先前地址不被覆盖；存储重新读取后定位仍在。
- 阅读切换、章节导航、刷新和前进返回不把保存的旧材料位置带到新材料；Agent 文档默认与分享时所读单篇一致。
- 新旧短链均可读，越界文档、身份参数及目标改写仍被拒绝；针对性服务端、浏览器、类型和生产构建验证通过。
