# 按模块评估 Change 配图需要

## 目标与方案

用户要求从中型 Change 开始，涉及数据结构、时序流程等明显变化时建议增加图表；措辞精简，按本次变更的模块分别评估，差异较大的模块分别说明，不能以整份文档已有一张图视为充分。

本次为 small：仅完善 SpecTrail 的文档配图指导与对应规范。在现有配图段落明确 medium 及以上的适用条件、逐模块判断和分别说明原则；图型、数量按实际说明需要选择，简单内容不强制配图，small 按需。沿用图片存放与引用约定，不增加审批或校验脚本。

## 验收

- 明确 medium 及以上、数据结构与时序流程等明显变化的配图建议。
- 按本次变更的模块分别评估；差异较大的模块分别说明，不以已有配图代替判断。
- 表达精简，不规定固定图型、数量或新增审批；简单内容保留选择空间。
- skill 校验、差异审阅通过，对应 Spec 与规则一致。
