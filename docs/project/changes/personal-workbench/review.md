# 独立评审与复验

以 main 至个人工作台分支的完整差异及 Requirement／Technical／Plan 为范围，独立评审者在不继承实现会话的 subagent 中只读审查代码、测试和截图；未使用真实凭据。评审包含会话加密、显式 Git 凭据、缓存授权、发现、公开产物、旧部署迁移及分享。以下记录具体问题与修复依据。

## R1 目录在途撤权未在交付前复验

独立 fixture 复现：检查仓库 2 时撤销仓库 1，原实现仍返回仓库 1，unavailable 为 0。列表逐项检查后只核对本地 lease，长目录请求可能交付已经失权的仓库元数据。

修复：返回前再次验证身份及所有保留项的仓库 API／Git 读取能力；单项有超时，全局并发受限，等全部校验结束才释放 lease。地址检查也执行交付前复验。新增 discovery 集成用例在检查后续项时撤销首项，确认首项不再返回且计入不可用。

## R2 地址检查结果依赖目录第一页

21 仓库 fixture 中，检查末页仓库返回 ready，重载第一页后不含目标；弹窗通过第一页 items 决定是否启用“打开仓库”，因此无法直接打开。

修复：使用地址检查返回的稳定 RepositoryIdentity 直接导航，后续读取仍重新验证本人权限。浏览器用例让目录响应不包含已检查目标，验证从弹窗进入仓库并携带稳定 id。

## R3 Git 原型错误诊断桥丢失

旧 Git 路由为 iframe 注入 runtime／CSP reporter，新公开路由原样返回文件，但画布仍监听诊断消息，脚本出错时无法显示原有提示。

修复：准备时把固定诊断桥写入发布 HTML，contentDigest、文件摘要与截图覆盖最终字节。公开读取仍仅返回已发布文件；load 参数只关联当前 iframe，不传递秘密。浏览器在真实 iframe 中触发脚本异常及被 CSP 阻断的 fetch，确认宿主展示对应错误。

## R4 Retry-After 未限制立即重新发现

自查发现发现状态虽记录限流等待时间，用户立即重试仍会再次调用平台。

修复：根据持久化更新时间与 Retry-After，在新的发现请求发出前拒绝过早重试；保留 continuation。测试确认等待期内不增加分页调用，期满后从原 cursor 续传。

## R5 公开预览尺寸与缓存图片状态回归

完整浏览器套件发现：组件分享携带 landscape 时被再次旋转，640×320 变为 320×640；缓存图片的 onLoad 可能先于 effect，随后被错误重置为 loading。另有一个断言仍使用已更新的 main 文案。

修复：公开页按设备自然方向恢复横竖，组件保留声明尺寸并隐藏旋转按钮；图片状态绑定 URL 与重试编号，避免 effect 覆盖已完成的加载事件。回归包含组件固定链接尺寸、跨页面返回后缓存图片 ready、图片重试及默认分支来源标签。

## R6 诊断桥升级与既有公开别名冲突

独立复验构造旧 HTML／manifest／alias 后确认：同一 Git revision 的新诊断桥改变 publicationId，而旧别名已占用，准备抛出 EEXIST。

修复：保留合法旧别名及原始公开字节，允许新渲染版本按新 publicationId 发布；旧版本被撤回时旧链接仍返回 410，新固定版本不重写它。损坏映射继续明确失败。新增升级 fixture 删除新版本后从旧版本重新准备，验证旧字节、旧别名和撤回语义。

## 最终复验

同一独立评审者先复验 R1–R3，再构造 R6 升级样本并复验最终修复；发现及公开产物 13 项测试通过，结论为无剩余阻塞项。主执行者完整单元／集成 119 项、浏览器 54 项通过，类型检查、格式检查及保留既有生产预览的 `.next-verify` 构建通过；临时构建与类型引用已清理。浏览器新增用例实际覆盖当前目录未包含已检查仓库、原型脚本异常和 CSP 阻断；组件尺寸、缓存截图及重试回归通过。整体验证和实际 GitHub 脱敏联调证据见 Execution。

## R7 生产反向代理误拒同源连接

上线检查发现 Next.js 生产 Request URL 使用内部监听地址，旧实现据此匹配 Origin，导致外部 HTTPS 同源连接返回 403。T11 改用实际 HTTP Host 与可信代理协议构造来源；忽略任意 X-Forwarded-Host，并保留跨源、非法 Host 和远程 HTTP 拒绝。运行实例的五组真实 HTTP 请求及新页面核对见 Execution。

T11 由另一名不继承实现会话的独立评审者只读审查，核对 d47dba5 全部差异、README 的代理信任前提与 Next 16.3.7 URL 构造源码，未发现可操作问题。个人会话测试 8 项、额外内存请求矩阵 23 项通过，覆盖本地 IPv4／IPv6、默认与自定义端口、Host 大小写、Fetch Metadata 回退、null Origin、伪造 forwarded-host、远程 HTTP、无 Host 回退和畸形 Host；成功 HTTPS 请求均保持 Secure Cookie。主执行者最终完整单元／集成 120 项、类型、格式及生产构建通过；既有完整浏览器 54 项证据保留，本轮另对实际生产页面与连接表单进行 Chromium 验证。
