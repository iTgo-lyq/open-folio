## T2：实现协作者展示并验证原型还原

列表、看板及归档时间线共用协作者组件，最多三字标加剩余人数、完整名单内部滚动、创建者第一。列开关接通显示菜单、个人视图编辑、保存与重新打开；时间线只显示列设置，仍隐藏不适用的排序/分组选项。按钮位于详情链接之外，点击不导航，Escape/关闭后焦点回到触发控件。

验证：370 项单元测试全部通过，生产构建及类型检查通过。相关浏览器回归 13 项场景全部通过（首轮 12 项通过；时间线一项原先笼统断言“没有任何按钮”，新增协作者按钮后改为仅检查展开/收起按钮，再单独复验通过）。框架以独立临时浏览器隔离 fixture 登录。专项覆盖浅深主题 × 1440/834/390/320px，12 人长名单、滚动到底、真实点击、键盘打开、焦点恢复、不误导航、看板进入详情及列设置保存恢复；无页面错误或窗口横向溢出。
