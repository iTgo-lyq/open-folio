# Change 协作者与默认展示

创建 Change 的人不一定是实际推进的人。列表需要展示参与推进的协作者，避免仅凭创建者判断归属。

用户已确认 Astra subagent 绘制的固定版本原型，并要求继续。正式实现以本 Change previews 中的 `quiet-changes` 固定版本为视觉与交互依据。

## 范围与验收

- 新增协作者列，创建者在成员顺序中排第一，成员去重。
- 视图默认不展示独立的创建者列。
- 列表与看板最多显示三个头像字标，其余用 `+N` 收拢；点击查看完整可滚动名单，展示成员名与可识别的平台用户名。
- 创建者列可在显示菜单恢复，其开关随个人视图保存；既有视图默认隐藏创建者，保留其他设置。
- 手机按原型在行底部展示协作者；桌面、平板、手机和浅深主题下可阅读、可操作，支持键盘打开、关闭和焦点恢复。
- 单人、多人与大量成员均可展示，创建者不因后续编辑、工作分支移交或归档发生变化。
- 历史资料能够识别多少成员就展示多少，不虚构人员或平台身份，不返回作者邮箱。
- 当前“我的”及创建者筛选继续采用现有创建者语义；本次交付聚焦协作者展示。
- 实现后按已确认的固定版本原型检查还原，并由用户验收。

## 数据口径

协作者识别、去重与排序的具体口径见 Technical，随方案和计划一起确认。规模维持 medium：涉及 Git 索引、工作台数据投影和账号个人视图配置，不能仅作为前端列调整处理。
