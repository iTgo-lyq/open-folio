# Change 协作者与默认展示

创建 Change 的人不一定是实际推进的人。列表需要展示参与推进的协作者，避免仅凭创建者判断归属。

本轮先绘制并交付现有 Changes 页的交互原型，由 Astra subagent 设计多人展示；正式业务实现等待原型确认。

## 范围与验收

- 新增协作者列，创建者在成员顺序中排第一，成员去重。
- 视图默认不展示独立的创建者列。
- 原型展示少量与大量协作者，能查看完整成员，在桌面、平板、手机和浅深主题下可阅读、可操作。
- 沿用现有工作台设计与虚构数据，不连接真实业务接口。

## 待后续方案明确

实际协作者的数据来源与识别规则、历史记录缺少协作者时的处理，以及是否调整“我的”等筛选语义，留待原型讨论后确定。本轮不改变这些正式产品行为。
