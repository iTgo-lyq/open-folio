# 交付计划

依据 [Requirement](requirement.md) 与 [Technical](technical.md)。

## T1：以静态业务片段替代七组手写原型

交付七个直接引用业务组件的 TSX 入口、类型化内存 mock、静态构建与匹配现有产品的评审场景；清除不再引用的旧实现与验证脚本，更新包内约定和使用说明，保留历史固定引用。

验收：不启动真实应用即可浏览各片段，主题与关键局部交互工作正常；无真实后端或持久存储副作用；清单、截图与发布协议保持兼容。

验证：原型单元测试、类型检查、自包含构建、七入口 × 明暗 × 声明设备及窄屏浏览器验证，关键表单/列表/目录/画布操作，prepare 协议检查及独立评审。证据写入 Execution；如环境限制无法核实，记录具体限制与复现步骤，不把未通过项记为成功。

全部实现与检查提交推送后停在人工验收，不记录 acceptance、不同步当前 Specs、不归档、不合入 develop；不公开上传新版本。
