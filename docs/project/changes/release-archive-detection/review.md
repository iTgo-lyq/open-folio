# 独立评审

独立子 Agent 在无实现对话上下文的会话中检查需求、全部生产差异与测试，执行针对性回归和真实 Git 反例。

## R1 归档自身关系错误被跳过

原实现的归档模式在关系校验前返回，自 dependsOn 或自 parent 会被错误认定为有效发布归档。已保留发布快照内可判断的关系、环与父子形状校验，仅忽略未在归档集合中的外部来源依赖。自引用反例及既有取消子项案例通过。

## R2 异常日期目录中的重复归档被忽略

原实现提前使用合法位置解析器过滤归档路径，导致有效目录旁的 2026-99-99 同 ID 归档被忽略。已保留形似归档路径的候选，由既有目录校验和唯一性校验拒绝。无效日期单记录、同 ID 重复记录回归通过。

## R3 PR 错误仍阻止发布快照

保留原限流和损坏缓存的全局异常会让已读取的新发布归档无法更新。已将 PR 限流/元数据限额转为停止后续 PR 查询并显示诊断，缓存损坏使用有界冷读取；身份失效、仓库权限失败和取消继续中止，发布前权限检查不变。已发布条目继续进入合入时间未知，不推进 PR 成功时间、不覆盖完整缓存的失败页。

最终独立复验：两处校验缺口已关闭；缓存重试、重启复用、发布提交和已知 ID 集合变化失效通过；最终 PR 错误隔离相关 21 项检查通过，无未解决问题。

## R4 版本文件超限被误当作缺失

T2 独立评审发现：超过读取上限的版本文件被跳过，随后错误回退 tag，可能将未读取文件中的真实版本替换为另一版本。已引入确定的 unreadable 结果，超限、符号链接等不可读取文件不被 tag、其他小文件或旧 PR 标记覆盖；按提交缓存，避免重复读取。临时 I/O 失败仍可重试。归档和时间不受版本读取失败影响。

T2 最终独立复验：版本读取、缓存和交付投影 25 项全部通过；另以独立实验核实 tag 正负缓存 TTL、后补、移动和文件缓存复用，git diff --check 通过，无未解决问题。
