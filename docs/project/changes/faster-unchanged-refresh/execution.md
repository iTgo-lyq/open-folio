# T1 执行记录

## 基线调查

在已部署的 a42290c 上暂停服务，直接运行同版本 Repositories.refresh，复用原工作台和仓库缓存，以临时包装器记录 provider 方法与 Git 子命令的完整调用时间。三个样本均复用快照 688e89ba-5bd6-42df-8244-6f11fe3a7c87。测量结束退出测试设备并恢复服务，保留原有设备、凭据与工作台偏好。

| 三轮均值 | 耗时 |
| --- | --- |
| 请求入口解析仓库 + 内容权限 | 0.94 秒 |
| ls-remote HEAD | 1.03 秒 |
| fetch | 0.97 秒 |
| 末尾再次解析仓库 + 内容权限 | 1.13 秒 |
| 本地缓存及 Git 引用处理等 | 约 0.04 秒 |
| 总耗时 | 4.12 秒（3.979 / 4.064 / 4.325） |

耗时来自六次串行远端操作，不是文档扫描；本地 ls-tree/cat-file 均未执行。原始无凭据计时保存于 Git 忽略的 artifacts/unchanged-refresh-latency-2026-10-13/before.json。

## 实现与回归

一次远端引用查询同时获取 HEAD、分支与原型归档保留标签；按原始对象比较本地引用，仅变化时执行 fetch/prune。附注标签对象变化但提交未变时仍更新 Git 引用，快照可继续复用。无变化只检查取消与工作台/设备有效性；新快照发布保留远端复验。

150 项单元/集成测试通过；15 项相关浏览器测试通过（API 授权、自动更新、隐藏恢复、失败重试、多设备、撤权与切换后的迟到响应）。类型检查、变更文件格式检查及 git diff --check 通过。新增或扩充测试覆盖单次 Git 查询、无 fetch、改写附注标签、删除标签、主分支切换、无变化授权次数及缓存命中时的并发设备撤销。
