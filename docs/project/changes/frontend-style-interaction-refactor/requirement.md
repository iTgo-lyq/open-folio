# 前端样式与交互重构

## 目标与范围

对 OpenFolio 工作台进行整体前端样式与交互重构，使其更现代、易读、易操作，在减少冗余信息的同时保持精致感。蓝色继续作为主题色，允许调整明暗和渐变；少量组件采用苹果液态玻璃的视觉语言，避免效果堆砌。

这是覆盖工作台壳层、共享样式和多个业务模块的 large 需求，不应拆解为仅发布一页原型的小型交付。原型用于对齐视觉与交互，具体页面组织和操作方式通过讨论收敛。

涉及的体验范围：

- 工作台导航、项目切换、上下文和常用操作，明确当前位置与主要入口。
- 仓库列表、信息密度、筛选、搜索和常用项目的访问方式。
- Specs 的目录、正文、来源和阅读连续性。
- Changes 的列表、进度表达、详情及相关材料阅读。
- 原型总览、设备筛选、预览和返回路径。
- 共享组件、表单、浮层、反馈及账号相关页面的视觉和交互一致性。
- 桌面、平板与手机的内容重排、键盘操作和可访问性。

这次重构以现有真实能力为基础。原型中新出现的搜索、收藏、主题切换等交互是待评审的候选方案，其正式实现范围需在需求与原型讨论中明确，不能仅凭原型展示推定已获实现授权。

## 设计方向

优先建立清晰的信息层级、适合长文的排版、稳定的阅读背景和直接可达的常用操作。玻璃质感主要用于少量导航、工具栏或浮层，通过透明度、背景模糊、描边和高光表达层次；正文与密集信息区域应保持清楚易读。

继续结合 shadcnuikit、现有共享组件和当前产品能力评估方案。明确组件复用边界，避免页面各自维护重复样式。明暗主题及渐变的具体方式、玻璃效果的位置与强度，随原型反馈确定。

## 讨论与验收约束

用户明确指出：“这是前端样式交互重构的大型需求。现在还在原型讨论阶段。”原型发布、浏览器测试通过、链接可打开，均不能作为需求或设计已获用户验收的依据。

在原型方案获得用户明确验收、large 所需的需求、技术方案和计划得到相应确认前，不进入正式产品实现，不以 Agent 自验收关闭或归档本需求。技术和计划文档在相应讨论阶段形成，不预先填写确认或完成结果。

最终验收应覆盖以下目标，并在方案收敛后补充具体页面与交互标准：

- 正式界面与用户确认的原型及视觉方向一致，保持蓝色主题和克制的液态玻璃。
- 常用路径清晰可操作，主要信息易读，重复状态和技术信息按合适层级呈现。
- 重构覆盖约定的业务页面与共享组件，既有阅读、切换、预览和权限行为保持正确。
- 响应式布局、加载/空态/错误反馈、键盘焦点与浮层操作完成验证。
- 完成与实现相称的测试、large 所需的独立评审，以及用户对最终交付的人工验收。
