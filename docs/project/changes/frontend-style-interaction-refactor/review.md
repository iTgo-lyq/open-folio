## R1 · 目录 Sheet 关闭后的焦点

证据：Reader 与原型目录由普通按钮打开，未使用 SheetTrigger，关闭时默认焦点无法回到打开按钮。影响键盘用户从目录继续操作。

处理：记录能力/材料、本页目录与原型目录的触发按钮 ref；关闭恢复原按钮，选择材料后进入正文，选择原型后进入标题或手机画布。从材料 Sheet 内选择章节时优先恢复标题。重点浏览器回归验证 Escape、导航后焦点及手机路径通过。

## R2 · Token 失效分类与恢复提示

证据：失权事件固定写 READ_DENIED，事件中止原请求后其 catch 无法写回真实 code；切到账号页还会清空错误。失效 Token 因而显示为无权限，重新绑定提示不能保留。

处理：事件携带真实 code/message/path，取消请求不触发失权清理；消费方核对当前连接/仓库，错误按设备会话、连接与 epoch 隔离。明确的 Token 失效保留至成功读取或切换/重新绑定，网络/503 重试不覆盖已知失效。浏览器回归覆盖真实错误响应→同步状态→503 重试→账号重新绑定→失效提示清除，通过。

## R3 · 原型详情内公开弹层层级

证据：Popover Portal 层级 70 低于 Sheet / 遮罩 81 / 80，详情内公开链接被遮挡。

处理：共用菜单/弹层层级改为 90；原型详情内真实点击复制按钮的命中检查、手动复制输入焦点与 Escape 返回均通过。

## R4 · diff 文件选中样式

证据：选择器 [aria-current] 匹配 aria-current="false"，所有文件显示选中背景与陶土文字。

处理：使用 [aria-current="true"]；浏览器比较选中/未选背景，并在切换文件后核对当前属性，通过。

## R5 · 重复章节定位

证据：相同 anchor 不改变 effect 依赖；选择章节后滚开、再次选择同一章节，正文不回到该章节。
