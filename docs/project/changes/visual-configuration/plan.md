# 配置管理交付计划

依据 [Requirement](./requirement.md) 与 [Technical](./technical.md)，按默认编号串行交付。

## T1：自动初始化并可靠保存服务配置

交付默认路径、指定路径缺失时的创建行为和配置读取保存接口，覆盖校验、原子写入、版本冲突和错误反馈，并更新配置部署说明。

验收：空环境可生成有效空文件，原有配置完整保留；合法配置可读写，非法或过期请求及文件系统失败不会覆盖原文件。构建不初始化用户配置。

验证：临时目录与接口测试，相关现有服务测试、类型检查和格式检查。

## T2：在工作台可视化维护配置并立即生效

交付左下角配置入口、项目和资源限制表单、移动端入口、空状态引导、未保存提示，以及保存后的项目列表与当前内容同步。

验收：从空配置添加项目，再修改、移除并重新加载，文件与页面一致；限制覆盖可恢复默认；保存失败或冲突保留输入；项目删除和仓库变更后不显示过期内容。

验证：桌面与移动浏览器流程、键盘交互、配置持久化及现有阅读刷新回归，类型、格式与生产构建。若新增 UI 包组件，同步独立预览并运行包内验证。交付后进行独立差异评审，提供人工验收入口与结果。
