# 目标与范围

修正用户截图中的两项原型预览问题：左侧目录因按钮居中产生不一致缩进；页面已经显示时仍提示“尚未确认页面就绪”。

- MODIFIED `project-knowledge/prototype-preview`：目录中不同长度的标题、图标统一左对齐，长标题可换行。
- MODIFIED `project-knowledge/prototype-preview`：区分浏览器完成页面加载与原型主动报告应用就绪。缺少可选桥接信号不产生持续警告；聚焦预览加载完成后收起正常状态，Change 原型标签可显示准确的加载状态。明确的宿主运行失败仍提示，并保留适用的独立打开入口。

本次为局部 CSS 与预览状态调整，预计不足 300 行有效实现、不改变发布协议或数据结构，按 small 执行。沿用用户本轮“直接修改并验证”的选择，直接修复并浏览器验证。

## 方案要点

目录按钮覆盖全局居中样式，保留图标固定宽度及标题换行。以当前 iframe 的 load 事件记录页面加载完成，ready/error 桥接作为独立的可选应用反馈；不把 iframe load 描述成应用运行成功。切换入口或重新加载使用独立加载标识，避免沿用旧页面状态。

依赖已归档并推送的 `simplify-workspace-ui`：在同一分支继续优化已经删除搜索、调整外壳后的预览目录，保留前一轮全部交付。

## 验收标准

1. 桌面及 320px 目录抽屉中，不同标题长度的图标与文字起点一致；长标题无横向溢出，切换入口及关闭抽屉正常。
2. 已渲染且没有桥接的页面不再出现“尚未确认页面就绪”提示；刷新、切换入口时状态随当前页面重新计算。
3. 有桥接的 ready/error 回报仍正确处理；错误提示不会被 iframe 加载完成事件隐藏，独立打开保留固定托管 URL，沙箱约束不变。
4. 相应浏览器回归、类型与格式检查、生产构建通过，开发机服务更新后对真实预览页冒烟。
