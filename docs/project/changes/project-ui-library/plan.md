# 交付目标

依据 [Requirement](./requirement.md) 和 [Technical](./technical.md)，先建立共享 UI 基础、前端开发规范和独立预览，再交付宿主发布引用及 main 当前页面总览。追加授权包括个人环境中的官方 shadcn 工具接入，以及代表性 shadcnuikit 组件适配。

按下列依赖串行推进，每项包含自身必要验证与使用说明。下列内容是拟执行的交付定义，任务实际状态以 `change.json` 为准。

## T1 建立基础 UI 包与前端开发规范

交付：增加 `@open-folio/ui` workspace，抽取 Button、IconButton、Badge、EmptyState 与共享 token，供主应用真实消费；在 AGENTS.md 维护精简的前端开发规范，明确组件职责、公共导出、样式、状态、无障碍与质量命令。

验收：至少一个组件在主应用使用公共包入口；业务状态映射仍由主应用决定；公共主题只有一个来源；类型和样式边界符合指引。指引可用于定位组件及完成维护，不要求个人环境配置。覆盖需求验收 1、2、4、6–8 中与共享实现有关的部分。

验证：依赖安装、应用及 UI 源码类型检查、格式检查、主应用生产构建；在真实使用点检查按钮禁用/加载、键盘焦点、状态标签及空态。仅为实际交互风险增加行为测试，沿用现有测试设施。

## T2 交付独立组件预览及维护示例

交付：在 UI 包内提供 Vite 预览与 dev/build/preview 命令、名称导航、状态及交互示例；示例使用公共入口，文档串联查找、修改、预览和两端验证路径。

验收：无需工作台或项目配置即可启动、查找并操作组件；主应用消费不引入示例；修改共享实现后两端反映变化；按前端规范完成一次示例维护并执行相应检查。覆盖验收 1–8 的完整 UI 路径。

验证：UI 预览类型检查及生产构建，独立预览服务浏览器操作；检查宽窄视口、键盘焦点、可访问名称、长文本和适用状态；检查包产物及正常运行依赖不包含个人配置。实际修改共享实现后验证主应用与预览，再恢复实验改动。

## T3 建立宿主发布与原型登记协议

交付：定义项目清单、新版产物引用及宿主发布输入输出，扩展共享校验与语义登记；提供独立测试宿主验证上传、重试和不可变版本；支持显式 Git 兜底当前产物与 Change 快照，并更新接入、可选建议和归档指引。

验收：普通宿主构建输出可通过协议发布，成功后登记当前及可选 Change 引用；部分失败、错误结果、重复请求及中断恢复不会破坏旧引用；Git 兜底必须显式选择；旧 PreviewEntry 校验与无 previews 的流程仍成立。覆盖验收 11、15–17 的生成与登记路径。

验证：共享协议及语义脚本测试，包括未知字段、重复 id、越界路径、符号链接、源码提交、幂等、版本冲突、部分上传、登记恢复和归档移动；使用测试宿主发布两个静态版本并验证旧版本字节不变。没有 previews 的 Change 继续通过状态及 hook 检查。

## T4 支持托管预览与固定 Change 分享

交付：读取并区分 hosted/git 引用；增加受控来源配置、托管 iframe 与就绪提示、宿主截图引用；沿用 Git HTML 隔离、离线截图与旧固定 URL，支持新 Change 快照及归档引用。

验收：进行中 Change 可查看、分享固定版本，后续发布不改变旧链接；宿主 React 多资源产物在 sandbox 中加载并支持局部交互；缺失文件、不允许来源、资源加载或嵌入限制均有准确提示。覆盖验收 11–14、16–17 的读取与分享路径。

验证：现有预览、截图、归档标签和固定链接回归；独立测试宿主构建 React 示例，测试 ESM、动态资源、截图、交互、就绪超时与两次发布；恶意 URL、未经允许来源、父 DOM/存储访问及错误消息发送窗口测试。服务端不下载托管产物或执行宿主脚本。

## T5 以 main 当前清单重建原型总览

交付：固定 main 提交读取描述文件，迁移快照并保留归档 pin，提供页面截图卡片、名称/说明查找与设备筛选；从当前入口直接预览；去除总览的分支、Change 来源及历史切换。为本项目登记仍维护的已有原型，更新使用说明。

验收：总览覆盖 main 当前入口，无 Change 关联也能展示；main 删除后消失，未合入分支与仅上传未登记版本不影响展示；共享 UI 预览不混入原型清单。缺失 main、描述损坏、产物缺失和刷新失败有对应提示。覆盖验收 9–10、12–14、17 的当前页面路径。

验证：Git fixtures 覆盖清单新增、删除、重命名、开发分支差异、源码变化但引用不变，以及缓存迁移保留 archivePins；浏览器验证查找、筛选、当前页面打开、截图降级与缺失态；两 Change 固定版本与当前版本联合回归。

## T6 修复共享组件抽取后的响应式样式

关联 T1：差异复查发现批量替换误删响应式规则；恢复原有布局，仅删除已迁入包的基础规则，并更新剩余关联选择器。验证差异范围、生产构建、桌面及 320px 页面截图与相关浏览器回归，防止无关界面回退。

## T7 迁移旧 HTML 存档并移除旧格式兼容

关联 T3、T4：一次性迁移已有存档，固定源码提交与原产物字节，保存到 Change 维度；删除共享契约、读取和校验中的旧 path 分支。为迁移交付建立新的固定引用，不强推旧标签。验证迁移幂等、字节一致、归档预览、新链接和缓存 pin 保留；更新样例及使用指引。

## T8 接入全局 shadcn 工具并用 shadcnuikit 优化 UI 预览

关联 T1、T2：官方 skill/MCP 安装到个人环境并验证真实调用；按需引入代表性组件，适配 UI 包公共接口和主题，再优化组件预览的发现、示例与交互。认证不进入仓库或产物。验证独立构建、主应用消费、宽窄视口与键盘操作，明确外部服务实际可用范围。

## T9 修复独立评审发现的预览与恢复边界

关联 T3–T5：根据独立评审复现证据修复当前原型缩略图错误响应及发布事务恢复指引/诊断等边界，补充针对性回归。保持既定产物协议和权限边界，完成后记录独立复验结论。

## T10 交付原型二级预览工作台

关联 T4/T5：总览预览改为二级路由；顶部跳转、自动隐藏全局导航、目录和画布布局，画布内设备/方向/缩放，移除预览来源展示。复用既有隔离和固定版本协议，验证浏览器历史、直接访问、目录切换、设备与窄屏，并回归 Change 预览。

## T11 区分卡片预览与详情并更新验收入口

关联 T5/T10：截图点击进入预览，其余卡片内容打开独立详情抽屉；展示来源和清晰完整截图，处理缺失态、键盘焦点与详情到预览跳转。完成交互/构建验证和隔离评审，更新原 Merlin 验收服务，重新等待人工验收。

## T12 修复原型总览返回状态并完成复验

关联 T10：修复独立评审发现的预览返回后滚动位置、已展开分页和卡片焦点丢失，保持 main 清单与详情路由行为。覆盖超过 24 项的非零滚动、返回/刷新及焦点场景，复验隔离评审，更新 Merlin 到最终版本并完成整体验证。

## T13 清理 UI 代码引用并精简开发入口

关联 T1/T8：按用户要求移除组件代码来源注释及独立预览中的供应方外链；AGENTS 前端开发只保留包 README 入口和必要归属约定。连同用户已修改的包文档一起提交，验证 UI 构建、现有预览交互及残留引用，继续等待验收。

# 整体验证与验收

从无个人素材配置的环境安装依赖，运行类型和格式检查、主应用与 UI 预览构建，以及受影响的单元和浏览器测试。生产构建遵守 AGENTS 的目录和串行约定，不覆盖运行中服务产物。

用独立测试宿主验证发布协议，不把该结果说成生产存储已接通。实际部署需要宿主维护者提供允许嵌入、资源 CORS 与版本保留配置；本次不承担任意生产存储的上线。

默认独立评审完整差异和需求覆盖；完成必要修正并保存验证证据后，提交可操作的 UI 预览与原型展示路径供人工验收。验收后同步 Specs 和归档；合入 main 与公开 SpecTrail 同步另按既有授权及 AGENTS 处理。
