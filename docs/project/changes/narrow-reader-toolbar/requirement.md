# 修复窄屏阅读顶栏目录按钮互相覆盖

## 目标与范围

修复现有阅读页在 320px 宽度、较大字号与专注阅读下，能力目录按钮被本页目录按钮覆盖、鼠标点击持续重试超时的问题。此问题已在上一项回归与未修改 main 上确认，本次独立作为 small Change 交付。

只修正顶栏可用宽度与按钮布局，保留仓库入口、当前位置目录、本页目录、阅读设置、同步与账号入口；长标题继续省略，目录与设置行为不变。不通过强制点击、隐藏必要操作、跳过测试或延长超时处理。

## 方案要点

复用现有顶栏与阅读位置按钮，先从实际元素尺寸和命中结果定位 flex 收缩或溢出边界，再做局部 CSS 修复。确保左右工具区按可用空间布局，标题在有限宽度内省略，按钮自身及实际点击区域互不覆盖。属于既有布局缺陷修复，不新增组件、配置、数据契约或阅读选项，按 small 推进。

用户已选择「直接修复，不另画原型」，沿用既有设计，以实际页面截图与浏览器检查验证。

## 验收

1. 在最新 develop 的未修改实现上复现原 `specs.spec.ts` 阅读设置失败，记录原始结果与覆盖证据。
2. 较大字号、专注阅读及普通阅读设置下，320px、360px、390px 的当前位置目录、本页目录与阅读设置入口均可正常点击，无横向溢出；长标题不会扩张点击区域遮挡邻近按钮。
3. 834px 和 1440px 继续保留既有目录、章节定位、阅读设置持久化与焦点恢复行为；共享顶栏的 Change 阅读和工作台入口不受影响。
4. 补充必要的命中或边界断言，原失败场景及相关 E2E 通过，执行受影响文件格式检查、类型检查及生产构建。
5. Agent 按 small 自查、自验收并归档，提交目标为 develop 的 PR；本次未授权合并或正式发布。
