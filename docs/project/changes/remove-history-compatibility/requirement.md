# 清理历史兼容并统一当前契约

## 背景与目标

用户准备稳定版本前，明确要求继续源码部署，完整清除工程内历史数据说明和兼容代码，历史归档 Change 不处理，执行完成后由 iclaude 再验收。版本发布不在本次范围。

## 范围与行为变化

- REMOVED：配置、会话、缓存的历史格式转换，凭据选择恢复、项目链接转接、原型链接别名及专用迁移工具；同时删除配套入口、样式和测试夹具。
- MODIFIED：登录只接受当前 token/username 输入；当前运行文档、Specs、skill 与示例只描述有效契约，不保留退役说明和升级路径。
- 保留当前源码部署、token 隔离、设备会话、密钥轮换、仓库读取、固定原型版本及其归档标签。数据目录和版本号不为文案整齐而重命名。
- 历史归档 Change、已发布字节及 Git 历史保持原样。开发机现有有效会话与密钥保留；停止服务后仅移除本次删除的状态字段，不将处理脚本交付为兼容层。

## 验收标准

1. 当前工程文档与代码不再提供历史格式迁移、恢复、转接或退役说明；归档 Change 不改写。
2. 全新数据目录和当前数据均能完成 token 登录、同 token 恢复、不同 token 隔离、设备撤销及仓库阅读；不再暴露迁移字段。
3. 配置、会话与缓存按当前 schema 校验；非法输入失败时不覆盖有效数据。固定公开原型和托管入口正常。
4. 类型、单元与相应浏览器检查通过，开发机服务更新并冒烟验证；iclaude 独立复核全部差异、残留扫描和测试证据。
