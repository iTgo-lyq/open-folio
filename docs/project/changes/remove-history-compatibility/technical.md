# 方案

采用直接删除方式收敛到当前契约，不增加格式适配器、隐藏转接或替代副本。会话持久状态只含 schemaVersion、workspaces、sessions；工作台不含连接别名。状态目录与密钥/AAD 保持当前命名，避免无关数据转换。配置只读取当前 schema；缓存只读取当前版本。未知 API 交由框架正常返回未找到。

保留当前发布 ID 访问和不可变产物，删除仅用于项目式地址的别名写入与解析。原型 skill 保留当前 artifact 发布、校验和 archive-v2 标签规则，删除转换脚本与说明。ISO 8601 时区读取是有效时间契约，文档用当前时态描述。

## 影响

这是用户明确授权的兼容范围移除，规模 medium。部署方式、依赖、版本、当前业务身份和原型产物不改变。现有开发机状态会因删除严格 schema 字段需要定点整理：停机后校验状态，最小临时备份，移除废弃字段并验证其余内容一致，启动成功后清理备份。不遍历删除运行数据。

## 验证

保留当前功能的回归测试，删除专属迁移测试；补充当前 schema 非法字段与无副作用校验。全量单元、类型、浏览器回归与源码生产构建验证。使用真实工作台完成部署冒烟；最后以 iclaude 的独立只读验收覆盖整个分支差异与证据，发现问题后修复并复验。
