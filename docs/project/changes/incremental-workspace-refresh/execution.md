分支文档缓存复用上次成功快照的来源提交、文档元数据和 blob。扫描规则指纹包含限额；旧版本、规则变化或默认分支角色变化时重新扫描。refs 全部相同时不重建索引或轮换快照；新快照只写入尚未在磁盘复用的正文。

Specs 固定默认保护分支；开发分支只扫描 Change 与归档目录。Change 对 Spec 的显式引用关联保护分支能力，普通 Change 文档保留自身提交。当前原型清单按默认分支提交和限额复用；固定发布缓存继续沿用既有机制。未配置、配置错误、历史读取和归档标签路径保留明确诊断。

可见页面后台检查、回到前台补查；成功检查时间独立持久化，同工作台刷新继续共享任务。普通后台网络失败保留内容并持续提示，明确失权清除内容并废弃晚到响应。轮询从前一次结束后计时，避免长采集叠加或节流导致相邻轮次白跑。
