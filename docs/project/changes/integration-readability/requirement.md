# 优化合入变更阅读布局

用户在现有“合入变更”截图上要求优化界面，并明确补充“左右区域的高度不一致的 bug 也修复一下”。此次调整面向逐文件阅读已合入差异，沿用现有简洁风格、数据来源和只读能力。

## 范围与方案

压缩顶部合入信息，突出文件数量与增删统计；文件列表使用紧凑路径、明确的选中态，完整路径仍可通过悬停及差异标题阅读。文件标题、元信息与阅读操作分层，增加自动换行开关，默认保留代码原始行布局。

两栏由同一个有界阅读容器决定高度，左右底边始终对齐，文件列表与代码区独立滚动；文件标题和列表标题保持可见。窄屏延续“文件列表 → 差异 → 返回文件”的导航，长路径、长行和按钮均不撑出页面。沿用主题 token、公共按钮和现有差异表，不引入编辑器依赖或修改服务端契约。

暂定 small：只涉及合入差异阅读 UI 的一个职责模块，预计不足 300 行有效实现，不改变共享接口与持久化数据。用户已确认上述优化方向；由 Agent 自验收后交付。

## 验收

- 桌面文件列表与差异面板顶部、底部对齐；短文件、长文件、非文本提示及加载状态均保持一致，滚动不移动标题或另一栏。
- 文件列表展示清楚的名称、路径、状态和统计；同名文件可以通过路径区分，选中态和键盘焦点清晰。
- 自动换行可开启/关闭，长代码与长路径始终可读取；换行不改变行号、内容或文件定位。
- 320px、390px、834px、1440px 及宽屏下无页面横向溢出，浅色/深色均可读；窄屏返回列表恢复原文件焦点。
- 固定版本、文件深链接、历史导航、复制命令及失败提示继续有效；完成相关浏览器回归、类型检查与生产构建，合入后更新长期服务并冒烟。
