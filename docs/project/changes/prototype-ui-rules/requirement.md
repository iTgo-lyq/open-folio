# 原型流程调整

依据用户明确要求，调整已启用原型追踪时的 UI 变更流程，保持措辞精简。

## 行为与方案

MODIFIED：小型 UI 变化先询问是否绘制，等待期间可推进无关工作，较长时间未回复可说明后跳过；大范围 UI 变化必须在实现前绘制或更新原型并提供预览。按 UI 影响判断，不以 Change 规模替代。

主 skill 负责触发与路由，原型子 skill 保存分级规则，同步已有能力规格。保留接入状态与已有用户选择，不新增确认字段或审批环节。本次仅调整指导文本，作为 small 独立交付，不依赖待验收的配置管理 Change。

## 验收

- 主 skill 对涉及 UI 的 Change 主动读取原型配置，移除旧的无条件可跳过表述。
- 子 skill 清楚区分小型询问与大范围先绘制；超时跳过仅适用于小型变化。
- 技能结构校验通过，人工核对启用、停用、小型未回复及大范围变更场景；无运行时代码变更。
