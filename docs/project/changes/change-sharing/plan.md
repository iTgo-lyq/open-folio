# 单个 Change 实时分享的实施计划

按[需求](requirement.md)与[技术方案](technical.md)交付。默认按 T1 → T2 → T3 串行执行；全部任务当前定义在 change.json，不在此维护执行状态。

实现前先验收分享模式固定原型，并确认 Technical 与本计划；随后从最新 develop 移交到 `codex/change-sharing` 及独立 worktree。同步时保留已集成的类型标签与紧急程度，避免覆盖其他 Change。原型制作和发布属于本轮方案准备，不代表产品功能已交付。

## T1 · 建立可撤销的实时 Change 分享读取

交付已登录用户创建/查询/停止分享的接口，以及匿名读取单个 Change 全部内容的完整服务端路径。包含独立分享记录、账号绑定 lease、现有权限及 Git 刷新复用、白名单 DTO、文档与图片、代码差异、受分享控制的 Git 原型与截图。公开读取不产生独立永久原型发布。

验收：同一范围重复创建复用链接；创建者退出后仍可读；推送、移交、归档后同一链接使用正确来源；撤回或解绑后所有资源及 HEAD 拒绝读取；其他账号、Change、文档、提交、历史快照和路径不能越界。单条分享撤回不影响同仓库其他合法读取。分享及撤回在服务重启后保留。

验证：复用当前账号、仓库、权限、集成和原型 fixture，扩展分享接口与在途竞态测试；回归已有权限复验周期、刷新去重和独立公开原型行为。检查实际响应字段，确保不含连接、账号、上传地址或其他工程内容。

## T2 · 完成分享管理与完整详情阅读

交付私有详情页分享入口、管理弹窗，以及独立 `/share/[id]` 只读页面。复用六个详情页签和共享阅读组件，拆除分享页对个人 Provider、设备滚动 scope 与永久原型发布的隐式依赖。支持稳定文档/原型深链、自动更新、版本重读、复制失败兜底、撤回及来源异常状态。

验收：全新匿名浏览器可阅读当前 Change 的概览、任务、文档/图表、原型、代码差异及依据，无需账号和 Token；标签、紧急程度与现有工作台一致。桌面、平板及 390/320px 宽度可用，键盘页签、文档弹层、焦点恢复和差异返回工作正常。分享者可以停止后重新分享，旧链接不恢复。

验证：Playwright 覆盖创建→匿名阅读→自动更新→停止→旧链接失效→重新分享闭环，检查请求未访问个人和私有工作台接口；跨移交/归档验证相对路径深链；复验原有阅读链接与公开原型。沿验收原型对照布局和状态，不重写已有 Markdown/原型渲染测试。

## T3 · 让 Agent 在文档和原型就绪后给出分享链接

交付零第三方依赖的分享链接 CLI、基于 `openfolioUrl` 的配置说明，以及精简的主 Skill 指引和一份专项参考。工具使用独立账号设备会话与明确指定的既有 Token 绑定，完成仓库定位、刷新、创建或复用、匿名验证与可靠退出；不自动注册、绑定新 Token或引入服务端机器密钥。

验收：技术文档已推送或原型已发布登记后，Agent 可得到指向对应内容的可访问链接；多次获取复用同一有效分享。未配置地址/账号/绑定、重定向、登录失败、分享不可读和退出失败均如实报告，秘密不进入 Git 或输出。主 Skill 改动仅提供触发时机与参考入口，不复制接口细节、不增加阶段审批。

验证：本地 HTTP fixture 覆盖正常与失败完整交互，并独立检查 Cookie 清理；复查 Skill 的引用和调用说明。核对实际外部服务地址及分享授权，配置后用独立匿名上下文完成真实链接检查。若外部前置未就绪，记录缺口，不以虚构链接或未验收结果关闭任务。

## 整体验证与交付

需求验收 1、3–6 由 T1 的接口证据及 T2 的浏览器闭环覆盖；验收 2、7 由 T2 覆盖；验收 8 由 T3 覆盖。运行类型检查、相关单元与浏览器回归、格式检查及生产构建；只在变化或新疑点需要时扩展复验。

按 medium 要求安排与实现上下文隔离的独立评审，覆盖完整差异、验收映射和验证证据。验证通过后提交推送并提供人工验收；用户验收后同步个人访问、Change 追踪、原型与工作流相关 Specs，再归档并以合并提交集成 develop。

产品实现集成后使用主工作区 `service:update` 更新长期开发服务，选择匹配实际改动的真实冒烟，所有登录检查遵循 `withSmokeSession`。正常更新保留持久数据，不生成额外 `.next-*` 或例行备份。
