# 单个 Change 实时分享的实施计划

按[需求](requirement.md)与[技术方案](technical.md)交付。T1、T2 的定义保留已提交版本；新增 T4 替换其账号归属、分享记录和管理入口，T3 使用新的直接链接能力。全部任务当前状态在 change.json，不在此维护执行状态。

全宽阅读原型已获用户验收；本次保留阅读布局，复制入口按用户最新要求简化。工作分支和 worktree 已建立，用户已允许当前聊天通过显式指定工作区继续实现，无需重新移交。修订后的 Technical 与本计划按既有阶段规则确认后继续受影响实施。

## T1 · 建立可撤销的实时 Change 分享读取

交付已登录用户创建/查询/停止分享的接口，以及匿名读取单个 Change 全部内容的完整服务端路径。包含独立分享记录、账号绑定 lease、现有权限及 Git 刷新复用、白名单 DTO、文档与图片、代码差异、受分享控制的 Git 原型与截图。公开读取不产生独立永久原型发布。

验收：同一范围重复创建复用链接；创建者退出后仍可读；推送、移交、归档后同一链接使用正确来源；撤回或解绑后所有资源及 HEAD 拒绝读取；其他账号、Change、文档、提交、历史快照和路径不能越界。单条分享撤回不影响同仓库其他合法读取。分享及撤回在服务重启后保留。

验证：复用当前账号、仓库、权限、集成和原型 fixture，扩展分享接口与在途竞态测试；回归已有权限复验周期、刷新去重和独立公开原型行为。检查实际响应字段，确保不含连接、账号、上传地址或其他工程内容。

## T2 · 完成分享管理与完整详情阅读

交付私有详情页分享入口、管理弹窗，以及独立 `/share/[id]` 只读页面。复用六类详情内容和共享阅读组件，以材料侧栏、内联正文及章节导航组织分享阅读，手机目录按需展开。拆除分享页对个人 Provider、设备滚动 scope 与永久原型发布的隐式依赖。支持稳定文档/原型深链、专注模式、临时字号、章节定位及前后材料阅读，以及自动更新、版本重读、复制失败兜底、撤回及来源异常状态。

验收：全新匿名浏览器可阅读当前 Change 的概览、任务、文档/图表、原型、代码差异及依据，无需账号和 Token；标签、紧急程度与现有工作台一致。桌面、平板及 390/320px 宽度可用，正文首屏可见，常规和专注模式均使用可用全宽且保留阅读边距，章节跳转、专注阅读、字号切换、前后文档、目录焦点恢复和差异返回工作正常。分享者可以停止后重新分享，旧链接不恢复。

验证：Playwright 覆盖创建→匿名阅读→自动更新→停止→旧链接失效→重新分享闭环，检查请求未访问个人和私有工作台接口；跨移交/归档验证相对路径深链；复验原有阅读链接与公开原型。沿验收原型对照布局和状态，不重写已有 Markdown/原型渲染测试。

## T3 · 让 Agent 在文档和原型就绪后给出分享链接

交付零第三方依赖的直接链接 CLI、基于 `openfolioUrl` 的配置说明，以及精简的主 Skill 指引和一份专项参考。工具从本地 Git 与 workflow 获取仓库、协作分支和服务地址，构造链接、匿名验证目标材料并返回来源；不要求分享账号或凭据，不创建分享或设备会话。

验收：技术文档已推送或原型已发布登记后，Agent 可得到定位对应内容的可访问链接；相同目标多次获取地址稳定。未配置服务地址、重定向到平台登录、目标不可读或本次材料尚未同步时如实报告。所有请求不带 Cookie 和 Authorization。主 Skill 仅增加触发时机与参考入口，不复制接口细节、不增加阶段审批。

验证：HTTP fixture 覆盖正常匿名读取、配置与目标错误、重定向、未同步、超时、来源核对和文档/原型深链；复查 Skill 引用与命令。核对 11117 的 Merlin 入口并配置真实 `openfolioUrl`，用独立匿名上下文验证可达性；实现的真实外部链接在集成部署后复核。若平台前置未就绪，记录实际缺口，不以虚构链接或未验收结果关闭交付。

## T4 · 改为按仓库与 Change 直接读取分享内容

交付不依赖创建记录的直接阅读地址和 API：从现有可用仓库来源定位目标，复用单 Change 投影、文档/图片、原型与合入差异读取；支持同仓库来源切换和权限检查。工作台分享入口直接复制/打开链接，阅读页导航、资源和深链保留完整目标参数。移除 T1/T2 初版的随机分享存储、账号归属、创建/撤销接口及管理状态。

验收：无需登录或创建操作，直接打开仓库与 Change 地址即可读取存在且服务可读的全部内容；不同分享者得到相同目标地址。设备退出不影响链接；来源失效可切换同仓库其他有效来源，全部失效后停止交付。目标、资源与版本边界保持，重启、移交和归档不改变链接。保留全宽阅读，不再出现开启/停止/重新生成操作。

验证：替换旧分享生命周期测试，覆盖匿名直达、来源定位/切换、无来源、仓库身份变化、解绑及版本竞态、子资源范围，回归账号/仓库权限。浏览器验证复制、匿名六类详情、目标参数保留、文档与原型深链、来源变化和桌面/窄屏。核对旧管理入口已移除，不为未部署的临时记录设计生产迁移。

## 整体验证与交付

需求验收 1、3–6 以 T4 新契约测试为准，保留 T1/T2 中适用的资源和阅读证据；验收 2、7 由 T2 阅读能力及 T4 浏览器回归覆盖；验收 8 由 T3 覆盖。运行类型检查、相关单元与浏览器回归、格式检查及生产构建；只在变化或新疑点需要时扩展复验。

按 medium 要求安排与实现上下文隔离的独立评审，覆盖完整差异、验收映射和验证证据。验证通过后提交推送并提供人工验收；用户验收后同步个人访问、Change 追踪、原型与工作流相关 Specs，再归档并以合并提交集成 develop。

产品实现集成后使用主工作区 `service:update` 更新长期开发服务，选择匹配实际改动的真实冒烟，所有登录检查遵循 `withSmokeSession`。正常更新保留持久数据，不生成额外 `.next-*` 或例行备份。
