# 按仓库与 Change 直接读取分享

依据[需求](requirement.md)。地址直接表达目标，服务实时读取指定 Change，不保存链接所有者或分享生命周期。复用 T1 的单 Change 投影、受控资源读取和 T2 的全宽阅读页，替换随机记录及管理接口。既有实施证据见 [Execution](execution.md)。

## 地址与接口

阅读地址为 `/share?repository=<GitHub HTTPS 仓库地址>&change=<Change ID>`，参数按 URL 编码。工作台和 CLI 同时携带 `collaborationBranch`，从项目配置取得，用于非默认分支和同仓库不同接入来源消歧；未指定时使用服务已知的唯一协作来源，存在歧义则提示补充，不随意选取。

接口统一为只读 `/api/shared-changes/<资源路径>`，通过相同参数指定仓库、Change 和协作来源：

| 资源路径                                  | 内容                                 |
| ----------------------------------------- | ------------------------------------ |
| `change`                                  | 当前单 Change DTO                    |
| `documents/<id>`、`assets/<id>`           | 当前 Change 的正文或图片             |
| `previews`                                | 当前 Change 原型清单                 |
| `previews/<entryId>/index.html`、设备截图 | 受控 Git 原型资源                    |
| `integration`、`integration/files[/<id>]` | 该 Change 集成记录的摘要、文件与差异 |

子资源继续要求当前详情的 `snapshot`，只接受接口声明的参数，不接受任意 Git 路径、来源分支、比较基点或头提交。GET/HEAD 执行相同读取检查，写方法不支持。

工作台改为复制链接和打开阅读页，不调用创建、查询分享状态或撤销接口。移除 `Shares` 存储及初版 `/share/[id]`、管理 API。初版仅存在于工作分支和测试数据，尚未部署，不涉及生产分享记录迁移，不增加兼容层。

## 服务端仓库来源

现有 `PersonalSessions` 保存持久绑定，`Discovery` schema 2 按绑定保存已接入仓库及协作分支；T1 已将设备会话读取与内部凭据 lease 分开。复用这些来源，不新增分享账号、机器密钥、开放名单或 share-enabled 字段。

新增内部目标解析：

1. 严格解析 GitHub.com HTTPS 地址及 Change ID，拒绝凭据、额外主机、端口、查询与片段，规范化 `.git` 后缀及名称比较。
2. 从当前仍存在的绑定及其已接入仓库记录中，筛选同一地址与协作来源；不向客户端返回这些账号、绑定或目录信息。
3. 按稳定顺序尝试来源，通过 `credentialLease`、仓库权限检查和稳定仓库 ID 校验构造上下文。来源失权或移除时可尝试同仓库其他有效来源；网络/限流失败如实返回，不冒充最新读取成功。
4. 用现有 Git 刷新和 SpecTrail 入口解析定位 Change；没有可用来源或目标不存在时显示“内容不存在或暂不可读”。本次不因匿名请求自动发现所有 GitHub 仓库或建立新绑定。
5. 交付前复核来源、权限及快照。在途来源移除后丢弃其响应；改用其他来源时完整重新读取，不跨来源拼装详情和资源。

账号绑定仅提供服务已有的源读取能力，不形成“分享所属账号”。地址不含账号或连接 ID，设备退出不改变链接；同仓库其他有效来源可继续支撑原地址。

匹配同时检查仓库地址、provider、instance 和稳定 ID。重解析发现改名、地址复用或身份变化时，不把旧记录当作新地址的有效来源。协作分支必须匹配接入记录，不通过匿名参数读取任意远端分支；修改仓库或 Change 按新目标重新执行所有检查。

授权行为较初版明确变化：服务已接入且可读取的仓库，包括私有仓库，无需创建者逐条开启，知道仓库与 Change 即可请求详情。单 Change 响应范围与私有工作台的原权限检查继续保留。

## 实时更新与资源一致性

详情沿用 `refresh(automatic: true)`，复用同工作台在途刷新和 60 秒成功检查窗口。可见页面每分钟、重新聚焦及手动刷新时检查，不新增后台轮询，也不提供匿名强制绕过刷新窗口。

仓库权限沿用固定 5 分钟复验；明确拒绝立即失效，远端静默撤权最迟在下次周期识别。网络失败和限流不延长权限有效期，绑定移除后不能通过旧缓存继续交付。

返回 `SharedChange` 白名单 DTO：快照 ID、读取时间、项目展示名、当前 ChangeGroup 和合法文档引用。保留标题、标签、任务、问答、确认、关闭、来源及该 Change 诊断；不展开整个 Workbench，不输出账号、连接、上传地址、其他 Change 或 Specs。前端用适配器填充组件需要的空集合。

文档白名单来自候选 `documentIds`，逐项核对分支、提交和目录，并保留集中入口 `change.json`；图片和图表同样受限，不递归跟随正文链接扩大范围。Git 原型和截图走受控 API，不永久公开发布；hosted 原型沿用既有公开 URL。保留 CSP 与 `allow-scripts` 沙箱。合入差异复用 `IntegrationReader` 固定记录、分页和大小限制。

子资源与当前快照不符时返回 `409 SHARE_VERSION_CHANGED`，前端重新获取详情。有效读取来源切换也可能产生新快照，必须按同样方式重读。不存在或不可读时清空可交互详情；临时网络失败可保留当前已显示内容并标记未同步。错误不暴露内部账号、存储路径或 Token 状态。

所有分享响应使用 `no-store`、`nosniff`、`no-referrer`、`noindex`，受控 Git 原型仅允许本站嵌入。私有接口保持设备会话、写入 Origin 和 revision 检查。

## 阅读页与深链

保留已验收的全宽布局：桌面材料目录、正文、章节三栏；平板与手机按需打开目录，正文与专注模式使用可用全宽。保留 16/18px 临时字号、章节进度、前后材料、焦点恢复，以及六类详情。

阅读上下文不依赖 `PersonalProvider`，由完整 URL 目标生成只读请求。所有导航、复制和请求必须保留仓库、Change 与协作来源；切换目标后取消旧请求，事件也按完整目标隔离，避免旧响应覆盖新详情。

文档深链为 `ct=documents&document=technical.md&anchor=...`，按当前 Change 目录相对解析；原型使用 `ct=previews&preview=<entryId>`。阅读链接不固定快照、内部文档 ID 或工作分支，移交/归档后重新定位。范围外引用提示不在本页内容范围，不误称其他 Change 没有分享资格。

**Q3（技术：原型）**的全宽阅读设计继续有效。复制入口去掉创建、停止和重新生成，落实本次明确要求；旧固定原型保留为历史，正式产品按新需求验收。

## 无账号 CLI 与精简 Skill

复用 `workflow.openfolioUrl`；已有设置命令为 `node .agents/skills/spec-trail/prototype/scripts/setup.mjs --configure --openfolio-url <服务地址>`，保留现有托管选择，不写入冒烟地址、上传地址或秘密。

新增零第三方依赖 `scripts/share.mjs`，接受 `--repo`、`--change` 和可选 `--document`/`--preview`：

1. 从 workflow 读取服务地址、协作分支，从 Git origin 规范化仓库地址。远程服务必须 HTTPS，拒绝 URL 凭据、查询和片段；仅 loopback fixture 可用 HTTP。
2. 构造直接链接，以无 Cookie、无 Authorization 的请求验证详情与目标材料。使用超时和有界响应，不跟随重定向；平台登录页、错误或目标不匹配不输出成功结果。
3. 返回链接及当前来源分支/提交、原型引用。Agent 先提交推送，核对服务已读到本次材料再主动提供。若尚未同步，沿自动刷新窗口有限重试，超时如实说明，不添加匿名强制刷新。

原方案全部 `OPENFOLIO_SHARE_USERNAME/PASSWORD/CONNECTION_ID` 前提取消；没有登录、退出、注册、绑定或创建分享步骤，不借用冒烟账号。

主 Skill 增加一段触发说明和 `references/sharing.md` 入口，原型子 skill 只引用同一说明；配置、命令和失败处理集中在参考中，不复制阶段规则、不扩展状态字段。

## 取舍与规模

| 处理   | 内容与理由                                                                                      |
| ------ | ----------------------------------------------------------------------------------------------- |
| 删除   | 随机 ID、持久分享记录、创建者归属、撤销及账号 CLI；直接地址已满足用户要求。                     |
| 保留   | 单 Change 白名单、权限与交付前复核、快照一致性、原型沙箱，防止越界和失权/版本变化后的错误交付。 |
| 复用   | 仓库发现、持久绑定、权限周期、Git 刷新及已有文档/原型/差异阅读组件。                            |
| 不新增 | 分享开放开关、机器账号、匿名全仓库浏览、任意 Git 主机与后台任务。                               |

本轮替换现有目标解析并简化 CLI，保持 medium 的串行交付安排；组件提取及原型样式迁移不重复计为实现重写。补充 Execution 与独立 Review，覆盖完整交付，旧契约测试不能替代新语义验证。

## 验证与部署

接口测试覆盖匿名直接读取、地址稳定、来源切换、无来源/目标不存在、GET/HEAD、资源越界、快照变化、解绑在途交付、权限周期及刷新合并。替换旧所有者/撤销测试，保留适用的资源隔离回归；禁止任意网络主机和跨仓库缓存借用。

浏览器验证直接访问、复制、全部详情、Git 原型、导航/复制后目标参数保留、深链跨移交/归档、失权和全宽/窄屏，不调用个人或私有 API。CLI 用 HTTP fixture 验证匿名请求、配置错误、登录重定向、目标不存在、未同步、超时及正确输出。

长期服务从主工作区 develop 构建，端口 11117，保留现有持久目录；集成后 `service:update` 与真实冒烟，不迁移或重置账号数据。回退代码会移除新增直接入口。

已核实 `openfolioUrl` 未配置，11117 的 Merlin 入口当前需要平台登录；另一端口的公开入口不属于指定长期服务。T3/交付围绕 11117 更新并验证匿名入口后填写配置，不借用其他运行服务。平台限制无法解除时报告实际原因，不以 localhost 或登录后的可达性替代匿名验收。真实登录冒烟仍仅使用 `withSmokeSession`，分享验证使用独立无 Cookie 上下文。
