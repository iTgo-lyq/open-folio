# 背景与目标

用户要求优先优化三项工作台 UI 与交互问题：原型卡片遮挡左侧导航提示、内容框架多占一行，以及无用的搜索功能。

## 范围与行为变化

- MODIFIED `project-knowledge`：导航提示显示在内容区域及原型卡片之上；框架仅保留一行页头，必要的来源、读取状态、分享和刷新操作放到右上角。
- REMOVED `project-knowledge/spec-reading`、`project-knowledge/change-tracking`：删除全文搜索、快捷键、搜索弹窗、API、类型和存储搜索方法；删除仓库、能力目录、Change、原型总览及预览目录的关键词筛选和相应样式。保留状态、类型、设备等非关键词筛选。
- 同步删除当前原型源码中的搜索副本与第二行外壳。历史归档与固定发布版本保持只读；组件库开发预览属于独立开发工具，不在本次工作台搜索范围。

## 方案要点

使用明确的侧栏和内容层叠上下文，避免卡片的变换或内部层级盖住导航提示。右上角以紧凑的来源状态配合原有分享与刷新按钮，在窄屏提供可访问的完整状态。删除搜索的整个调用链，不保留隐藏入口、兼容实现或替代副本。

本次只涉及局部布局及搜索删除，新增或实质重写代码预计不足 300 行，不改变持久化数据或核心协议，按 small 执行。用户已明确三项目标及删除方向；直接实施并用浏览器验证。按原型约定已异步询问是否先绘制独立原型，默认推荐直接修改；未回复时给出合理等待后沿用此建议。

## 验收标准

1. 原型卡片附近悬停或键盘聚焦左侧导航时，提示文字完整可见且不会被卡片覆盖；全局通知也位于内容之上。
2. Specs、Changes、原型总览的框架不再有第二行；来源、读取状态和必要操作可从右上角获取。桌面及 320px 窄屏均无横向溢出。
3. 工作台各页面及当前原型源码不存在搜索入口、关键词状态、快捷键和搜索调用链；旧搜索 URL 不再执行搜索。目录导航、深链接、状态和设备筛选、预览与分享仍可用。
4. 相应类型检查、现有测试调整、浏览器交互验证和生产构建通过，并更新开发机服务完成冒烟。
