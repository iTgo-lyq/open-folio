集成脚本只保留 preflight / verify / cleanup，平台合并由 Agent 的现有工具执行；两类 PR 以末尾元数据段关联。未集成归档可通过 rework 恢复活动目录及原型路径，已集成归档仍冻结。主 skill 替换原直推规则，发布内容集中到短篇 release.md，未加入 changelog、tag 或 Release 管理。

验证：20 项状态命令回归通过；修正新增 fixture 后，20 项合入、返修、标记和清理专项全部通过；类型检查与格式检查通过。模拟平台普通合并，检查预检与验证无 push、目标推进、未推送来源、重复核实、已集成冻结、Git 原型恢复和逐项清理。发布指令核对了首次整理、复用已有 PR、候选变化、仅准备 PR 与合入失败的处理，未向发布分支执行合码。
