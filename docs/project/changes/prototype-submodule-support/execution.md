新增分发脚本时将应用、锁文件和技能版本同步为 0.1.10。未操作长期服务及持久用户数据。

Change 自有 Git 快照和 hosted 引用不再依赖当前原型包的读取；源码追溯单独从构建父基线解析子 gitlink 与入口源码，失败保留产物并标记 sourceAvailable=false 和具体原因。可选的源码追溯不作为主仓库产物的授权依赖；直接派生的子仓库内容仍要求独立权限。
