# 统一原型页面与评审预览图标

七个 `quiet-*` 原型入口没有声明 favicon，新版图标只出现在评审设置的模拟标签页中，直接打开原型时无法显示一致的网站图标。用户在确认遗漏后要求「帮我全部替换下」。

## 范围与方案

为七个原型 HTML 的 head 内联现有 `openfolio-icon.svg`，沿用构建器的 data URL 展开，保持产物自包含。侧栏、登录页和评审图标预览统一使用新版矢量；蓝色评审选项继续用于强调色对照，不再恢复旧位图。移除原型包及主站 public 中无引用的旧图资源并同步设计说明。

共享原型导出检查允许使用图片 data URL 的 `link rel="icon"`，仍拒绝外链图标、样式及其他不支持的嵌入标签；同步递增技能补丁版本。

用户补充要求确认新原型不会继续带旧图标。项目构建器为未声明 favicon 的新页面自动内联当前新版图标，已有自定义图标不覆盖；通用 SpecTrail 模板没有 OpenFolio 品牌绑定。

本次为 small：只修正原型图标及相应说明，不改变共享接口或数据结构。重新构建并发布七组当前原型和全部声明设备的截图，更新当前清单及本 Change 的固定引用，历史发布和归档引用保持原版本。主站图标已经是新版，无需替换。

## 验收

- 七个自包含入口都有 SVG favicon，内容与现有新版应用图标一致，无额外网络资源依赖。
- 新建未声明图标的入口构建后自动使用新版图标；自定义 favicon 保留且不会重复插入。
- 浅色、深色与蓝色评审场景均展示新版标志，评审设置中的图标预览一致。
- 原型静态契约、既有浏览器交互检查通过；发布后七项的桌面、iPad、手机缩略图在刷新后的真实工作台均能加载。
- 当前原型引用可公开读取，主站服务使用集成后的实现；真实登录冒烟通过 `withSmokeSession` 完成并核验退出清理。
