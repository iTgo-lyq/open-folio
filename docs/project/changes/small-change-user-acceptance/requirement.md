# small Change 人工验收反馈后停止自动归档

## 目标与范围

保留 small 默认自验收归档的便利；人工验收一旦提出问题，该 Change 后续改为等待用户确认，便于继续调整。

用户最新要求：“一旦出现人工验收有问题，后续取消自动归档吧。注意措辞精简。”本次仅调整流程指导，不改变状态结构或服务实现。

## 方案要点

- small 默认自验收后归档；用户要求人工验收或人工验收提出问题后，该 Change 后续须用户确认，并在 Requirement 保留此要求。
- 复用现有 user/agent 验收、等待和返工命令，主 skill 集中说明规则，命令参考引用，不新增状态字段。
- 本次已收到人工验收反馈，后续等待用户确认；确认后同步相关 Specs 并归档。

## 验收

1. 无人工验收要求或问题反馈的 small 可自验收并归档。
2. 人工验收提出问题后，修复及后续返工不恢复自动归档；验证通过后等待用户确认。
3. 主 skill 与命令参考一致、措辞精简，skill 校验和差异检查通过。
