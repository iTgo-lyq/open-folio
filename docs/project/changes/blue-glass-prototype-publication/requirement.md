用户已要求将本次对话中完成的蓝色玻璃工作台原型发布到 OpenFolio 的原型总览，并提供可以直接打开的预览链接。

## 范围与方案

将已完成的独立原型机械迁入现有原型包，保留蓝色主题、局部液态玻璃、仓库搜索与收藏、Specs 阅读、Change 详情、设备预览和明暗主题。原型继续使用明确标识的示例数据，交互只在内存运行。

使用现有自包含 HTML 构建和 R2 发布适配器，为 `blue-glass-workbench` 登记固定版本及桌面、iPad、手机缩略图。保留此前所有原型与历史引用；本次发布不将该设计应用到正式工作台，也不改变服务实现。

本次为 small：只迁入已验证材料并按现有协议发布，不新增产品行为、共享契约或构建逻辑。用户本轮明确的发布指令作为启动依据。
