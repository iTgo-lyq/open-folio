# 按邮箱识别 TRAE 提交的协作者

TRAE 生成的 Git 提交可能把作者名统一写为 `TRAE`，同时保留用户邮箱。工作台和分享页需要显示可识别的用户名称，避免多人因同一工具署名折叠为一个成员。此次延续 Change 协作者的 Git 历史识别。

## 行为与验收

- 作者名为 `TRAE` 且提交有可解析的邮箱时，创建者及协作者显示邮箱前缀，例如 `TRAE <dev.12@example.com>` 显示为 `dev.12`。GitHub 隐私邮箱使用可识别的登录名。
- 同一邮箱的多次署名按既有规范化规则归并，使用不同邮箱前缀的 TRAE 作者可分别显示。普通作者及无法解析邮箱的 TRAE 作者沿用原有显示规则，完整邮箱仅在服务端使用。
- 刷新已有仓库快照即可看到历史提交的修正结果，即使仓库提交未变化。

## 方案

复用服务端 Git 作者投影与身份去重逻辑，更新可重建的快照版本。改动集中于作者显示和缓存失效，规模为 small。
