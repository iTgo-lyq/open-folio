# 修复提交校验误判子模块固定对象缺失

在 linked worktree 提交原型子模块的 gitlink 更新时，Git 将父仓的 `GIT_DIR` 传给 pre-commit。校验器切换目录后仍从父仓读取对象，误报子仓的固定提交缺失。本 Change 补齐子模块固定版本交付的本地提交校验。

同仓查询沿用当前提交的 Git 环境，父仓暂存查询保留 Git 为本次提交指定的索引。跨仓查询隔离 Git 的仓库本地环境变量，让目标子仓自行解析仓库和对象目录。

## 验收

- 通过真实的 linked worktree 提交校验，暂存指针引用子仓已有提交时通过，确实缺少固定对象时拒绝提交。
- 部分提交按 Git 提供的临时索引校验，已有原型关联和嵌套子模块检查继续通过。
