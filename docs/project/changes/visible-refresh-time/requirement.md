# 顶栏保留刷新入口与上次更新时间

当前阅读页右上角只展示“已同步”，刷新按钮和快照时间藏在弹层中，容易让用户误以为内容实时更新。顶栏需要直接保留手动刷新入口，并显示当前内容的上次更新时间。

## 范围与方案

- Specs、Changes 和原型阅读页顶栏直接展示刷新按钮，以及当前快照的上次更新时间；更新时间仍可点击查看来源、分支、提交和异常详情。
- 沿用现有刷新请求与快照 `capturedAt`，不以浏览器打开时间或失败请求时间替代成功快照时间；后台检查没有产生新快照时保留原时间。
- 刷新期间显示读取状态并禁用重复点击；失败或离线仍显示上次成功快照时间及现有异常提示。
- 沿用现有组件和样式，窄屏使用紧凑时间展示，Change 详情和原型聚焦阅读页也保留入口。本次不扩展匿名分享页。
- 技术澄清 Q1：用户选择直接沿用现有样式实现，跳过本次原型绘制。

## 验收

- 无需打开弹层即可在阅读页右上角看到刷新入口和更新时间。
- 点击刷新触发现有仓库刷新；读取中不可重复点击，成功后显示当前快照时间。
- 刷新失败时保留已有内容与更新时间，仍能重试并打开来源详情。
- 桌面与窄屏顶栏不溢出，Change 详情和原型聚焦阅读页保留刷新入口。
