# 缓存淘汰后保留已显示的原型截图

延续 [原型截图返回总览时即时显示](../../archive/2026-11-17-prototype-thumbnail-loading/requirement.md)。从画布返回总览时，卡片会用共享缓存中的准备结果显示自动截图。展开大量原型后，准备结果可能被淘汰，此时导航重渲染会使已显示的截图退回加载状态。

## 方案

缓存命中时将准备结果保存在当前 hook 实例中，沿用缓存实例、请求键和可读状态的匹配规则。共享读取缓存仍按原有上限淘汰条目，画布预览沿用原有准备流程。

## 验收

- 从画布返回总览并命中同版本的准备缓存，展开足够多的原型淘汰该条目，再打开详情触发总览重渲染。已挂载卡片仍显示原截图，准备请求次数不增加。
- 固定截图、准备失败重试和不同版本隔离的现有浏览器用例通过。
