# Change 分享持久短链接与空间名返回入口

用户希望缩短 Change 分享地址并长期保留，同时从分享页左上角返回所属空间。用户进一步明确：「不要加【返回空间】按钮，现在本来就是空间名字，用户点击支持它跳回去就行。」沿用此方向直接实施，不另绘制原型。

## 范围与方案

- 将现有左上角空间名变为普通链接，返回对应仓库的 Changes 空间。只携带仓库定位信息，接收者使用自己的账号和连接读取；匿名进入登录页，没有该仓库权限的账号正常被拦住。
- 分享弹层生成网页与 Agent 文本短链接，形如 `/s/<id>` 和 `/s/<id>/agent`。固定标识只映射仓库、集成分支和 Change，不保存账号、凭据或内容快照；同一目标复用记录，存入服务持久数据目录，不设置过期与清理周期。
- 网页地址在切换材料后保持短格式，材料、章节等阅读位置继续使用查询参数。Agent 文本分篇和快照定位沿用既有范围与版本校验。
- 旧 `/share`、`/share/agent` 地址及本地离线分享脚本继续可用。短链接每次读取仍经过现有可读来源校验；长期保存定位不保证来源失权后仍可读取正文。

本次为 small：新增局部分享目标映射，复用现有分享读取与工作台权限路径；旧读取契约保持兼容，路由与调用方只做适配。没有数据库迁移、短链管理界面、撤销机制或新鉴权体系。

## 验收

- 现有空间名可通过鼠标和键盘返回正确仓库；未登录需登录，无权限不能读取私有空间；不增加返回按钮。
- 分享弹层的网页和 Agent 地址不含长仓库参数，两种地址均可匿名读取同一 Change；错误不泄露凭据。
- 同目标并发生成、服务重新创建与重启后，原短链接仍能解析；持久记录无有效期，缺失或非法标识正常返回 404。
- 短链接切换文档、刷新及前进返回保留材料和章节；Agent 文本链接支持分篇、快照校验与 HEAD。
- 来源解绑或失权仍停止正文交付，不能利用短链参数改写目标或越界读取其他 Change。
- 旧长链接及既有分享行为保持可用；类型、针对性服务端测试、生产构建和浏览器验收通过。
