# 补齐技术方案反膨胀指导

## 目标与方案

延续 `technical-anti-bloat`：用户指出上一版过度精简，丢失了原 skill 可操作的判断方法。本次为 small，将技术方案中的单段原则改为短小节，补回问题与最小验收对齐、具体检查对象、已知风险和预防性扩张的区别、有证据的取舍、必要保护与审查成本控制。

依据此前已读取的 [anti-bloat-review 原文](https://github.com/wp-a/codex-evolution/blob/main/skills/anti-bloat-review/SKILL.md) 整合，保留对门禁、哈希/SHA 比对等具体机制的判断，不因名称自动认定冗余。结论写入既有方案取舍，沿用阶段确认，不新增独立审核流程或固定报告。原有数据不兼容选择规则保持适用。

## 验收

- 指南说明检查什么、凭什么判断及如何提出取舍，不止泛泛要求精简。
- 明确保留有实际目的的保障，证据不足时说明缺口，不编造风险或结论。
- 保留轻量整合方式，对应 Spec 同步；skill 校验与差异自查通过。
