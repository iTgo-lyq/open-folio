# 配置与访问评审

## R1：读取限制语义

独立评审发现 `refreshMs` 是 `AbortSignal.timeout` 的时限，界面却写成最短刷新间隔。已将配置表单、说明与浏览器断言统一改为读取超时；配置浏览器 6 项通过。

## R2：外部更换仓库后的选择同步

面板打开时取得最新配置不足以代表工作台当前展示的来源。已记录工作台实际 fingerprint，新来源到达后清除 branch、文档及原型等旧选择。新增外部换仓库后仅改名称保存的浏览器回归，通过。

评审由独立 Agent `review_configuration` 对 T1/T2 差异进行。初始化、冲突拒绝、原子保存、旧请求失效未发现其他明确问题；权限范围另行评审。


## R3：访客令牌不可作为管理密码的离线验证器

独立评审用已知项目邀请码和测试访客 Cookie 复现了旧方案中以候选管理密码直接计算 HMAC 的验证路径。已改成私有自动生成的 32 字节 `access-secret` 独立签名密钥；管理密码摘要、项目标识与邀请码只作为签名消息，仍支持轮换撤销。新增签名隔离回归，独立评审运行访问单元测试 7/7 通过，复核原伪造方式无效。

## R4：截图重定向与错误响应的撤销检查

原返回前检查仅处理成功和 304，遗漏托管截图 302 Location。已改为所有项目资源响应统一复核当前配置与凭证，覆盖重定向及错误响应；配置 GET 返回前和 PUT 读完请求后再次复核管理员。独立评审确认缺口关闭。

T3 评审由隔离上下文的 `review_configuration` Agent 只读完成，覆盖配置、API、图片、Git 原型 GET/HEAD、截图、分享片段、权限失效及访客/管理员隔离。所有问题已修正，复核无其他明确阻断项；最终 80 项单元与 49 项浏览器回归通过。
