# 方案

依据 [Requirement](./requirement.md)，保留现有 JSON schema 和配置读取函数的调用方式。`OPENFOLIO_CONFIG` 非空时解析指定路径，否则使用数据目录下的 `config.json`；相对路径以服务工作目录为基准。配置只在运行时实际读取时初始化，构建不创建文件。

不存在时递归创建父目录，并以独占、完整发布的方式创建空配置，避免并发首读覆盖已有配置或读到半写入文件。已有内容无法解析、路径是目录或权限不足时返回相应错误，不自动重置。创建的目录、文件使用私有权限。

## 读取与保存

新增 `/api/config`：GET 返回当前配置、内容版本、实际文件路径及默认限制；PUT 接收配置和读取时的内容版本。客户端不能提交存储路径。接口使用 `private, no-store`，保存只接受 JSON，限制请求体大小，复用服务端 schema 校验。追加权限需求后，读取及保存配置均要求管理员凭证。

版本由原文件字节计算摘要。单进程内按实际路径串行保存，写入前重读核对版本；有新内容时返回冲突，保留用户尚未提交的表单。通过同目录临时文件及 rename 原子替换，失败清理临时文件；仅在写入成功后返回新的配置与版本。此机制覆盖工作台内并发保存，并检测保存前可见的外部修改；不宣称与任意外部编辑器构成跨进程事务。

读取内容格式错误和 schema 错误应能区分于文件系统读写失败。错误信息说明下一步，避免向浏览器返回原始异常、凭据或完整配置内容。损坏文件由部署者修复后重新读取，页面不提供无条件覆盖损坏文件的入口。

## 界面与生效

沿用雾蓝工作台的色彩、字体和布局，左下角齿轮作为入口；面板包含项目列表与可展开的资源限制，显示实际配置文件位置，采用显式保存和取消。复用 `@open-folio/ui` 组件及现有 Radix 弹层交互；需要新增的通用表单部件放 UI 包，业务字段与交互放应用组件。使用已安装 Next.js 16.3.7 的 Route Handler 和 React 客户端状态模式。

项目字段使用常规表单，原型来源逐行输入；资源限制展示默认值和单位，未填写代表沿用默认。保存进行中禁止重复提交；字段错误保留输入，冲突提供重新加载操作；退出存在未保存改动的面板时确认放弃。空项目页提供直接配置入口，移动端提供可见入口，支持焦点恢复与 Escape。

保存后重新读取项目列表，作废旧项目读取和刷新请求，重新建立当前项目数据。当前项目仍存在且来源未改变时保留可用浏览选择；当前项目被删或来源变化时清除不再适用的来源与内容选择，再读取有效项目。自动首读去重状态随配置更新重置，避免更换仓库后无法获取新快照。

## 影响与验证

### 管理密码、项目邀请码和分享

用户已明确选择独立管理密码及链接自动验证并可通过换码撤销的方案。管理密码优先读取 `OPENFOLIO_ADMIN_PASSWORD`；未设置时按建议默认自动生成随机密码，私有保存至数据目录下 `admin-password`，由部署者读取。此初始化不开放给匿名页面设置，不回传密码或将密码打印到日志；用户已明确确认此初始化方式。

项目配置扩展可选 `inviteCode` 以兼容读取旧文件；保存完整配置时每个项目必须有非空邀请码。新建项目及历史项目编辑时默认补充足够随机的邀请码，管理员可更换。没有邀请码的历史项目只允许管理员访问，避免旧文件在升级后成为公开访问例外。

新增访问接口处理管理密码和项目邀请码验证。浏览器提交 JSON，服务端常量时间比较凭据并使用数据目录私有随机 `access-secret` 密钥签发 HMAC 凭证，消息绑定当前管理密码摘要及项目邀请码。签名密钥独立于用户密码，避免访客凭证成为离线猜测管理密码的验证器。持久 HttpOnly Cookie 自动覆盖 API、图片和 iframe 请求；使用 SameSite=Lax、固定站点路径，在 HTTPS 下启用 Secure。凭证不含明文密码或邀请码，不建立用户数据库；更改密码或邀请码后验证计算变化，旧凭证立即不能通过后续访问。浏览器的 Cookie 保留期和用户主动清理仍可能要求重新验证，邀请码本身不自动到期。

匿名项目列表返回 id、名称和是否锁定；只有管理员或已获该项目权限的浏览器才能读取项目摘要及其子资源。通用项目 API 和独立 Git 预览路由共享同一权限判断，所有配置访问要求管理凭证。管理员可以查看所有项目。正在进行的截图等异步读取返回前复核项目权限，避免换码或项目移除后返回受保护内容。

分享链接采用当前站点地址、项目查询参数与 `#invite=...` 片段。片段不随初次页面请求进入服务器 URL，客户端先移除地址栏中的凭据，再兑换项目 Cookie。成功后重新加载对应项目；失败展示邀请码输入及具体提示。复制链接来自已保存配置，新修改须先保存，防止分享尚未生效的邀请码。

配置面板未登录时显示管理密码输入；工作台中被锁定项目显示邀请码输入。表单和分享遵循现有 token、错误展示与移动端布局。HTTPS 和持久数据目录仍由部署环境提供；外部静态原型宿主的直接 URL 不由本站邀请码保护。

保留旧 `OPENFOLIO_CONFIG` 部署方式，新增默认文件行为无需迁移；需要写入的部署须给服务用户配置目录权限。页面写入后，现有 API 下一次读取同一个文件即可使用新配置，不增加第二份持久状态。

单元测试使用临时目录覆盖路径优先级、缺失文件与父目录创建、首读竞争、无损保存、校验失败、冲突和文件系统失败。浏览器测试使用现有独立配置与临时仓库，验证完整配置流程、保存后的项目切换、移动端和错误提示，每项修改后恢复测试配置。新增匿名、管理员和独立访客上下文验证所有数据入口、记住访问、分享、换码撤销及权限隔离。类型、格式、生产构建和相关阅读回归作为交付检查；不覆盖正在运行的生产预览产物。

已核对安装包 Route Handler、环境变量文档和现有配置 schema；既有 Radix 弹层及浏览器测试环境可复用。尚未实施或运行本次新增测试。
