# 独立评审

由独立 subagent 在隔离的评审上下文检查完整需求、方案、计划及实现差异；仅只读调查与内存复验，未修改实现或启动服务。

| 编号 | 发现与影响 | 修正与复验 |
| --- | --- | --- |
| R1 | 多篇文档复用引用标签时，后续文档的链接或 GFM 脚注会绑定到前文定义 | 全文按篇为普通引用及脚注命名；独立验证 full、shortcut、footnote 与代码块保留，通过；双文档回归通过 |
| R2 | Next 在代理后构造的 request.url 可能使用内部监听地址，绝对链接对外不可达 | 与个人会话共用现有 Host / HTTPS 协议解析，忽略 forwarded-host；独立评审通过实际 NextRequestAdapter 复验，代理 Host 回归通过 |
| R3 | 归档改变物理目录后，原本指向同 Change 的旧相对或根路径引用会失效 | 将当前 Change 逻辑活动路径映射到当前权威材料白名单；真实 Git 归档及越界拒绝回归通过 |
| R4 | 托管原型 URL 包含右括号时，生成的 Markdown 链接可能被截断 | 转义生成链接的目标分隔字符；合法 hosted URL 含右括号回归及独立复验通过 |

最终独立复读结论：上述问题均已关闭，未发现剩余实质问题；另外复验单篇、代码块、越界、超大目录与不读取正文的降级行为。测试、构建及界面证据见 Execution。
