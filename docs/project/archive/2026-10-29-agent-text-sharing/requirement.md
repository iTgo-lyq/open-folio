# Agent 文本分享链接

## 目标与范围

跨系统合作时，用户需要将一个 Change 的上下文交给其他人的 Agent。现有网页分享依赖浏览器及后续 API 请求，增加读取材料的成本。提供普通 HTTPS 文本分享链接，接收方无需登录或安装专用工具，一次 GET 即可取得 Markdown 内容。

复用现有单 Change 匿名分享范围、可读来源、权威分支和归档解析规则。分享跟随已推送内容，返回项目与 Change 身份、流程状态、澄清、任务和关闭记录，以及已存在的需求、技术、计划、调查、执行和评审等材料原文。每次返回注明采集时间、快照及各文档的分支、提交、路径，保持同一快照。

支持单篇文档链接。完整材料过大时明确说明正文未包含，返回完整目录和同快照分篇链接，不静默截断。图片及原型以带说明的绝对链接表达，注明视觉信息需要打开原资源；不自动解读或概括原文。关联材料不扩大到其他 Change 或仓库任意文件。

分享弹层同时提供网页和 Agent 文本复制入口，文案、样式由 Astra 子 agent 设计实现，沿用现有风格，支持窄屏、键盘和剪贴板失败时选中链接手动复制。用户已明确选择直接实现，不另绘原型。

## 验收

- 匿名 GET 链接直接得到 UTF-8 Markdown 文本，成功及失败响应均不返回 HTML 页面；HEAD 无正文。
- 正文包含目标 Change 的背景材料、当前状态、澄清与未决项、任务信息；原文完整且顺序稳定。
- 来源与版本可追溯；分篇、图片及原型链接为绝对地址且限定于当前 Change 和快照。移交及归档后，相对文档链接仍能定位当前权威材料。
- 大材料明确说明未包含正文，目录列出分篇链接；不存在或越界的文档失败，不夹带其他 Change 正文。
- 全部来源不可读、读取过程中失权或版本变化时不交付过期正文；临时错误给出可读错误信息，继承现有公开响应保护策略。
- 两种分享入口均能复制正确链接，失败可手动复制，桌面和窄屏清晰可用；现有网页分享继续可读。
