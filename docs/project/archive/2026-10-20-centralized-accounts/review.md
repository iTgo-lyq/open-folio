# 独立评审

由未继承实现对话的独立 subagent 只读评审完整差异、需求、技术与计划，覆盖新增文件、账号认证、归属、读取 lease、界面、冒烟和轮换。

## R1 登录响应与绑定列表并发

原实现把其他设备修改绑定引起的 revision 增长视为登录被替换，可能提交了新会话却未交付 Cookie。改为复核同一有效 deviceSessionId，返回最新摘要；真正已退出或撤销的会话仍拒绝。`personal-sessions.test.ts` 以登录后、响应前的受控命名复验通过。

## R2 Unicode 凭据输入

原表单的原生长度按 UTF-16 计算，服务端按码点，合法补充平面字符可能被截断。表单改为码点校验，原生上限仅作对应两倍长度的兜底。浏览器以 40 个补充平面字符的账号和 80 个补充平面字符的密码完成登录；定向回归通过。

两项修复已由独立评审静态复核；未发现其他有证据的实现缺陷。评审指出的同 Token 跨账号实际缓存／偏好／复制、失效当前凭据、延迟切换及另设备解绑等证据补测在 T2；真实浏览器进程与服务重启在 T3 核对。

补测定向复核已覆盖实际同 Token 两账号读取／复制／缓存／偏好隔离、延迟 switch 的撤销、另一浏览器解绑的晚到正文、当前 Token 后续失效以及浏览器和服务进程重启；四项证据缺口关闭。分类断言的调度顺序修正也经独立复核。实现修复及新增测试未发现新的明确问题。
