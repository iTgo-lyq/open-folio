# 仓库刷新后恢复最相关的工作台页面

仓库内容刷新后，工作台当前链接可能仍指向已移除的 Spec、Change、材料或原型。使用最新快照重新解析当前阅读位置，在所属仓库内打开仍可读的最近页面，并替换地址栏中的失效定位。

- Spec 消失时打开最近的上级 Spec，其次选择同一目录下的可读 Spec，最后使用 Specs 默认入口。仅章节消失时保留正文。
- Change 仍存在时保留其详情。刷新时被删除的材料或失效的附加材料深链回到该 Change 概览，当前原型入口或合入文件失效时回到所属材料。Change 已消失时回到 Changes 列表并保留原筛选。当前原型入口消失时回到原型总览，固定版本预览继续使用其指定版本。已消失的附加文档关闭抽屉并保留所在页面。
- 在成功读取快照后使用现有客户端导航替换地址，浏览器返回时可以继续使用此前有效的历史位置。以刷新完成时仍打开的页面为准。临时刷新失败保持已有页面。

验收覆盖页面停留期间远端删除目标、打开旧深链、自动与手动刷新、保留有效链接与列表筛选，并验证失效地址已被替换。
