# 精简整合技术方案反膨胀原则

## 目标与方案

用户要求将 `anti-bloat-review` 内容直接精简整合进技术方案指南。本次为 small：仅在 SpecTrail 技术方案章节补充一段方案取舍原则，并同步对应规范。

以已确认目标、范围和验收标准为依据，要求复杂机制对应实际需求、失败场景或必须保持的约束；缺乏依据的设计、兜底、审核、门禁及重复校验优先合并、延后或删除，说明影响与最小替代。保留必要保护与明确批准要求，显式说明授权或保护边界变化；聚焦少量有效调整，不新增审核层级或固定报告。

来源：[anti-bloat-review 原文](https://github.com/wp-a/codex-evolution/blob/main/skills/anti-bloat-review/SKILL.md)。本次为提炼整合，不是原样安装；沿用现有数据不兼容取舍规则，不恢复已回滚的测试策略。

## 验收

- 技术方案指南用一段话表达依据、减量取舍与必要保护。
- 不增加独立 skill、审核阶段、固定报告或测试门禁。
- skill 校验与差异自查通过，对应 Spec 与指南一致。
