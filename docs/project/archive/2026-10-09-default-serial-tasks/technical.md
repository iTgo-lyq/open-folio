# 方案

主 skill 提供无第三方依赖的共享任务顺序模块，读取 Plan 中实际的执行顺序表并生成任务图。没有显式表时按任务编号数值顺序建立串行链；已有执行顺序标题但只有文字说明时仍采用默认规则。显式表保留表格唯一性、覆盖、引用和循环检查。medium/large 缺少 Plan 文件与缺少可选表分别处理。

工作台调用共享模块并展示默认或显式来源；流程命令在进入执行、开始/完成任务及关闭步骤时核对顺序。启动和完成任务时检查全部前置链上的任务，阻止尚未完成的前置被越过。恢复失败提交、记录阻塞及返工操作保持可用，以便修复无效材料。

保持 JSON 状态契约及提交 hook 的结构校验范围。任务图的来源信息仅属于读取结果，不新增状态字段，不将流程检查加入提交 hook。

# 验证路径

解析回归覆盖数字排序、无表、显式并行、Markdown 示例、歧义/损坏表及循环；临时 Git 仓库覆盖真实语义命令、失败无写入、任务中途改表与关闭前复查。运行项目测试、类型检查和工作台浏览器回归，完成独立评审。
