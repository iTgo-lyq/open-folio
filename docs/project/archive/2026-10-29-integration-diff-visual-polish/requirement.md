# 统一合入变更阅读界面视觉

延续 [integration-readability](../../archive/2026-10-29-integration-readability/requirement.md)。上一轮已经修好合入差异的两栏等高与阅读控制，但用户验看后认为“还是很丑，很不协调”。对照截图核实的原因：文件列表用陶土色底、左侧色条和陶土色等宽文件名表示选中，紧挨着左侧材料导航的中性灰选中态，形成两套选中样式；差异卡片内白色文件头、灰色工具条、灰色 hunk 行与灰色列表列交替，条纹感重；一个列表条目混用等宽与界面字体及三档小字号，路径从末尾截断而丢失最近目录；顶部合入信息两端分散；增删行连同行号整行着色，行号栏偏宽、行高偏松，卡片下方留白。

本次只调整合入差异阅读的视觉层级与一致性，沿用现有数据、URL、复制兜底、窄屏导航和只读能力，不修改色板 token、不引入新的强调色或依赖、不改变服务端契约。

## 方案要点

- **合入信息**：标题下收成一行安静的元信息：合入目标、时间、可复制的短提交号与“只读”。文件总数与增删统计移入文件列表表头。原列表底部的范围说明移除，内容改为“只读”的悬停说明（需求 Q2）。
- **文件列表**：选中态与材料导航一致，使用中性选中底与加粗，不再使用主题色底、色条或主题色文字（需求 Q1）。文件名改用界面字体并与增删数同行；目录在第二行，从开头省略以保留最近目录。“修改”不单独标注，新增、删除、重命名等其他状态保留弱化文字。
- **差异面板**：文件头与工具合为一行，左侧为文件名与完整路径，右侧为自动换行与复制比较命令；取消独立灰色工具条，保留重命名、模式变化等元信息。
- **代码区**：收窄行号栏并以细分隔线区分；增删行背景减淡，行号栏略深以便扫读；hunk 行改为弱化细条；行高收紧。阅读卡片高度贴合视口底部。窄屏沿用“文件列表 → 差异 → 返回文件”，同步上述层级。
- 不单独绘制原型，在独立 worktree 实现后以真实页面前后截图交用户验收（需求 Q3）。

## 验收

- 文件列表选中态与左侧材料导航同一视觉语言；页面内主题色仅用于小图标与焦点，增删统计保留成功/危险色。
- 合入信息为一行，文件数与增删统计位于列表表头；底部说明不再出现，“只读”悬停可读到范围说明。
- 差异面板顶部只有一层文件头，包含文件名、完整路径、状态元信息与两个操作；两栏顶部、底部仍对齐，滚动不移动标题。
- 长路径、长行、自动换行、非文本提示与加载状态保持可读；1440px、834px、390px、320px 和浅色/深色下无页面横向溢出。
- 固定版本、文件深链接、历史导航、键盘焦点、窄屏返回焦点、复制命令及失败兜底继续有效，相关浏览器回归、类型检查与生产构建通过。
- 用户已对上一轮自验收结果提出问题，本 Change 由用户依据前后对比截图人工验收，后续返工同样需要用户确认。
