# Changes 展示规模列与标签

用户确认列表新增“规模”列，阶段看板保持阶段分列并在卡片标签区补充规模标签。本次延续 frontend-style-interaction-refactor 的规模展示，便于无需打开详情即可识别工作量。

## 方案与验收

- 列表在 Change 与阶段之间新增规模列，按主记录 size 显示 S、M、L、XL，悬停和可访问名称说明完整规模；来源无有效状态时显示“—”，不猜测规模。
- 看板在现有类型标签区显示相同规模标签，复用 Badge 样式，不增加阶段列。
- 桌面和平板保持列头与内容对齐；窄屏保留紧凑规模与任务进度，无页面横向溢出。
- 保持现有筛选、排序、阶段和详情行为；验证四档规模、无状态记录、标签换行和卡片导航。
- 用户追加详情优化：紧急程度为 normal 或未填写时不显示“普通”，显式 urgent/high/low 仍显示。筛选和排序仍按未填写等同普通处理，类型标签不变。

仅涉及列表与卡片呈现和响应式 CSS，核心契约不变，按 small 实施并自验收。
