# 原型关联必须指定入口 ID

主仓库关联子模块原型时，省略 `--entry` 会将发布清单里所有已发布的原型写入 Change。按「entry 不该是可选」的要求，`prototype associate` 每次只关联明确指定的一个已发布入口。

CLI 将 `--entry <id>` 列为必填，关联逻辑按 ID 精确查找。帮助、发布后的指引和文档采用相同用法。需要关联多个入口时，每个 ID 执行一次，最后一起提交；关联同一 ID 时更新该项，保留 Change 中的其他引用。

验收时使用含多个已发布入口的前端清单。省略入口、传入空值或指定未知、未发布的 ID 时，命令报错且 Change 和快照均无写入。指定有效 ID 时仅关联对应入口；依次指定两个有效 ID 时，Change 保留两条引用。
