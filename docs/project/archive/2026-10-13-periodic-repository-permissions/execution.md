# T1 执行记录

## 实现

按 PersonalSessions 实例、凭据工作台 UUID 与稳定仓库 key 共享进程内权限状态。成功结果固定复用 5 分钟，读取不会滑动延长期限；首次或过期检查属于工作台，合并并发并独立于单设备退出。列表、私有正文、搜索、图像、原型及刷新共用结果；公开原型真正新增发布前即时复验。

明确 READ_DENIED / REPOSITORY_MISMATCH 清除该仓库权限；TOKEN_INVALID / IDENTITY_CHANGED 清除该凭据所有仓库的状态，并阻止较早的检查回填。交付前仍检查本地设备与已确认拒绝。Git 错误主动复验后按实际权限或原错误返回；网络、限流不被前端作为失权清空当前正文。发现与手动仓库检查所遇到的明确拒绝也同步使权限结果失效。
