# 原型截图返回总览时即时显示

原型总览和详情已经知道已发布截图的固定地址，但仍等待公开版本准备接口。看过的自动截图也会在返回总览后等待同一接口，造成加载态闪现。

## 方案

总览和详情直接读取清单中所选设备的固定截图 URL。没有对应设备图时沿用自动截图，成功的准备结果复用工作台内存缓存，按访问身份、仓库、集成分支、固定提交和入口隔离。公开预览仍按现有流程验证和准备。复用已显示截图时交由浏览器读取原图，省去加载提示的闪现。失败的准备结果可重新发起，图片加载失败可单独重试。

## 验收

- 延迟准备接口时，已发布的设备截图仍能在总览与详情中显示，详情切换设备读取对应的固定 URL。
- 自动截图首次缺失时有加载提示，准备失败后可重试。成功后可在详情、总览之间复用，并从画布返回时直接显示，即使准备接口仍有延迟。
- 图片本身出错后可重试。不同身份、仓库或固定版本不复用旧截图信息。
