# 工作台展示澄清问答

## 背景与目标

在工作台回看 Agent 提过的问题和用户最终回答，便于核对需求澄清。

## 范围与行为变化

- ADDED：Change 详情概览在目标与材料下展示澄清问答，按 Q 编号数值升序排列，直接呈现问题与最终回答。
- 未回答显示“未回答”，撤回保留问答并标记“已撤回”；没有记录时隐藏整个区域。活动与归档记录均适用。
- 只读展示，沿用现有字段；不增加编辑、回答历史、轮次、推荐或来源展示。

## 方案要点

先绘制并发布原型，再沿用详情样式实现。读取主来源的 clarifications，以纯文本列表呈现，长文自动换行。

## 验收标准

- 详情可读到问题及最终回答，Q2 排在 Q10 前，不把推荐或撤回原因显示为用户回答。
- 未答、撤回及旧记录无问答的情况可明确区分，桌面与窄屏均可阅读完整内容。
- 原型与实际界面完成浏览器验证，类型检查通过，开发机服务更新并验证。
