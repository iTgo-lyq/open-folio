# 需求确认后移交独立工作区

需求文档提交并按规模确认后，从最新交付目标建立或复用所属 Change 的独立分支和 worktree。原型、技术方案、计划和实现均在所属工作区推进；绘制前识别与其他进行中 Change 的重叠，提前安排公共修改、依赖和合入顺序。

移交不再等待技术方案、计划、任务或依赖交付；small 沿用现有确认规则，暂缓仍阻止移交。执行和关闭检查保持有效。同步主 skill、原型规则、移交说明、脚本及必要回归测试，按分发约定递增补丁版本。本次为 small，仅调整既有移交前置条件。

验收：各规模可在需求就绪后移交，未确认需求和显式暂缓仍被拒绝，缺少方案、确认、任务或依赖时不能执行；移交回归、skill 校验及版本一致性检查通过，规则措辞精简。
