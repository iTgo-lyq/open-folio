# 冒烟验证结束后可靠退出测试会话

真实服务已复现：脚本登录后不携带 `X-OpenFolio-Revision` 退出会返回 409，测试会话继续有效；连续两次验证使设备数由 1 增至 3。此前临时冒烟脚本没有统一的退出与结果校验流程。

本次补齐可复用的登录会话生命周期工具。冒烟检查内容继续由负责任务的 Agent 选择，不增加固定业务冒烟场景。用户已明确要求成功或失败都退出测试会话，并检查退出结果。

## 行为与方案

- 每次调用使用独立的请求上下文和 Cookie，不复用用户浏览器登录；Token 由调用方从 Git 忽略的环境配置注入，不输出凭据。
- 登录、响应解析和检查回调都包含在统一清理范围内。检查成功、断言失败或请求失败后，都执行清理。
- 清理读取最新会话版本，通过现有退出或身份移除接口撤销该测试浏览器的授权，检查 HTTP 状态，并再次读取确认 `connected=false` 且无记住的身份。
- 版本冲突或短暂请求失败允许有限重试；重试仍失败明确报错，不能报告冒烟成功。检查与清理同时失败时保留两项错误。
- README 给出调用示例，AGENTS 明确真实登录冒烟必须使用该工具。工具不重置工作台、缓存或其他浏览器登录，不调用退出全部设备。

进程被强制终止、服务持续不可达或登录响应完全丢失时，客户端无法保证服务端已完成退出；可捕获的清理失败必须报告，不能吞掉。此次不改变登录服务协议或页面文案。

## 验收

正常回调与故意失败的回调均在结束后清除自己的会话，原有设备和工作台保留。覆盖登录后的解析失败、最新版本号、版本冲突重试、退出假成功与永久清理失败；后者必须使调用失败且保留原检查错误。最后用真实服务分别跑成功和故意失败的冒烟，确认设备列表恢复到开始状态。
