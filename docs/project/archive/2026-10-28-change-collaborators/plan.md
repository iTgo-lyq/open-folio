# Change 协作者交付计划

按 T1 → T2 串行推进。沿用已确认的 `quiet-changes` 固定原型；技术数据口径见 Technical。

## T1：识别协作者并兼容个人视图配置

交付：批量收集 Change 材料的 Git 提交作者，创建者优先且成员去重，支持工作分支、活动/归档目录与快照刷新。工作台及必要的分享投影只返回公开身份信息。增加默认隐藏创建者的视图开关，保留旧账号、旧视图及 URL 恢复行为。

验收：创建人和后续推进人均正确出现；其他文件修改和纯合并操作者不计入；归档不丢失成员；邮箱不进入响应。既有个人视图可继续读取，开关可以读写保存并恢复，筛选含义保持现状。

验证：临时真实 Git 仓库测试与相关快照、分享、个人视图测试；类型检查。

## T2：实现协作者展示并验证原型还原

交付：列表、看板和归档时间线共用头像组与完整名单弹层；创建者列默认隐藏且可恢复；个人视图编辑保存包含开关。手机布局、键盘及焦点行为与原型一致。

验收：单人、少量及大量成员可阅读；创建者始终第一，完整名单可滚动；触发协作者不会导航到 Change；已有进入详情、筛选、切 tab 和返回行为正常。浅深主题与桌面、平板、手机布局符合已确认的原型。

验证：必要的浏览器场景和相关回归、类型检查及生产构建；复用常驻 Chrome 验证 1440/834/390/320px，按固定版本完成原型还原检查。medium 整体差异独立评审后交用户验收；通过后同步 Specs、归档并更新 PR。

## T3：修正 T1 的协作者来源隔离

独立评审 R1 发现 T1 按所有已路由分支汇总可能混入无关工作分支的材料作者。本任务修正该边界：仅纳入集成来源和该 Change 正式材料来源可达的历史，仍按来源批量读取，不逐 Change 请求远端。

验收：未合入的其他工作分支修改同名目录不影响当前 Change；该 Change 正式工作分支的作者仍展示，合入后成员正确继承。分享投影同样遵守来源范围。

验证：增加真实 Git 隔离回归，运行相关测试、类型检查与生产构建，独立复核 R1。此任务在 T2 后串行执行，再做真实工作台检查。

## T4：修复单人协作者姓名的垂直截断

用户验收截图显示 `iTgo-lyq` 等单人名称的文字上下边缘被裁切。修正名称的行高与裁切区域，保留长名称的横向省略和原有头像/弹层交互。

验证：通过常驻 Chrome 和专用冒烟会话检查真实姓名的字形边界、浅深主题及桌面/手机截图，构建后更新同一验收入口。此任务在 T3 后串行执行。
