# 修复分享文档的 YAML 元数据渲染

分享带有 YAML front matter 的 Markdown 时，左侧文档名取正文第一个 H1。没有 H1 时沿用首个其他标题、文档路径的回退顺序。正文和目录从正文开始展示。

标题索引和正文共用同一规则，只识别文件开头由两行 `---` 包裹的有效 YAML 映射。正文的普通分隔线与 Setext 标题按 Markdown 语法处理。保留原文及正文节点的源位置，刷新时重新生成旧的标题和目录索引。

用带 front matter 的 `SKILL.md` 验证分享页左侧文档名、正文和目录，并覆盖无 H1 的回退、普通分隔线与 Setext 标题。
