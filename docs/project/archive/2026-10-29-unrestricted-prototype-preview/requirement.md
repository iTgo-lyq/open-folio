# 放开原型预览能力限制

原型 iframe 和 OpenFolio 提供的 HTML 响应当前附带沙箱、CSP 和权限禁用策略，导致 `window.confirm` 等浏览器能力无法使用。用户明确要求原型功能完全放开，不局限于修复单个 API。

移除工作台、Change 分享及公开原型页面的 iframe 沙箱和能力禁用，向跨域原型委派浏览器支持的权限策略功能；移除 OpenFolio 原型资源响应上的 CSP、Permissions-Policy 和嵌入限制。浏览器自身的权限确认、安全上下文、同源规则和第三方宿主策略继续由浏览器执行。

保留固定版本、文件白名单、摘要校验、公开撤回和工作台接口认证。Git 兜底仍采用自包含单文件产物；缩略图生成继续使用独立的受限后台浏览器，不影响交互预览。同步原型验证工具和能力文档。

验收覆盖工作台、Change 分享、公开预览以及直接打开的托管原型：确认对话框能够真实弹出并返回选择，存储、网络、表单、嵌套 iframe、Worker、弹窗及下载不被 OpenFolio 策略拦截；跨域原型的设备能力不再被容器禁用。运行相关测试、类型检查和构建。

本次为 small：主要删除既有策略并统一容器权限配置，不变更持久化格式或发布协议，以一个任务交付。
