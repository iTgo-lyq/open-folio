# 兼容 PR 正文中的 Change 标记位置

Change PR 的正文末尾可能有 Claude Code 自动追加的署名。署名会使现有解析器漏掉前面的独立标记段落，导致预检与合入核实无法判断 PR 关联。

## 方案与验收

- 读取正文中唯一、独立的 `SpecTrail-Change: <id>` 标记段落，允许它后面有署名或其他正文段落。忽略代码示例和正文中的普通提及，拒绝重复或冲突的标记。发布 PR 沿用末尾元数据段落。
- preflight 区分同仓库、同源目标分支的有效未合并 PR、标记缺失或不符的未合并 PR，以及尚无未合并 PR。标记异常时提示对应 PR 编号并阻止预检通过。
- 共享解析用于预检、合入核实、归档 CI 和工作台。工作台刷新时重新读取按旧规则解析的 PR 页面。
