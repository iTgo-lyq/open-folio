# 执行记录

## T1 批量获取分支并并发补齐远端历史

集成分支提供配置和集中登记后，发布分支与工作分支合并为一次精确广告查询；已变化的引用通过一次 atomic fetch 获取，实际取得的提交供后续读取复用。未变化引用跳过 fetch，缺失分支不采用残留引用，保留最后的集成配置/路由复核。可选发布来源造成批次失败时，仅将必须读取的工作来源作为一个批次重试一次；工作来源仍失败则保留原有刷新失败边界。

仓库 PR 目录读取与 Git 采集重叠，沿用同一目录缓存中的查询 Promise、条件请求和更新时间分页。首份列表不等待 PR；最终投影复用查询结果。后台查询立即观察异常，凭据拒绝中止采集并保留原错误，Git 失败及取消会结束并等待该查询；PR 与 tag 缓存仍在发布前权限核实后落盘。

自查核对了来源归属、固定提交、发布源降级、PR 查询复用、权限与取消边界。改动限定于 Git 获取和刷新调度，未改变外部协议、缓存格式或发布事实规则；生产新增/实质改写少于 300 行，保持 small。
