# 材料推送后直接提供分享链接

## 目标与范围

材料已推送时，Agent 直接提供对应 Change 的工作台链接，用户进入网页后由页面刷新获取内容。分享前请求接口、核对远端内容和等待同步会把正常同步延迟变成额外阻塞，需要从 skill 流程中移除。

需求来源：用户明确要求“把 skill 里的分享规则也改掉，材料推送后直接给链接，不用验证接口或等待工作台同步。简化 skill。”

覆盖主 skill、原型分享指引和链接辅助脚本，并同步相关使用说明。分享页当前的读取、错误提示和刷新行为保持既有实现；页面可能先显示来源暂不可用，随后自动或手动重试。

## 方案要点

分享脚本只读取本地 workflow 和 origin，构造带 repository、integrationBranch、change 及材料定位参数的稳定链接。删除 HTTP 请求、远端正文和原型比对、轮询等待与对应参数；返回链接不附带未经核验的服务分支或提交信息。未配置服务地址时给出仓库材料入口。

## 验收

- 材料推送后，skill 指引 Agent 直接给链接，不要求验证工作台接口或等待同步。
- 概览、文档和原型链接保留正确定位参数；服务不可达或尚无新数据时仍可生成链接。
- 文档和原型共用同一规则，不再宣称生成链接代表内容已同步或验证可访问。
- 本地配置和地址参数错误仍给出明确错误；不修改工作台服务、登录或数据。

## 验证

运行链接脚本测试，覆盖离线生成、材料定位和配置错误；校验 skill 并检查相关说明一致性。
