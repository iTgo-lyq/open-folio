# 工作台 PR 差异预览交付计划

[需求与验收](requirement.md) · [技术方案](technical.md)

## T1 在合入变更页预览待合入 PR 并自动切换正式差异

- 从授权的工作台快照读取唯一开放 Change PR 的文件列表和 diff。复用当前页面与自动刷新，显示 PR 状态、链接及异常提示，合入后显示正式差异。
- 开放及 Draft PR 可审阅，新提交刷新后可读，合入后同页自动切换。缺失、歧义及读取失败可辨识，公开分享无法读取未合入文件列表或 diff。
- 用真实 Git 对象和 PR 夹具验证提交边界、快照更新及私有和公开入口的结果，再运行浏览器回归核对同页更新及状态提示。

## T2 自动换行时保持 diff 行号列宽一致

- 修正验收发现的行号列变宽，切换自动换行时保持新旧行号列宽度一致。
- 扩展现有浏览器回归，测量桌面与窄屏换行前后的宽度，同时检查长行换行和横向滚动。

## T3 大 diff 正文默认折叠并支持按需加载

- 文件列表继续显示路径及增删统计。单个 diff 超过 1,000 个展示行或 128 KiB 时，返回折叠状态，用户可按需加载正文。
- 复用现有 1 MiB 和 10,000 行读取上限及 Git 比较命令。回归覆盖两种折叠门槛、手动展开、换文件或刷新及超出硬上限的情况。

## 整体验证

运行单元及集成测试、类型检查、构建和相关浏览器回归，核对目标行为与访问边界。人工验收通过后同步 Change 跟踪的 Specs 并归档。
