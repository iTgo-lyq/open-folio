# 取消工作台请求的 Host 校验

## 背景与目标

用户明确要求“完全删除 `Host` 校验吧，目前不需要”。当前阶段不接入多用户管理，部署入口的主机名不再作为请求是否可用的判断条件。

## 范围与行为变化

`project-knowledge`：REMOVED 请求 `Host` 以及请求 URL 主机名的允许列表校验，覆盖 API、Git 原型页面和缩略图的公共请求校验入口。

保留既有 `Origin`、跨站请求、已配置项目、快照和文档范围校验。刷新仍要求允许的 `Origin` 和空请求体，原型托管来源仍由 `prototypeOrigins` 控制。

## 验收标准

- 请求主机名未登记、与代理内部地址不同或请求 URL 使用其他主机名时，读取请求通过公共请求校验。
- 合法 `Origin` 的刷新请求不因 `Host` 不同而失败。
- 非法 `Origin`、跨站请求及缺失 `Origin` 的刷新请求继续返回 403。
- 部署文档说明 `allowedOrigins` 仅参与来源校验，不再要求代理为 Host 校验保留主机名。

本次调整请求访问边界，采用 medium 规模，交付一个聚焦任务。
