# 支持工作台文档图片大屏浏览

读者可以在工作台点击 Markdown 正文中的仓库图片，打开铺满窗口的查看器，放大并拖动查看图表细节。键盘可以打开和缩放图片，按 Esc 或点击关闭按钮返回原阅读位置。通过普通文档链接打开的图片也可继续放大。Markdown 中给图片设置的超链接继续作为导航入口。

复用工作台现有对话框管理焦点和嵌套弹层，使用 Yet Another React Lightbox 的缩放插件处理图片适配和手势。大图继续使用正文中同一权限和快照范围的资源地址，匿名分享页沿用相同交互。

在工作台和匿名分享页验证打开、缩放和关闭，确认关闭后保留阅读上下文与键盘焦点。验证抽屉中关闭大图时抽屉保持打开，图片原有加载限制及链接行为继续有效。
