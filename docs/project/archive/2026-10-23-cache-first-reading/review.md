# 独立评审

独立只读评审使用与实现隔离的 subagent，核对整个分支相对 develop 的差异、需求、技术方案、计划及测试；最终复查包含 T3 自动恢复与 T4 修正。评审未改代码或重复运行主任务测试。

## R1 更新期间切换材料

初版 prepare 仅在开始时枚举当前材料，A 新正文挂起时切到 B 可使新快照先于 B 正文展示。T4 在每轮 IO 后重新核对当前 readers，准备新增的阅读项；单测通过挂起 A、切换 B、继续挂起 B 验证完成条件。复审确认问题已关闭。

## R2 原型目录连续显示

初版新快照改变目录 key，目录挂起或失败时旧列表消失。T4 将当前原型目录纳入同一快照准备过程，目录成功后才切换整个版本；失败保留旧快照、目录和资源版本。浏览器覆盖挂起、503、恢复。复审确认问题已关闭。

## R3 目录确认失权

初版事件过滤遗漏目录接口的会话/绑定失效错误，叠加会话轮询网络失败时旧正文可继续展示。T4 将当前连接的 SESSION_REQUIRED、CONNECTION_CHANGED、CONNECTION_NOT_FOUND 纳入作用域清理，取消旧交付并清缓存。浏览器分别覆盖三个错误与会话网络失败组合。复审确认问题已关闭。

## 最终检查

独立复审未发现新的需修复问题。自动选用沿用服务端 Token 身份验证、浏览器修订号与提交前归属核对；迟到自动请求不能覆盖新选择，失败保留登录与手动选用入口。README 与实现一致，diff 空白检查通过。实际测试与构建结果见 execution.md。
