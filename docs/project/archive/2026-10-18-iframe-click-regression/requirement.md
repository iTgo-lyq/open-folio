# 修复托管 iframe 点击回归超时

原型浏览器回归中，`loaded hosted pages need no ready bridge and explicit errors survive page load` 在点击 iframe 内「已添加 0 次」时稳定超时，报告 html 拦截指针。前次截图修复已经用未修改测试复现，用户明确要求继续排查并修复。

## 范围与方案

按 small 推进。实验确认 Playwright 1.63 对隔离 iframe 的子元素坐标只增加 iframe 偏移，没有应用 CSS 缩放；真实鼠标按可视位置点击正常。仅调整测试：握手生命周期使用 100% 视图，另加适应画布与 100% 两种模式的鼠标回归，按元素实际布局换算坐标并检查命中、可信点击事件与计数更新。保留默认适应画布、隔离 iframe、可选 ready 握手、显式错误及重载行为，不改变产品实现或原型协议。

修复后保留真实鼠标交互检查，不用强制点击、DOM click、跳过测试或延长超时掩盖失败。记录最小复现及工具实现证据，避免将工具坐标问题误认为产品的鼠标遮挡。

## 验收

- 查明超时的具体原因，以最小实验区分测试问题与真实点击障碍。
- 点击可使计数更新；不提供可选 ready 握手的已加载页面在 5 秒后仍无告警，显式 error 继续显示，重新加载能恢复页面。
- 覆盖适应画布和 100% 下的交互，受影响测试定向复验及原型浏览完整回归通过，类型检查通过。
- 实现影响运行服务时，在 develop 集成后更新服务并验证；真实登录按仓库约定清理本次测试会话。
