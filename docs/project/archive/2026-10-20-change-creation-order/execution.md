# 执行证据

## T1

Git 按已读取分支提交批量扫描首次新增记录，覆盖各 merge parent 和归档路径，取同 ID 最早提交者时间。可重建快照增加可选 createdAt，列表倒序、相同时间按 ID、未知时间置后；升级扫描指纹，旧缓存刷新时重新索引。延续组保持现有匹配成员顺序。

验证：`npm test` 240/240 通过；`npm run typecheck` 通过；`npm run build` 通过。新增真实 Git 仓库测试覆盖创建、后续修改、合并提交独有新增、归档及热缓存；排序测试覆盖同时间和未知时间。首次 worktree 构建因外部 node_modules 符号链接被 Turbopack 拒绝，改为本地 npm ci 后构建通过。

Agent 自查：不修改工作流持久化契约，不依赖文件系统时间或归档时间；Git 历史读取失败沿用快照刷新失败路径，不伪造时间。真实未提交创建时间不可还原，提交时间以可达 Git 历史为依据。
