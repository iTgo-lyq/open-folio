# 验证证据

## T1

托管截图复用现有缓存、OS 沙箱与原子公开版本，按视口保留项目图片并补齐缺失项。当前总览、详情、私有截图接口及 Change 分享均采用该优先级；托管页面预览独立于截图准备。既有 hosted 公开版本不改写，新的准备标识可生成缺失图片。生产实现差异不足 300 行，沿用 small。

- 全量 Node 测试 314 项：313 项首轮通过；未修改的服务生命周期项首次停止超时，单独复跑通过。截图、公开版本与分享的定向测试全部通过。
- 浏览器共 19 个相关场景通过：原型总览与详情 12 项、分享 2 项、截图 5 项。新场景确认无图托管卡片及详情实际加载 1440/390px 图片，公开图片字节重复读取一致；截图准备失败仍可打开托管 iframe。夹具清单与选择器错误已修正并复跑对应失败场景。
- 独立 HTTP 主机及跨域模块、样式、图片真实渲染通过；验证空白 Cookie、503 失败、脚本卡死超时及后续恢复。另以外部 HTTPS 页面实际生成 390×844 JPEG。
- `npm run typecheck`、受影响文件 Prettier、`git diff --check`、`npm run build` 及 skill `quick_validate.py` 均通过。
- Agent 自查覆盖设备/组件视口、部分覆盖、全部覆盖时不渲染、缓存复用、旧公开版本保留、来源权限复查与失败后的直接预览。沿用部署出站代理；不注入账号、仓库凭据或用户浏览器资料。
