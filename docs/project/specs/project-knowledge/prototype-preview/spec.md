# 原型浏览与预览

OpenFolio 在[项目知识工作台](../spec.md)提供独立「原型」模块，以及 [Change 详情](../change-tracking/spec.md)内的原型标签。工作台只读中心 Git 中已推送的关联和静态产物，开发由项目内 Agent 与 SpecTrail 原型子 skill 完成。

## 单一原型包与关联

一个项目维护一个 Git 跟踪的 monorepo 原型包，默认 packages/prototype，复用用户已有的设计规范和组件库。用户自由选择源码组织与工具；源码、依赖声明、设计引用和导出的静态 HTML 都由 Git 管理，不提供模板服务、在线编辑或云端构建。

项目选择写入 docs/project/workflow.json 的 prototype：缺失表示未选择，disabled 表示拒绝，pending 表示接入未完成，enabled 表示可追踪。拒绝后不反复提议或新增关联，用户明确重新同意后才启用。包初始化失败保持 pending，不覆盖已有设计与源码。功能开关从服务配置的 specBranch（未指定为远端默认分支）最新成功快照读取；正常部署使用已登记守护分支。旧版本不能绕过当前停用选择。

Change 的 previews 数组直接声明多个页面或组件，不使用独立 prototype.json。每项含 id、title、包内 preview 入口文件夹 path 和 kind。页面必须声明 pc-web/ipad/mobile 中非空、去重的设备集合；组件可声明设备集合或 viewport 宽高，二者互斥，自定义尺寸为 1–4096 的整数 CSS px。多个入口共用一个工程，不为每个页面建立独立包；不同 Change 可以复用同一入口。

主 skill 的 previews-set 命令维护关联，staged hook 校验暂存入口与契约。用户无需提交截图；服务截图仅为可重建缓存。

## 项目总览与内容卡片

原型清单从文档快照中各 Change 的权威记录汇总，按路径和类型去重，展示页面、组件、关联 Change 数量。提供名称/路径/Change 搜索、类型与适配筛选、分页。多个来源保留各自关联版本，不合并字段或把分支副本计为额外原型。

卡片以真实首屏截图为主体，底部仅保留可点击名称、轻量类型与更多按钮。路径、适配、截图尺寸、来源状态和版本选择在按需浮层显示；浮层支持触屏、键盘退出和焦点恢复。切换来源同步图片与打开预览的版本，可跳到来源 Change。截图失败保留名称预览入口并支持重试。

统计表示有效关联数量，不提前保证每个产物可用。停用、空项目、无匹配、关联非法和来源不明分别提示；局部异常不遮蔽正常关联，只有来源异常时不误报空项目。模块/项目切换和浏览器前进后退保留或清理对应上下文，固定版本链接可从原型模块恢复。

## 固定版本与画布

页面使用声明设备的 CSS 视口：PC Web 1440×900、iPad 834×1194、移动设备 390×844；组件使用声明的固定尺寸或设备。画布提供方向切换、适应与 100% 查看，缩放不改变 iframe 实际布局宽高。设备选项是尺寸预设，不模拟设备硬件。

活动 Change 读取其主来源固定提交。固定链接记录完整 revision，保持整个包、关联与 HTML 来自同一提交；来源可达性、当前开关和资源范围每次检查。原型归档以 spec-trail/archive/<change-id> 标签保留交付提交和源码；主分支与标签推送并核对后才完成交付。删开发分支不影响有保留标签的历史预览，标签缺失或已观察标签被改写会明确报错，不回退最新版。

预览缺失、非法路径、符号链接、LFS、超限、配置或来源异常均有诊断，旧无 previews 的 Change 正常显示尚未关联。服务不会自动安装依赖或运行仓库构建脚本。

## 静态交付与同域隔离

每个入口包含 UTF-8 自包含 index.html：脚本、样式与 mock 内联，图片/字体使用 data URL。不依赖外部 import、动态 chunk、网络请求、真实后端、持久存储、Worker 或 eval；基础导出工具支持共享代码和资源内联，其他开发框架自行提供符合约定的导出。

原型与工作台共用域名、端口、进程和私有访问入口。iframe 只授予 allow-scripts，不授予 allow-same-origin；HTML 响应头同时设置 CSP sandbox，直接导航仍受沙箱限制。opaque origin 无法读写工作台 DOM、Cookie、存储或 API。CSP 禁止网络连接、外部脚本/样式/图片、嵌套 iframe、表单、对象及 worker，仅允许内联脚本/样式与 data 图片/字体。API 不接受 Origin:null，不增加 CORS 或匿名资源通道。

局部交互使用页面内存，重载重置。沙箱不承诺消除浏览器漏洞或所有自身导航，原型产物不得包含秘密。HTML 响应 private,no-store；只能经已关联入口与固定提交请求，不接收任意文件路径、仓库或 URL。

## 首屏截图与缓存

可见卡片按需请求截图，默认用第一个声明设备，设备筛选后图片与交互预览使用相同尺寸。图片保持原比例，不把压缩缩放后的展示尺寸当成原型适配。来源切换清理旧图片状态；等待、错误、重试与预览操作独立。

服务在启用 OS 沙箱的独立 Chromium 空白上下文中离线渲染已校验 HTML，不携带用户登录态或宿主凭据，拦截网络/WebSocket，不运行构建工具。浏览器为部署依赖；每任务有总时限、强制终止及受限并发队列。

缓存键包含项目/仓库、HTML 内容摘要、视口及渲染器版本，内容不变时跨无关文档提交和服务重启复用。权限、当前开关、关联及历史引用独立于缓存键，命中和 304 也重新检查；生成结束再次检查撤销。缓存命中只读取当前入口正文，仍保留整包树元数据与容量边界。

图片保存在私有数据目录，原子写入，可删除重建；默认总量 100 MiB、闲置 7 天回收、单图 4 MiB，失败短暂退避，相同任务合并。最多两个浏览器并行，24 个排队任务，排队和渲染均有超时。响应 private,no-cache,must-revalidate 与 ETag，不放入公共静态目录或公开 CDN。
