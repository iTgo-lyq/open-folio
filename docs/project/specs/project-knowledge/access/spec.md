# 个人访问与分享

## 凭据工作台与设备会话

用户输入 token，服务验证平台身份后建立或恢复凭据工作台。同一受信平台实例与完全一致的 token 对应同一工作台；不同 token 即使属于同一平台账号，也分别保存凭据、发现、缓存与偏好。新设备或清除 Cookie 后重新提供相同有效 token，可恢复原工作台。通用身份模型不依赖 GitHub 用户 ID 或 OAuth；公开版本只提供 GitHub.com 适配器。

“用户名”是最长 100 字符的可选显示名称，允许中文、内部空格及冒号，拒绝控制字符；省略、空字符串或纯空白视为未指定。首次登录未指定时使用 Git 账号名，恢复时保留原名称；自行填写无需与平台账号一致，不参与鉴权、工作台匹配或缓存归属。Git 传输用户名来自适配器验证的身份。登录输入兼容既有 label 字段，显式 label 优先于 username。

每个浏览器建立独立设备会话，只属于一个工作台。浏览器使用随机 HttpOnly、SameSite=Lax Cookie，HTTPS 下为 Secure；服务端只保存 Cookie 摘要。设备会话采用 30 天闲置期限和 90 天绝对期限，已认证活动每天至多更新一次闲置期限。Cookie 初次签发覆盖绝对期限，普通读取不写或清 Cookie；登录、旧 Cookie 恢复与主动退出才变更 Cookie。新增设备不会轮换其他设备的 Cookie；刷新与服务重启恢复有效会话，绝对期限到达后需重新提供 token。

切换凭据先验证新 token，成功后创建新设备会话并在同一次提交中撤销当前设备旧会话，失败保留原登录。相同 token 恢复原工作台，不同 token 进入独立工作台；其他设备原有会话不受影响。前端切换、退出或过期时清除旧正文、列表、错误与临时凭据，晚到请求不能恢复旧账号或阅读内容。

当前凭据页展示设备列表，只允许列出或撤销当前工作台的设备，不返回 Cookie、摘要或详细网络指纹。退出当前设备或撤销单台设备只终止对应会话与在途交付，共享任务继续供其他设备使用；退出全部设备撤销该工作台所有会话并中止共享任务。过期设备会话在后续会话操作时清理。退出或到期保留工作台凭据及已提交缓存，再次提供相同有效 token 仍可恢复。

## 凭据存储与主动复制

服务在私有 `personal-v2/state.json` 保存凭据工作台、设备会话与旧 Cookie 选择映射，归属与撤销原子提交。目录权限 0700，状态与秘密文件 0600；工作台和设备会话各最多 10,000 条，单工作台最多 32 个有效设备会话。

工作台使用随机 UUID；服务端以独立 32 字节 identity-key 对平台、实例与完整 token 计算 HMAC-SHA256 匹配索引，不以可变用户名或 subjectId 合并账号。token 只去除首尾空白，保留大小写及内部字节。索引不进入响应、URL 或目录名。

token 采用 AES-256-GCM 加密，使用独立 nonce 和绑定存储版本、工作台、平台实例的 AAD；独立 32 字节加密密钥来自私有 credential-key 或外置密钥文件。状态、加密密钥与身份密钥必须配套备份，缺失密钥或解密失败时拒绝恢复，不生成新密钥覆盖既有数据。停机密钥轮换先验证全部原密文与匹配索引，再生成成套替换数据，保留工作台 UUID、设备会话及缓存归属；更换平台 token 仍进入独立工作台。

token 不进入 URL、日志、Git 配置、localStorage 或 sessionStorage；表单提交后清空输入，普通会话、设备和仓库摘要不包含明文。用户主动点击“复制 token”时，同源 `POST /api/session/token` 仅读回当前设备已登录工作台的凭据，不接受目标工作台、连接 id 或批量导出。响应前复验会话仍有效，响应采用 private、no-store。剪贴板不可用时提供本次操作的临时只读文本，关闭、切换或退出时清除；不生成另一个登录秘密。

## 旧连接恢复

旧 personal-v1 部署按平台实例与完整解密 token 迁为工作台，不能按账号名或 subjectId 合并。迁移验证旧状态、配套密钥和全部密文，重新生成新 nonce 与 AAD；保存来源摘要和稳定映射，经 staging 验证后最后发布 state.json。中断可幂等继续，原状态、密钥与缓存保持备份；缺失密钥、来源改变或无法解密时停止恢复并保留现场。

只有可证明属于相同 token 的旧发现与缓存可恢复。同 token 同仓库多份缓存选择完整且最新的一份，不拼接不同 refs 或快照；不能证明来源的文件只留旧备份。新设备输入一个 token 不能枚举旧会话的其他 token。

单连接旧 Cookie 在页面取得摘要后自动 POST 恢复，多连接旧 Cookie 明确选择原会话拥有的凭据。兑换重新验证 token，成功后原子撤销一次性选择凭证并签发独立设备 Cookie；不能凭 connectionId 单独登录。回退须停机并恢复旧版本及配套 v1 数据，保留新版目录；新 Cookie 不转换成旧 Cookie。运维步骤见仓库 README。

## 仓库授权与协作链接

工程列表、Specs、Changes、正文、图片及历史快照的 GET/HEAD 逐次检查当前设备与工作台归属。远端仓库身份与内容权限按同一凭据工作台、同一稳定仓库身份复用 5 分钟，列表与仓库读取共用结果，并发只执行一轮。首次、过期或服务重启后先复验再返回数据；普通读取不滑动延长有效期。状态仅驻留内存，不保存 token，也不跨凭据复用。平台身份在登录时验证。

活跃工作台利用每分钟的后台检查在权限状态到期后复验；页面关闭后不常驻检查，再次访问时按有效期处理。仓库列表对需复验的条目执行受限并发检查，保持发现顺序、分页和不可用条目统计。私有快照刷新和已发布原型读取使用相同周期；新增公开原型在发布前额外即时复验。Git 访问使用本人 token，读取失败主动复验权限以区分失权与采集或网络错误。

远端明确拒绝立即使对应权限状态失效；token 或身份失效影响该凭据全部仓库，较早的在途检查不能恢复被拒绝的状态，已确认失权阻止在途交付。远端撤权在周期复验或实际接口错误时被识别；本地设备退出、撤销与切换仍即时生效。网络故障或限流不作为失权清空当前正文，过期复验失败不延长原成功状态，后续检查可重试。

所有远端请求明确使用当前连接，不使用宿主凭据、不回退其他 token。管理员 Cookie 与旧邀请码不接入个人仓库授权。已交付浏览器的内容不能远程收回。

工程分享链接仅包含平台、实例、稳定仓库 id 与阅读位置，不携带连接 id、会话、token 或可转让权限。接收者用当前工作台的 token 验证后恢复目标，需要其他凭据时主动切换；无权时不泄露工程内容。旧 project 链接仅在本人连接验证后使用私有映射恢复，旧 `#invite` 直接清除，邀请码验证及旧工程 API 停用。

原型分享使用独立固定版本公开入口，匿名只读取已发布产物、必要元数据与截图，不触发远端采集。退出、token 撤销或关闭后续准备不删除已公开版本；部署者可主动撤回。详见[原型浏览](../prototype-preview/spec.md)。

## 独立运维权限

管理密码由 `OPENFOLIO_ADMIN_PASSWORD` 指定；未设置时自动生成并私有保存到数据目录的 `admin-password`，签名密钥独立保存在 `access-secret`。管理员仅维护资源配置、获取专用上传地址及撤回公开版本，不获得任何仓库的个人读取权限。更换管理密码使旧管理员 Cookie 失效。

个人写请求只接受同源调用；远程必须使用 HTTPS。受信代理提供真实 Host 与协议，不能让客户端伪造；任意 forwarded-host 不作为访问来源。

持有专用上传地址者可上传静态原型，无需个人或管理员 Cookie，也不能凭此维护配置或读取工程记录。上传地址可保存到仓库供成员使用，轮换上传密钥撤销旧地址，不改变已发布文件。详见[内置静态托管](../prototype-preview/spec.md#openfolio-内置静态托管)。
