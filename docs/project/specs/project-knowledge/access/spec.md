# 项目访问与分享

独立管理密码由 OPENFOLIO_ADMIN_PASSWORD 指定；未设置时自动生成并私有保存到数据目录的 admin-password 文件。签名密钥独立保存在 access-secret。管理员可以查看全部项目和维护服务配置。

每项目维护长期邀请码，访客首次访问需验证。新建项目默认生成邀请码；旧配置缺少邀请码时仅管理员可访问。公开项目列表仅返回选择项目需要的名称、标识和锁定状态，不泄露仓库地址、邀请码或快照内容。

验证后通过 HttpOnly、SameSite=Lax 持久 Cookie 保存凭证，HTTPS 使用 Secure。各项目凭证不互通。工程文档、图片、Git 原型及截图的 GET/HEAD 均校验权限，异步读取结束后再次检查项目撤销和凭证变化。

分享链接在片段中携带邀请码，打开后自动验证，地址栏移除邀请码。同页切换分享链接同样生效。更换邀请码后旧链接和旧凭证失效；更换管理密码撤销已有访问凭证。外部 hosted URL 的权限由其托管者管理。
