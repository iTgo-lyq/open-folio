# 个人访问与分享

## 个人会话与连接

用户输入 GitHub token，服务先验证平台身份，再建立个人连接；Git 用户名来自已验证身份。一个浏览器会话可以拥有多个连接，包括同一平台账号的不同 token。新设备或清除 Cookie 后需要重新连接，不以平台账号名恢复其他会话的缓存。

浏览器使用随机 HttpOnly、SameSite=Lax Cookie，HTTPS 下为 Secure；服务端只保存 Cookie 摘要。会话有效期 30 天，成功新增或替换连接轮换 Cookie。替换必须保持原平台身份，失败保留原连接；换账号使用新增连接。重新进入多连接工作台时明确选择，不自动借用其他 token。

服务在私有 `personal-v1` 目录保存会话与连接。token 采用 AES-256-GCM 加密，使用独立 nonce 和绑定连接身份的 AAD；密钥来自私有 `credential-key` 或外置密钥文件。密文与密钥必须配套备份，缺失密钥或解密失败时拒绝恢复，不生成新密钥覆盖既有数据。token 不进入 URL、日志、Git 配置、浏览器持久存储或可读回的接口响应；表单提交后清空输入。

移除连接、替换 token、退出及会话到期撤销对应权限并取消在途任务。当前退出删除会话及其连接；会话到期在下一次会话操作时清理密文与授权。私有发现、Git 与快照按会话、连接和凭据 revision 隔离。

## 仓库授权与协作链接

工程列表、搜索、Specs、Changes、正文、图片及历史快照的 GET/HEAD 都检查本人连接、token 身份、仓库 API 权限及指定 token 的 Git refs。长操作交付前再次确认远端权限与本地连接仍有效。即使仓库公开或缓存已存在，也不能绕过失效 token；无法确认权限时隐藏内容并提示恢复。

所有远端请求明确使用当前连接，不使用宿主凭据、不回退其他 token。管理员 Cookie 与旧邀请码不接入个人仓库授权。已交付浏览器的内容不能远程收回。

工程分享链接仅包含平台、实例、稳定仓库 id 与阅读位置，不携带连接 id、会话、token 或可转让权限。接收者连接自己的账号后恢复目标，多个连接时明确选择；无权时不泄露工程内容。旧 project 链接仅在本人连接验证后使用私有映射恢复，旧 `#invite` 直接清除，邀请码验证及旧工程 API 停用。

原型分享使用独立固定版本公开入口，匿名只读取已发布产物、必要元数据与截图，不触发远端采集。退出、token 撤销或关闭后续准备不删除已公开版本；部署者可主动撤回。详见[原型浏览](../prototype-preview/spec.md)。

## 独立运维权限

管理密码由 `OPENFOLIO_ADMIN_PASSWORD` 指定；未设置时自动生成并私有保存到数据目录的 `admin-password`，签名密钥独立保存在 `access-secret`。管理员仅维护资源配置、获取专用上传地址及撤回公开版本，不获得任何仓库的个人读取权限。更换管理密码使旧管理员 Cookie 失效。

个人写请求只接受同源调用；远程必须使用 HTTPS。受信代理提供真实 Host 与协议，不能让客户端伪造；任意 forwarded-host 不作为访问来源。

持有专用上传地址者可上传静态原型，无需个人或管理员 Cookie，也不能凭此维护配置或读取工程记录。上传地址可保存到仓库供成员使用，轮换上传密钥撤销旧地址，不改变已发布文件。详见[内置静态托管](../prototype-preview/spec.md#openfolio-内置静态托管)。
