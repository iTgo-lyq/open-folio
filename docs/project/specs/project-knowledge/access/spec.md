# 个人访问与分享

## 凭据工作台与浏览器身份

用户输入 token，服务验证平台身份后建立或恢复凭据工作台。同一受信平台实例与完全一致的 token 对应同一工作台；不同 token 即使属于同一平台账号，也分别保存凭据、发现、缓存与偏好。新设备或清除 Cookie 后重新提供相同有效 token，可恢复原工作台。通用身份模型不依赖 GitHub 用户 ID 或 OAuth；公开版本只提供 GitHub.com 适配器。

“用户名”是最长 100 字符的可选显示名称，允许中文、内部空格及冒号，拒绝控制字符；省略、空字符串或纯空白视为未指定。首次登录未指定时使用 Git 账号名，恢复时保留原名称；自行填写无需与平台账号一致，不参与鉴权、工作台匹配或缓存归属。Git 传输用户名来自适配器验证的身份。

每个浏览器有独立身份集合，保存本浏览器亲自登录过的工作台授权，并且只有一个当前身份。每条设备会话同时是本浏览器记住一个工作台的授权；同浏览器与同工作台最多一条有效授权。身份列表展示显示名称、平台账号、当前标记和切换／移除操作，不能查看其他浏览器或全服务的凭据目录。

“当前凭据”页可输入 token 添加并使用身份，其他已保存身份保留；相同 token 恢复原工作台并重新签发本浏览器授权，不增加重复列表项。点选有效的已保存身份无需输入或提交 token，服务使用目标工作台加密保存的凭据验证平台身份，成功后才提交当前选择。平台、实例与稳定账号身份必须一致；token 失效提示重新登录，网络故障或限流保留目标授权和当前身份。

浏览器使用随机 HttpOnly、SameSite=Lax Cookie，HTTPS 下为 Secure；服务端只保存 Cookie 摘要。Cookie 指向身份集合，新增或重新添加身份可用同一个值更新其保留期，覆盖集合内授权的最晚绝对期限；普通读取、点选切换、移除与退出不写或清 Cookie。不同浏览器 Cookie 独立；刷新、浏览器重开与服务重启恢复有效列表和当前选择，清除 Cookie 后须重新添加各身份。

每条授权独立采用 30 天闲置期限和 90 天绝对期限。普通已认证活动每天至多更新一次当前授权的闲置期限，查看列表不续期非当前身份；切换可触达目标授权但不重置绝对期限。过期授权在后续会话操作时清理，当前授权失效后回到选择／登录界面，不自动使用其他身份。

移除身份仅撤销该浏览器对应授权。移除非当前身份保留当前阅读；移除当前身份或退出当前设备清空当前选择，仍可点选其余有效身份。当前凭据页只列出或撤销当前工作台的设备，包括其他浏览器暂未选中的记住授权，不返回 Cookie、摘要或详细网络指纹。单台撤销同时移除记住授权；退出全部设备撤销该工作台所有授权，其他工作台身份保留。已退出或撤销的身份不能靠列表恢复，工作台凭据、偏好及已提交缓存保留，再次提供相同有效 token 可恢复。

同浏览器标签页共享当前身份，通过不含凭据或身份摘要的 BroadcastChannel 通知及 focus、可见性和定时检查同步。选择变化时清除旧正文、仓库列表、错误与临时凭据，晚到会话、偏好和读取响应不能恢复旧上下文；切回同一工作台也重新建立读取代次并从仓库第一页恢复。移除非当前身份只更新列表。其他浏览器的当前身份与登录保持独立。

## 授权关系与并发契约

身份集合保存 Cookie 摘要、当前授权指针、集合 revision 和 selectionRevision；设备授权通过 browserId 与 workspaceId 关联集合和工作台。当前指针只能指向所属有效授权。添加与切换、当前指针清理增加选择代次；非当前授权移除只增加集合版本，当前读取继续有效。

`GET /api/session` 返回当前工作台、仅当前连接的 connections、所属 identities 及两个版本；没有当前选择时 connected 为 false，仍可返回其他有效身份。`POST /api/session` 添加，`POST /api/session/switch` 只接收 identityId，`DELETE /api/session/identities/[id]` 移除所属授权。浏览器身份操作、设备管理、偏好写入和当前 token 复制携带 `X-OpenFolio-Revision`；有效集合必须匹配当前 revision，否则拒绝并重新读取会话。首次无有效集合的登录不要求该字段，版本不构成授权。

远程 token 验证前后复核原集合与授权；最后一个身份退出后的在途登录不能重建集合。登录响应写 Cookie 前再复核提交结果，延迟响应不能覆盖新登录。私有读取同时绑定原设备授权和选择代次，HTTP 交付前复核，A → B → A 也不能恢复第一次 A 的响应。共享发现与刷新任务按工作台归属，只使用原工作台 token；单设备切换、退出或撤销只停止该设备交付，全设备退出中止该工作台共享任务。

## 凭据存储与主动复制

服务在私有 `personal-v2/state.json` 的 schemaVersion 3 保存凭据工作台、浏览器集合与设备授权，归属、选择与撤销原子提交。目录权限 0700，状态与秘密文件 0600；工作台、浏览器集合与设备授权各最多 10,000 条，单工作台最多 32 个有效设备授权，单浏览器最多记住 32 个身份。达到上限拒绝新增并保留现有选择。

读取 schemaVersion 2 状态时保留工作台 UUID、加密凭据和偏好，丢弃旧设备会话，构造空的新集合与授权；首次成功状态提交写入版本 3。旧 Cookie 和设备会话不能恢复登录，重新输入相同 token 可恢复原工作台与缓存。损坏状态或缺失密钥不覆盖原数据。

工作台使用随机 UUID；服务端以独立 32 字节 identity-key 对平台、实例与完整 token 计算 HMAC-SHA256 匹配索引，不以可变用户名或 subjectId 合并账号。token 只去除首尾空白，保留大小写及内部字节。索引不进入响应、URL 或目录名。

token 采用 AES-256-GCM 加密，使用独立 nonce 和绑定凭据格式版本、工作台、平台实例的 AAD；凭据格式仍为 `[2, workspaceId, providerId, instanceId]`，独立于外层状态版本。独立 32 字节加密密钥来自私有 credential-key 或外置密钥文件。状态、加密密钥与身份密钥必须配套备份，缺失密钥或解密失败时拒绝恢复，不生成新密钥覆盖既有数据。停机密钥轮换先验证全部原密文与匹配索引，再生成成套替换数据，保留工作台 UUID、浏览器集合、设备授权、当前选择及缓存归属；更换平台 token 仍进入独立工作台。

token 不进入 URL、日志、Git 配置、localStorage 或 sessionStorage；表单提交后清空输入，普通会话、身份、设备和仓库摘要不包含明文。用户主动点击“复制 token”时，同源 `POST /api/session/token` 仅读回当前已登录工作台的凭据，不接受目标工作台、连接 id 或批量导出。响应前复验授权、当前选择与选择代次，响应采用 private、no-store。剪贴板不可用时提供本次操作的临时只读文本，关闭、切换或退出时清除；不生成另一个登录秘密。

## 仓库授权与协作链接

工程列表、Specs、Changes、正文、图片及历史快照的 GET/HEAD 逐次检查当前设备与工作台归属。远端仓库身份与内容权限按同一凭据工作台、同一稳定仓库身份复用 5 分钟，列表与仓库读取共用结果，并发只执行一轮。首次、过期或服务重启后先复验再返回数据；普通读取不滑动延长有效期。状态仅驻留内存，不保存 token，也不跨凭据复用。平台身份在登录时验证。

活跃工作台利用每分钟的后台检查在权限状态到期后复验；页面关闭后不常驻检查，再次访问时按有效期处理。仓库列表对需复验的条目执行受限并发检查，保持发现顺序、分页和不可用条目统计。私有快照刷新和已发布原型读取使用相同周期；新增公开原型在发布前额外即时复验。Git 访问使用本人 token，读取失败主动复验权限以区分失权与采集或网络错误。

远端明确拒绝立即使对应权限状态失效；token 或身份失效影响该凭据全部仓库，较早的在途检查不能恢复被拒绝的状态，已确认失权阻止在途交付。远端撤权在周期复验或实际接口错误时被识别；本地设备退出、撤销与切换仍即时生效。网络故障或限流不作为失权清空当前正文，过期复验失败不延长原成功状态，后续检查可重试。

所有远端请求明确使用当前连接，不使用宿主凭据、不回退其他 token。管理员 Cookie 不接入个人仓库授权。已交付浏览器的内容不能远程收回。

工程分享链接仅包含平台、实例、稳定仓库 id、实际协作分支与阅读位置，不携带连接 id、会话、token 或可转让权限。接收者用当前工作台的 token 验证后恢复目标，需要其他凭据时主动切换；无权时不泄露工程内容。

原型分享使用独立固定版本公开入口，匿名只读取已发布产物、必要元数据与截图，不触发远端采集。退出、token 撤销或关闭后续准备不删除已公开版本；部署者可主动撤回。详见[原型浏览](../prototype-preview/spec.md)。

## 独立运维权限

管理密码由 `OPENFOLIO_ADMIN_PASSWORD` 指定；未设置时自动生成并私有保存到数据目录的 `admin-password`，签名密钥独立保存在 `access-secret`。管理员仅维护资源配置、获取专用上传地址及撤回公开版本，不获得任何仓库的个人读取权限。更换管理密码使旧管理员 Cookie 失效。

个人写请求只接受同源调用；远程必须使用 HTTPS。受信代理提供真实 Host 与协议，不能让客户端伪造；任意 forwarded-host 不作为访问来源。

持有专用上传地址者可上传静态原型，无需个人或管理员 Cookie，也不能凭此维护配置或读取工程记录。上传地址可保存到仓库供成员使用，轮换上传密钥撤销旧地址，不改变已发布文件。详见[内置静态托管](../prototype-preview/spec.md#openfolio-内置静态托管)。
