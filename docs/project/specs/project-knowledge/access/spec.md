# 个人访问与分享

## 账号登录与 Token 绑定

用户自行设置账号和密码并注册，注册成功即登录；后续使用相同账号密码登录。账号去首尾空白后为 1–64 个 Unicode 码点，拒绝控制字符，以 NFKC 与小写检查唯一性并保留显示名称。密码为 8–128 个码点，不裁剪或归一化。重复账号返回 409，账号不存在或密码错误统一返回 401。

密码只保存随机盐和异步 scrypt 摘要，使用等时比较；不存在的账号也执行派生。注册与登录共用每进程最多 2 次并发、8 项等待的有界入口；同规范化账号连续失败 5 次后暂缓 5 分钟并返回 429 和 Retry-After，计数有过期与容量限制，不依赖客户端转发头识别来源。

账号拥有多条 Token 绑定，一条绑定对应一个随机 UUID 工作台。同账号、同受信平台实例与完全一致的 Token 去重；不同 Token 分别保存工作台、发现、缓存与偏好。不同 OpenFolio 账号即使绑定同一个 Token，也分别隔离这些数据。平台身份不依赖可变用户名；公开版本只提供 GitHub.com 适配器，Git 传输用户名来自适配器验证的身份。

账号没有 Token 也能登录并管理设备。另一浏览器登录同一账号即可看到绑定列表，不批量验证 Token，也不需要重新提交 Token；新登录不预选绑定。刷新、浏览器重开和服务重启恢复该设备已有选择。会话有效但未选择绑定时 authenticated 为 true、connected 为 false；Token 失效不退出 OpenFolio 账号。

Token 可命名、选用和解绑。添加前验证平台凭据；选用时服务使用加密凭据验证平台、实例及稳定账号身份，成功后才提交选择。验证失败保留原选择；平台明确拒绝提示重新绑定，网络故障和限流保留绑定与当前选择。解绑从账号删除绑定，清空所有选中它的设备选择，并取消该绑定的在途任务；重新使用须再次绑定。

## 账号设备与并发契约

浏览器使用随机 32 字节的 openfolio-account Cookie，HttpOnly、SameSite=Lax，HTTPS 下为 Secure；服务端只保存摘要。注册或登录签发新 Cookie，并替换该浏览器原账号会话；普通读取、选用、解绑及退出不写 Cookie，避免晚到响应覆盖新登录。

每台账号设备采用 30 天闲置、90 天绝对期限，已认证活动每天至多续期一次且不超过绝对期限。账号可列出、撤销单台设备或退出全部设备，只返回必要设备摘要，不返回 Cookie、摘要或详细网络指纹。退出按账号处理，保留 Token 绑定和工作台；重新登录后直接选用。过期或被撤销的设备不能管理绑定或读取私有内容。

每台设备保存 accountId、当前工作台、revision 与 selectionRevision，当前工作台必须属于同一账号。绑定列表变化更新该账号各设备 revision；只有选择变化增加对应设备 selectionRevision。解绑清空所有受影响设备选择并增加选择代次，其他绑定及账号不受影响。

同浏览器标签页通过不含凭据的 BroadcastChannel、focus、可见性及定时检查同步。选择变化时清除旧正文、仓库列表、错误和临时凭据，晚到会话、偏好及读取响应不能恢复旧上下文；A → B → A 也重新建立读取代次。其他浏览器的选择保持独立。

POST /api/accounts/register 接收 username、password 注册；POST /api/session 登录，DELETE 退出当前设备。GET /api/session 返回 authenticated、账号摘要、账号全部 connections、可选的当前 workspace、设备有效期及两个版本，不返回 identities。POST /api/connections 验证、绑定并选用；PATCH /api/connections/[id] 命名，DELETE 解绑。POST /api/session/switch 只接收 connectionId。设备列表、单台撤销和 logout-all 均按账号授权。

个人写请求只接受同源调用；已登录修改、设备管理、偏好写入及主动复制携带 X-OpenFolio-Revision，冲突返回 409 后重新读取会话，版本号不构成授权。Token 远程验证前后复核原账号、设备、归属和版本，退出或解绑后的在途添加与切换不能恢复授权。密码登录响应交付前复核同一有效设备，其他设备修改绑定列表不会把已成功的登录误判为被替换。

私有读取 lease 绑定账号、设备、工作台与选择代次，HTTP 交付前复验。共享发现与刷新只属于该账号工作台，使用其原始 Token；单设备退出或切换停止本设备交付，共享任务可继续服务其他设备。解绑中止该绑定全部任务并移除后台扫描目标，退出全部设备中止该账号当前全部任务；保留绑定的常驻扫描会在后续周期继续，不恢复已退出设备的授权。

## 私有存储与主动复制

服务仅在 personal/state.json 的 schemaVersion 1 保存账号、绑定工作台和设备会话；使用串行写锁与原子替换统一校验归属、唯一性和选择。目录权限 0700，状态及密钥 0600。账号、绑定与设备各最多 10,000 条，每账号最多 32 个绑定和 32 台设备；达到上限拒绝新增并保留已有数据。损坏状态或缺失密钥不覆盖重建。

账号保存密码盐及摘要；独立 32 字节 identity-key 对 accountId、平台、实例和完整 Token 计算 HMAC-SHA256 匹配索引。索引不进入响应、URL 或目录名。Token 使用独立 nonce 的 AES-256-GCM 加密，AAD 包含格式版本、账号、工作台、平台和实例；独立加密密钥来自 personal/credential-key 或外置密钥文件。

状态与配套密钥共同保存；密钥缺失或解密失败时拒绝凭据使用，不生成新密钥覆盖已有数据。停机密钥轮换只处理当前格式，先验证全部密文与匹配索引，再生成配套替换数据，保留账号、工作台 UUID、设备、当前选择与缓存引用。系统不读取旧个人身份模型，不接受旧 Cookie 或旧 Token 登录协议，不提供历史兼容、导入或迁移路径。

密码及 Token 不进入 URL、日志、Git 配置、localStorage 或 sessionStorage；表单提交后清空秘密输入，普通账号、连接、设备及仓库摘要不包含明文、密码摘要或密文。主动点击“复制当前 Token”时，同源 POST /api/session/token 仅读回当前绑定的 Token，不接受目标 id 或批量导出。响应前复核账号设备、选择代次及授权，使用 private、no-store；剪贴板失败提供临时只读文本，关闭、切换或退出时清除。

## 仓库授权与协作链接

私有工程列表、Specs、Changes、正文、图片及历史快照的 GET/HEAD 逐次检查当前设备与工作台归属。远端仓库身份与内容权限按同一凭据工作台、同一稳定仓库身份复用 5 分钟，列表与仓库读取共用结果，并发只执行一轮。首次、过期或服务重启后先复验再返回数据；普通读取不滑动延长有效期。状态仅驻留内存，不保存 token，也不跨凭据复用。平台身份在绑定及选用 Token 时验证。

页面检查与服务端常驻扫描均在权限状态到期后复验；有近期页面活动的来源约每分钟扫描，两分钟没有刷新请求后按完成后至少五分钟的间隔扫描，页面关闭不停止。仓库列表对需复验的条目执行受限并发检查，保持发现顺序、分页和不可用条目统计。私有快照刷新和已发布原型读取使用相同权限有效期；新增公开原型在发布前额外即时复验。Git 访问使用本人 token，读取失败主动复验权限以区分失权与采集或网络错误。

远端明确拒绝立即使对应权限状态失效；token 或身份失效影响该凭据全部仓库，较早的在途检查不能恢复被拒绝的状态，已确认失权阻止在途交付。远端撤权在周期复验或实际接口错误时被识别；本地设备退出、撤销与切换仍即时生效。网络故障或限流不作为失权清空当前正文，过期复验失败不延长原成功状态，后续检查可重试。

PR 关联额外需要 Pull requests: read 权限。PR 接口的 403/404、限流或网络失败只降级对应交付信息，保留文档和已核实事实；401 或确证仓库内容失权仍走授权失效路径。

私有工作台的远端请求明确使用当前连接，不使用宿主凭据、不回退其他 token。管理员 Cookie 不接入个人仓库授权。已交付浏览器的内容不能远程收回。

工作台阅读链接仅包含平台、实例、稳定仓库 id、实际集成分支与阅读位置，不携带连接 id、会话、token 或可转让权限。接收者用当前工作台的 token 验证后恢复目标，需要其他凭据时主动切换；无权时不泄露工程内容。

原型分享使用独立固定版本公开入口，匿名只读取已发布产物、必要元数据与截图，不触发远端采集。退出、token 撤销或关闭后续准备不删除已公开版本；部署者可主动撤回。详见[原型浏览](../prototype-preview/spec.md)。

## 单个 Change 的公开只读分享

`/share?repository=<仓库HTTPS地址>&change=<id>&integrationBranch=<集成分支>` 直接指定目标，任何人都可构造、复制或转发，不创建分享记录，不绑定分享者账号，也没有单链接启停或撤销。接收者无需登录或配置 Token。仓库可以是公开或私有仓库；目标必须存在且服务具有可用的已接入读取来源，匿名访问不会发现或接入任意新仓库。

服务从已保存的有效绑定与发现记录中匹配平台、实例、稳定仓库身份和实际集成分支，再使用该来源的凭据及缓存读取。失效来源可切换到同目标的其他可读来源，损坏的单份发现缓存不影响其他候选。只允许受信平台的规范 HTTPS 仓库地址，不接收任意 Git 主机、路径或 ref；未指定集成分支时必须能唯一确定来源。全部来源不可用时停止返回内容，不能用旧缓存延续访问。

匿名 API `/api/shared-changes/...` 仅提供 GET/HEAD，采用白名单投影，只返回目标 Change 的状态、材料、图片、原型及合入与 PR 交付信息，不公开仓库目录、其他 Change 正文、个人账号、绑定或设备信息。正文、图片、合入文件和原型资源均校验目标范围与固定快照；不能通过参数越界读取或混用版本。交付前再次核对来源和读取范围，解绑或已确认失权阻止在途交付。

分享跟随已推送的最新内容，沿用集中入口、登记分支及有效归档的权威来源。成功检查可复用一分钟，远端权限沿用固定五分钟有效期，读取不滑动续期；页面可见时定期检查，隐藏时暂停。快照或来源变化后重新读取，明确失权清空正文。设备退出不撤销仍存在的仓库绑定，因此不关闭分享；链接本身不能绕过服务的来源与权限检查。

公开响应不携带凭据，使用禁止缓存、禁止 MIME 嗅探及无 Referrer 的响应策略，页面禁止搜索引擎索引。外链不转发分享页来源。原型在当前 Change 范围内读取，不自动产生永久公开版本；独立 `/preview/<publicationId>` 的发布与撤回规则保持独立。

## 独立运维权限

管理密码由 `OPENFOLIO_ADMIN_PASSWORD` 指定；未设置时自动生成并私有保存到数据目录的 `admin-password`，签名密钥独立保存在 `access-secret`。管理员仅维护资源配置、获取专用上传地址及撤回公开版本，不获得任何仓库的个人读取权限。更换管理密码使旧管理员 Cookie 失效。

个人写请求只接受同源调用；远程必须使用 HTTPS。受信代理提供真实 Host 与协议，不能让客户端伪造；任意 forwarded-host 不作为访问来源。

持有专用上传地址者可上传静态原型，无需个人或管理员 Cookie，也不能凭此维护配置或读取工程记录。上传地址可保存到仓库供成员使用，轮换上传密钥撤销旧地址，不改变已发布文件。详见[内置静态托管](../prototype-preview/spec.md#openfolio-内置静态托管)。
