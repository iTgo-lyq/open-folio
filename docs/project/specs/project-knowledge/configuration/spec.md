# 服务配置

数据目录由 `OPENFOLIO_DATA_DIR` 指定，默认 `~/.local/share/open-folio`。配置优先使用 `OPENFOLIO_CONFIG` 路径，否则使用数据目录下的 `config.json`；不接受内联 JSON。不存在的父目录与文件自动创建，初始配置为 `schemaVersion: 2` 和空资源限制，已有文件不会被初始化覆盖。

配置只保存读取资源限制，仓库通过个人 token 自动发现；用户在仓库接入时指定协作分支，初值推荐 develop，可使用其他合法名称。当前内容与原型策略直接来自所选分支，必须匹配其 workflow v2 声明；后台不读取默认分支配置、不校验保护分支引用存在，缺少有效入口时提示 Setup。个人 UI 不提供服务配置或管理密码表单；管理员通过独立管理 API 读取与保存限制、获取上传地址和撤回公开版本，管理权限不授予工程读取权限。

资源限制可清除覆盖值以恢复默认，合法保存立即生效，无需重启。配置使用原文摘要进行版本比较，在同目录写入临时文件再原子替换；过期版本或外部编辑导致冲突时返回 409，重新读取后才可保存。损坏 JSON、字段不合法和读写失败保留原配置并显示明确错误。数据目录按 0700、敏感文件按 0600 初始化，单进程锁防止重复写入。

个人数据包含凭据工作台、浏览器身份集合与设备授权，state.json、credential-key 与 identity-key 须配套备份；缺失密钥不能补生成。外层状态版本 3 与凭据加密格式分开；旧版本状态只保留工作台，旧登录需重新添加身份。工作台与缓存不随身份移除或设备退出删除。对应的数据归属和停机密钥轮换约束见[个人访问与分享](../access/spec.md)。

服务使用单实例独占写入数据目录。持久化目录、密钥轮换、备份与缓存清理步骤见仓库 README；开发机服务更新遵循 AGENTS.md。

## 真实登录冒烟

冒烟检查内容由每次任务选择，真实登录通过 `scripts/smoke-session.ts` 的 `withSmokeSession` 建立独立测试 Cookie。检查成功、抛错或请求失败后，都读取最新会话版本并携带 `X-OpenFolio-Revision` 退出，检查响应后再读取确认当前与记住的授权均已清除；只处理本次测试浏览器，保留其他设备与工作台数据。

清理最多尝试三轮，无法确认退出时必须失败；检查与清理同时失败时保留两项错误。浏览器验证使用包装器提供的内存 Cookie，所有检查在回调内等待完成。进程强制终止、服务持续不可达或登录响应完全丢失时不能保证客户端完成清理，不能将可捕获的清理失败当作验证成功。配置与调用示例见仓库 README。
